Screen resolution vs. viewport

Bildschirmauflösung is the size of your whole display. Browsers report it in CSS pixels; multiply by the device pixel ratio to get physical pixels. A 4K monitor at 150% scaling, for example, reports 2560 × 1440 CSS pixels with a ratio of 1.5 (3840 × 2160 physical).

The viewport is the visible area of the web page inside the browser window. Web designers use it to test responsive layouts.

Common resolutions

  • 1920 × 1080 (Full HD, 16:9) — the most common desktop size
  • 1366 × 768 — many budget laptops
  • 2560 × 1440 (QHD) and 3840 × 2160 (4K UHD)
  • 390 × 844 and 412 × 915 — common phone viewports in CSS pixels

Häufige Fragen

Warum ist meine Auflösung niedriger als die Spezifikationen meines Monitors?

Durch die Anzeigeskalierung in Windows oder macOS meldet der Browser eine kleinere CSS-Größe. Physische Pixel zeigen die tatsächliche Panel-Auflösung.

Was ist das Pixelverhältnis eines Geräts?

Die Anzahl der physischen Pixel pro CSS-Pixel. Retina- und High-DPI-Bildschirme sind normalerweise 2 oder 3.

Werden Daten erhoben?

Nein. Die Werte werden von Ihrem Browser gelesen und nur Ihnen angezeigt.

Ist screen resolution kostenlos?

Ja. screen resolution ist im Browser kostenlos, ohne Konto.
