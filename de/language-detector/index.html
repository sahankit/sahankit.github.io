    Sprache erkennen

    Erfordert Desktop-Chrome mit integrierter KI (Gemini Nano) und ausreichend freiem Speicherplatz. Die Verarbeitung erfolgt auf Ihrem Gerät.

    So verwenden Sie den Sprachdetektor

    1. Geben Sie Ihre Daten ein. Erkennen Sie die Sprache von Text mit der Spracherkennungs-API von Chrome.
    2. Holen Sie sich das Ergebnis. Drücken Sie „Erkennen“ . Aktualisierung der Ergebnisse auf der Seite.
    3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

    Wann sollte der Sprachdetektor verwendet werden?

    Erkennen Sie die Sprache von Text mit der Spracherkennungs-API von Chrome. Verwenden Sie es, wenn Sie eine schnelle Antwort benötigen, ohne Software zu installieren oder ein Konto zu erstellen.

    Alles läuft lokal in Ihrem Browser, wo das Tool es unterstützt – nützlich für Formulare, Rechnungen, Studien und schnelle Überprüfungen unterwegs.

    Häufige Fragen

    Ist dieser Sprachdetektor kostenlos?

    Ja. Der Sprachdetektor kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

    Verlassen meine Daten das Gerät?

    Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

    Funktioniert der Sprachdetektor auf Mobilgeräten?

    Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
