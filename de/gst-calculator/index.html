Exclusive vs inclusive GST

If your amount excludes GST, the tool adds tax on top. If the amount already includes GST, it backs out the taxable value and tax component—useful for invoices marked GST-inclusive.

How to use the GST calculator

  1. Enter your details. Fill in Amount (₹) and GST rate (%) .
  2. Get the result. Press Calculate . Results update on the page and recalculate as you edit values.
  3. Use or copy it. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Welche GST-Sätze werden unterstützt?

Schnellvoreinstellungen für 5 %, 12 %, 18 % und 28 % – gängige Plattenraten in Indien.

Gilt das für die Einreichung von Steuererklärungen?

Nein. Nutzen Sie offizielle GST-Portale und Ihre Zertifizierungsstelle für die Einhaltung der Vorschriften. Dies ist ein schneller Mathe-Helfer.

Ist GST-Rechner kostenlos?

Ja. GST-Rechner ist im Browser kostenlos, ohne Konto.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
