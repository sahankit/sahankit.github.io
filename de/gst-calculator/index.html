Exklusiv vs. inklusive GST

Wenn Ihr Betrag GST ausschließt, fügt das Tool zusätzlich Steuern hinzu. Wenn der Betrag bereits GST enthält, werden der steuerpflichtige Wert und die Steuerkomponente zurückgesetzt – nützlich für Rechnungen, die mit GST-inklusive gekennzeichnet sind.

  • Exklusiv ₹1.000 bei 18 %: GST ₹180 → insgesamt ₹1.180
  • Inklusive ₹1.180 bei 18 %: Steuerpflichtig ≈ ₹1.000, GST ≈ ₹180
  • Innerstaatliches B2B: wird oft als CGST + SGST (jeweils die halbe Rate) angezeigt – zwischenstaatlicher Wert wird IGST verwendet

How to use the GST calculator

  1. Geben Sie Ihre Daten ein. Geben Sie den Betrag (£) und den GST-Satz (%) ein.
  2. Holen Sie sich das Ergebnis. Drücken Sie Berechnen . Die Ergebnisse werden auf der Seite aktualisiert und neu berechnet, während Sie Werte bearbeiten.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Welche GST-Sätze werden unterstützt?

Schnellvoreinstellungen für 5 %, 12 %, 18 % und 28 % – gängige Plattenraten in Indien.

Wie entferne ich GST aus einem Inklusivpreis?

Öffnen Sie den GST-Inklusivrechner oder den umgekehrten GST-Rechner für die gleichen Tarifvoreinstellungen.

Gilt das für die Einreichung von Steuererklärungen?

Nein. Nutzen Sie offizielle GST-Portale und Ihre Zertifizierungsstelle für die Einhaltung der Vorschriften. Dies ist ein schneller Mathe-Helfer.

Wird dadurch meine GSTIN validiert?

Nein. Verwenden Sie den GSTIN-Formatprüfer nur zur Mustervalidierung.

Ist dieser GST-Rechner kostenlos?

Ja. Der GST-Rechner kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
