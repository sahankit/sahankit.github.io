The four-value order

When the corners differ, CSS reads the four lengths clockwise from the top left: top left, top right, bottom right, bottom left. A single length applies to every corner. The copied line is ready to paste into a style rule.

How to use the border radius generator

  1. Enter your details. Fill in Alle Ecken (px), Oben links (px), Oben rechts (px), Unten rechts (px) und Unten links (px).
  2. Get the result. The result updates on the page as you type.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Kann ich Prozent statt Pixel verwenden?

Dieser Generator schreibt Pixel. Ein prozentualer Radius ist relativ zur Boxgröße, die sich ändert, wenn das Element wächst.

Is this border radius generator free?

Yes. The border radius generator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
