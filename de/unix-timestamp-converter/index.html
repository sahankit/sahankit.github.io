Über den Unix-Zeitstempel

Konvertieren Sie Unix-Epochensekunden (oder Millisekunden) in Ihr lokales Datum und Ihre lokale Uhrzeit oder wandeln Sie einen Datumsauswahlwert in einen Zeitstempel um.

Läuft im Browser—keine Anmeldung, keine Installation.

So verwenden Sie den Unix-Zeitstempel

  1. Geben Sie Ihre Daten ein. Geben Sie den Unix-Zeitstempel sowie Datum und Uhrzeit ein.
  2. Holen Sie sich das Ergebnis. Drücken Sie Zeitstempel → Datum. Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist dieser Unix-Zeitstempel kostenlos?

Ja. Der Unix-Zeitstempel kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert der Unix-Zeitstempel auf Mobilgeräten?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
