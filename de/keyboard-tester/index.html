Grenzen von Browser-Tastaturtests

Einige Tasten sind vom Betriebssystem oder Browser reserviert und erreichen Webseiten nie – zum Beispiel Fn, „Bildschirm drucken“ auf einigen Systemen und Tastenkombinationen wie Strg+W oder Befehl+Q. Medientasten variieren je nach Gerät.

So verwenden Sie den Tastaturtester

  1. Geben Sie Ihre Daten ein. Kostenloser Online-Tastaturtester. Drücken Sie die Tasten, um zu überprüfen, ob sie funktionieren: Die Tasten leuchten auf, wenn Sie sie gedrückt halten, und bleiben nach dem Test markiert. Zeigt Ereignisschlüssel, Code und Schlüsselcode an.
  2. Holen Sie sich das Ergebnis. Drücken Sie Test zurücksetzen. Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Kann es den Schlüssel-Rollover (NKRO) testen?

Halten Sie mehrere Tasten gleichzeitig gedrückt – jede gedrückte Taste leuchtet auf. Wenn einige aufhören zu leuchten, haben Sie die Rollover-Grenze Ihrer Tastatur erreicht.

Warum wird die Fn-Taste nicht angezeigt?

Fn wird innerhalb der Tastaturhardware verarbeitet und nicht an den Browser gemeldet.

Zeichnet es auf, was ich tippe?

Nein. Tastendrücke werden nur auf dieser Seite angezeigt und niemals irgendwohin gesendet.

Ist dieser Tastaturtester kostenlos?

Ja. Der Tastaturtester kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
