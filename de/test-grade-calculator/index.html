About the test grade calculator

Find the final exam score you need to reach a target course grade when the final has a fixed weight.

Runs in your browser—no signup and no install.

How to use the test grade calculator

  1. Enter your details. Fill in Aktueller Kursdurchschnitt (%), Gewicht der Abschlussprüfung (% natürlich) und Angestrebte Kursnote (%).
  2. Get the result. Press Berechnen. Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this test grade calculator free?

Yes. The test grade calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
