Über die Stichprobengröße

Schätzen Sie die Stichprobengröße der Umfrage für einen Anteil mit Fehlertoleranz. Kostenloser Beispielrechner für Statistiken.

Läuft im Browser—keine Anmeldung, keine Installation.

So verwenden Sie die Stichprobengröße

  1. Geben Sie Ihre Daten ein. Geben Sie den erwarteten Anteil (0–1, verwenden Sie 0,5, wenn Sie unsicher sind), die Fehlerspanne (z. B. 0,05 = ±5 %) und den Z-Score (1,96 = 95 %) ein.
  2. Holen Sie sich das Ergebnis. Drücken Sie Probengröße n . Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist diese Stichprobengröße kostenlos?

Ja. Die Stichprobengröße kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert die Stichprobengröße auf Mobilgeräten?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
