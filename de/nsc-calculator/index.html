Wie sich der Fälligkeitsbetrag zusammensetzt

Die Zinsen werden einmal im Jahr addiert und werden in späteren Jahren verzinst. Die Auszahlung erfolgt erst bei Fälligkeit. Bei 7,7 % über 5 Jahre wachsen 10.000 ₹ auf etwa 14.490 ₹. Das Finanzministerium gibt den Satz vierteljährlich bekannt. Ein Zertifikat behält den Kurs des Quartals, in dem Sie es kaufen, für die gesamten fünf Jahre.

So verwenden Sie den NSC-Rechner

  1. Geben Sie Ihre Daten ein. Geben Sie den investierten Betrag (£), die Jahresrate (%) und die Jahre ein.
  2. Holen Sie sich das Ergebnis. Drücken Sie auf Fälligkeit schätzen. Die Ergebnisse werden auf der Seite aktualisiert und neu berechnet, während Sie Werte bearbeiten.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Wann Sie den NSC-Rechner verwenden sollten

Schätzen Sie die Laufzeit des National Savings Certificate. Die Zinsen werden jährlich berechnet und am Ende der Laufzeit ausgezahlt. Der Standardsatz beträgt 7,7 % für Oktober–Dezember 2026. Verwenden Sie ihn, wenn Sie eine schnelle Antwort benötigen, ohne Software zu installieren oder ein Konto zu erstellen.

Alles läuft lokal in Ihrem Browser, wo das Tool es unterstützt – nützlich für Formulare, Rechnungen, Studien und schnelle Überprüfungen unterwegs.

Häufige Fragen

Sind NSC-Zinsen steuerfrei?

Nein. Zinsen sind steuerpflichtig. Die Einlage und die in den ersten vier Jahren als reinvestiert behandelten Zinsen können auf die Abzugsgrenze des alten Systems angerechnet werden. Auf dieser Seite werden keine Steuern berechnet.

Was ist das Minimum?

Die NSC VIII-Ausgabe wird in mehreren Exemplaren ab 1.000 ₹ ausgegeben. Dieser Rechner erzwingt nicht das Postamt-Minimum.

Ist dieser NSC-Rechner kostenlos?

Ja. Der NSC-Rechner kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert der NSC-Rechner auf Mobilgeräten?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
