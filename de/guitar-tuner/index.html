How to tune your guitar

Standard guitar tuning from thickest to thinnest string is E2 (82.41 Hz), A2 (110 Hz), D3 (146.83 Hz), G3 (196 Hz), B3 (246.94 Hz) and E4 (329.63 Hz).

  • Choose your instrument and tuning, press Tuner starten and allow the microphone.
  • Pluck one string and let it ring. The tuner finds the nearest string and shows the note.
  • If the needle is left (too low), tighten the string; if it is right (too high), loosen it.
  • When the display turns green (within ±5 cents), move to the next string.

Tuning tips

  • Tune up to the note rather than down—strings hold pitch better.
  • Tune in a quiet room and keep the phone or laptop mic close to the sound hole.
  • Tap a string button to hear a reference tone and tune by ear.
  • Change A4 from 440 Hz only if your band or recording uses a different reference.

How to use the guitar tuner

  1. Enter your details. Fill in Instrument and Reference pitch A4 (Hz) .
  2. Get the result. Press Start tuner . Results update on the page.
  3. Use or copy it. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Funktioniert es auf meinem Telefon?

Ja – in Chrome, Safari und anderen modernen mobilen Browsern. Erlauben Sie den Zugriff auf das Mikrofon, wenn Sie dazu aufgefordert werden.

Was ist ein Cent?

Ein Hundertstel Halbton. Die meisten Menschen können Unterschiede unter etwa 5 Cent nicht hören.

Wird mein Ton aufgezeichnet?

Nein. Der Ton wird live in Ihrem Browser analysiert und niemals gespeichert oder hochgeladen.

Ist guitar tuner kostenlos?

Ja. guitar tuner ist im Browser kostenlos, ohne Konto.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
