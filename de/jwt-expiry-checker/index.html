Über den JWT-Ablaufprüfer
Dekodieren Sie die JWT-Nutzlast und zeigen Sie die Ausgabe-/Ablaufzeiten sowie Sekunden bis zum Ablauf an. Überprüft keine Signaturen.
Läuft im Browser—keine Anmeldung, keine Installation.
So verwenden Sie den JWT-Ablaufprüfer
  1. Geben Sie Ihre Daten ein. Füllen Sie JWT aus.
  2. Holen Sie sich das Ergebnis. Drücken Sie auf Ablauf prüfen. Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.
Häufige Fragen
Ist dieser JWT-Ablaufprüfer kostenlos?
Ja. Der JWT-Ablaufprüfer kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.
Verlassen meine Daten das Gerät?
Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
Funktioniert der JWT-Ablaufprüfer auf Mobilgeräten?
Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
