WCAG contrast requirements

  • AA normal text: at least 4.5:1
  • AA large text (24px, or 18.66px bold): at least 3:1
  • AAA normal text: at least 7:1; AAA large text: 4.5:1
  • UI components and icons (WCAG 2.1): at least 3:1 against adjacent colours

How the ratio is calculated

Each colour’s relative luminance is computed from its sRGB values, then the ratio is (lighter + 0.05) ÷ (darker + 0.05). Ratios range from 1:1 (same colour) to 21:1 (black on white). The displayed value is rounded down so a pass is never overstated.

Häufige Fragen

Welches Kontrastverhältnis benötige ich?

Streben Sie beim Fließtext ein Verhältnis von 4,5:1 an, um WCAG AA zu erfüllen, auf das sich die meisten Barrierefreiheitsgesetze beziehen.

Kann ich kurze Hex-Codes eingeben?

Ja. #333 wird als #333333 gelesen.

Überprüft es Verläufe oder Bilder?

Nein. Überprüfen Sie die hellsten und dunkelsten Teile des Hintergrunds separat.

Ist color contrast checker kostenlos?

Ja. color contrast checker ist im Browser kostenlos, ohne Konto.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
