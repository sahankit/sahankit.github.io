Beautify, then read and debug

Paste minified or badly indented code and press Verschönern. The formatter (powered by the open-source js-beautify library) re-indents nested tags, CSS rules and JavaScript blocks, and also formats CSS and scripts embedded in HTML. Choose 2 spaces, 4 spaces or tabs to match your project.

Minify for production

  • HTML — removes comments and indentation whitespace while keeping <pre>, <textarea> and <script> content intact.
  • CSS — strips comments, spaces and the last semicolon in each rule.
  • JSON — removes all whitespace.
  • JavaScript — use a build tool such as Terser or esbuild; safe JS minification needs a full parser.

How to use the HTML formatter

  1. Enter your details. Fill in Language , Indent , Paste your code and Result .
  2. Get the result. Press Beautify . Results update on the page.
  3. Use or copy it. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ändert die Formatierung die Funktionsweise meiner Seite?

Durch die Verschönerung werden nur Leerzeichen geändert. Durch die Minimierung von HTML werden zusätzliche Leerzeichen ausgeblendet, wodurch sich das Rendering fast nie ändert.

Wird mein Code an einen Server gesendet?

Nein. Die Formatierung erfolgt in Ihrem Browser. Es wird nur die Formatierungsbibliothek heruntergeladen.

Kann es defektes HTML reparieren?

Das, was Sie ihm geben, wird eingerückt, fehlende Tags werden jedoch nicht repariert. Bei Bedarf mit dem W3C-Validator validieren.

Ist HTML-Formatierer kostenlos?

Ja. HTML-Formatierer ist im Browser kostenlos, ohne Konto.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
