Über das Wortspiel

Läuft im Browser—keine Anmeldung, keine Installation.

So verwenden Sie das Wortspiel

  1. Geben Sie Ihre Daten ein. Kostenloses Spiel im Wordle-Stil. Erraten Sie das aus fünf Buchstaben bestehende Wort in sechs Versuchen. Grün bedeutet richtige Stelle, gelb bedeutet falsche Stelle.
  2. Holen Sie sich das Ergebnis. Klicken Sie auf „Erraten“. Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist das das offizielle Wordle?

Nein. Es handelt sich um ein originelles Wort-Ratespiel mit ähnlichen Farbregeln, das nur auf dieser Seite gespielt wird.

Wie viele Vermutungen bekomme ich?

Sechs. Jeder Tipp muss aus fünf Buchstaben bestehen. Verwenden Sie „Neues Wort“ für eine weitere zufällige Antwort.

Ist dieses Wordle-Spiel kostenlos?

Ja. Das Wordle-Spiel kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert das Wordle-Spiel auf Mobilgeräten?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
