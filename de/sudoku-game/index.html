About the sudoku game

Play Sudoku in the browser. Fill the grid so each row, column and 3×3 box has digits 1–9 once.

Läuft im Browser—keine Anmeldung, keine Installation.

How to use the sudoku game

  1. Enter your details. Play Sudoku in the browser. Fill the grid so each row, column and 3×3 box has digits 1–9 once.
  2. Get the result. Press Check . Results update on the page.
  3. Use or copy it. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Erzeugt es neue Rätsel?

Neues Puzzle lädt heute das gleiche einfache Starterraster neu. Löschen Sie Ihre Einträge mit „Neues Rätsel“ und versuchen Sie es erneut.

Was macht Check?

Es vergleicht Ihre gefüllten Zellen mit der Lösung und sagt Ihnen, ob etwas falsch oder unvollständig ist.

Ist sudoku game kostenlos?

Ja. sudoku game ist im Browser kostenlos, ohne Konto.
