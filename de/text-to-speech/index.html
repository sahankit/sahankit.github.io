Listen to any text

Paste an article, notes or an email and press Sprich. Choose a voice to change the accent or language—Hindi, English (India, US, UK) and many other voices are available depending on your device. Slow the speed down for learning or speed it up to skim.

Long text is split into sentences so it keeps playing smoothly. Use Pause, Resume and Stop at any time.

Which voices will I see?

The tool uses the Web Speech API, which plays voices installed on your device or provided by your browser. Chrome and Edge include extra online voices; Safari uses Apple system voices; Windows and Android voices can be added in system settings.

How to use the text to speech

  1. Enter your details. Fill in Text zum Vorlesen, Stimme, Geschwindigkeit und Tonhöhe.
  2. Get the result. Press Sprich. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Kann ich die Rede als MP3 herunterladen?

Nicht mit diesem Tool – Browser erlauben das Speichern von Web Speech-Ausgaben nicht. Sie können es mit einer Bildschirm- oder Audioaufzeichnungssoftware aufnehmen.

Unterstützt es Hindi?

Ja, wenn auf Ihrem Gerät eine Hindi-Stimme verfügbar ist. Suchen Sie in der Stimmenliste nach „hi-IN“.

Wird mein Text an einen Server gesendet?

Der Text wird von der Sprachmaschine Ihres Browsers verarbeitet. Einige vom Browser bereitgestellte Online-Stimmen senden möglicherweise Text an den Sprachdienst dieses Browsers.

Is this text to speech free?

Yes. The text to speech is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
