Format or minify JSON safely

Paste API responses or config files. Format adds readable indentation; Minify removes extra whitespace. Invalid JSON shows a parse error instead of silently failing.

How to use the JSON formatter

  1. Enter your details. Fill in JSON .
  2. Get the result. Press Format . Results update on the page.
  3. Use or copy it. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.
