A lightweight monthly estimate from CTC with PF and new-regime tax. For full CTC structure, HRA, old vs new regime, and 87A, use the salary breakup calculator.

So verwenden Sie den Gehaltsschätzer

  1. Geben Sie Ihre Daten ein. Geben Sie CTC pro Jahr (£) und Mitarbeiter-PF (% des Grundbetrags, ca.) ein.
  2. Holen Sie sich das Ergebnis. Klicken Sie auf Kostenvoranschlag. Die Ergebnisse werden auf der Seite aktualisiert und neu berechnet, während Sie Werte bearbeiten.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Wann sollte der Gehaltsschätzer verwendet werden?

Grober monatlicher Bestand von CTC mit einfachem PF-Platzhalter. Kein Lohn- und Gehaltsabrechnungssystem. Verwenden Sie es, wenn Sie eine schnelle Antwort benötigen, ohne Software zu installieren oder ein Konto zu erstellen.

Alles läuft lokal in Ihrem Browser, wo das Tool es unterstützt – nützlich für Formulare, Rechnungen, Studien und schnelle Überprüfungen unterwegs.

Häufige Fragen

How is this different from the salary breakup calculator?

This page is a rough in-hand estimate. The salary breakup calculator models CTC components, HRA, deductions, and tax-optimized structure.

Berechnet es TDS?

It uses the shared FY 2026–27 new-regime tax engine—not a payroll TDS ledger.

Ist dieser Gehaltsrechner kostenlos?

Ja. Der Gehaltsrechner kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert der Gehaltsrechner auf Mobilgeräten?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
