Über die Urlaubsabrechnung

Grobe Urlaubsanrechnung vom Grundgehalt und ungenutzten Urlaubstagen. Illustration zur Gehaltsplanung – keine Gehaltsabrechnungsberatung.

Läuft im Browser—keine Anmeldung, keine Installation.

So nutzen Sie das Urlaubsguthaben

  1. Geben Sie Ihre Daten ein. Geben Sie den monatlichen Grundurlaub (£) und die nicht genutzten Urlaubstage ein.
  2. Holen Sie sich das Ergebnis. Klicken Sie auf Kostenvoranschlag. Die Ergebnisse werden auf der Seite aktualisiert und neu berechnet, während Sie Werte bearbeiten.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist die Urlaubsabrechnung kostenlos?

Ja. Die Urlaubsabrechnung kann kostenlos in Ihrem Browser genutzt werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert die Urlaubsabrechnung auf dem Handy?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
