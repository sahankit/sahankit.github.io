Wie man spielt

Tippen oder klicken Sie auf eine Figur, um die zulässigen Züge anzuzeigen, und tippen Sie dann auf ein hervorgehobenes Feld, um zu ziehen. Weiß zieht zuerst. Verwenden Sie Flipboard, wenn Sie unten Schwarz bevorzugen.

Im vs-Computermodus spielen Sie Weiß. Der Computer spielt eine einfache Heuristik – gut für Gelegenheitsspiele, nicht für Meister.

Wie man das Schachspiel benutzt

  1. Geben Sie Ihre Daten ein. Ausfüllmodus.
  2. Holen Sie sich das Ergebnis. Drücken Sie Neues Spiel. Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Wann sollte man das Schachspiel nutzen?

Spielen Sie Schach in Ihrem Browser. Standardregeln: Rochade, En Passant, Bauernförderung, Schach und Schachmatt. Zwei Spieler auf einem Gerät oder gegen einen einfachen Computer. Verwenden Sie es, wenn Sie eine schnelle Antwort benötigen, ohne Software zu installieren oder ein Konto zu erstellen.

Alles läuft lokal in Ihrem Browser, wo das Tool es unterstützt – nützlich für Formulare, Rechnungen, Studien und schnelle Überprüfungen unterwegs.

Häufige Fragen

Entspricht dies echten Schachregeln?

Ja: Nur legale Züge, Rochade, En Passant, Bauernumwandlung zur Dame, Schach, Schachmatt und Patt.

Können zwei Personen auf einem Telefon spielen?

Wählen Sie im Modusmenü „Zwei Spieler (gleicher Bildschirm)“.

Gibt es eine Uhr oder Bewertung?

Kein Timer oder Elo-Wertung. Es ist ein lässiges Board zum Üben und Spaß.

Ist dieses Schachspiel kostenlos?

Ja. Das Schachspiel kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert das Schachspiel auf Mobilgeräten?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
