Gehaltsrechner

Grober Nettolohn aus Bruttolohn, Bundes- und Landessteuersätzen, optionalem 401(k)-Aufschub und FICA. Kein Ersatz für die Gehaltsabrechnung Ihres Arbeitgebers.

Die FICA verwendet in dieser Schätzung 7,65 % des Bruttobetrags (6,2 % Sozialversicherung + 1,45 % Medicare). Die tatsächliche Quellensteuer richtet sich nach IRS-Tabellen, Vorsteuervorteilen und Lohnobergrenzen.

Über den Gehaltsrechner

Grober Nettolohn aus Bruttolohn, Bundes- und Landessteuersätzen, optionalem 401(k)-Aufschub und FICA. Kein Ersatz für die Gehaltsabrechnung Ihres Arbeitgebers.

Läuft im Browser—keine Anmeldung, keine Installation.

So verwenden Sie den Gehaltsrechner

  1. Geben Sie Ihre Daten ein. Geben Sie Bruttolohn in diesem Zeitraum ($), Bundeseinkommenssteuer (%), Landeseinkommenssteuer (%) und 401(k)-Aufschub (% des Bruttos) ein.
  2. Holen Sie sich das Ergebnis. Klicken Sie auf Nettolohn schätzen. Die Ergebnisse werden auf der Seite aktualisiert und neu berechnet, während Sie Werte bearbeiten.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist das mein genauer Gehaltsscheck?

Nein. Arbeitgeber verwenden IRS-Quellensteuertabellen, Sozialleistungen und staatliche Regeln. Nutzen Sie dies als Baseballstadion.

Was ist FICA?

Sozialversicherungs- und Medicare-Lohnsteuer. Dieses Tool verwendet als einfache Schätzung 7,65 % des Bruttobetrags.

Ist dieser Gehaltsrechner kostenlos?

Ja. Der Gehaltsscheckrechner kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert der Gehaltsrechner auf Mobilgeräten?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.

Wie unterscheidet sich dies von einem generischen Gehaltsrechner-Suchergebnis?

Diese Seite kombiniert den Rechner oder das Dienstprogramm mit kurzen Antworten, FAQs und Links zum nächsten Schritt im selben Arbeitsablauf.
