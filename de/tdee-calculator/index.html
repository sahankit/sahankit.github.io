Über den TDEE-Rechner

Berechnen Sie den gesamten täglichen Energieverbrauch (TDEE) und den BMR mithilfe der Mifflin-St-Jeor-Gleichung. Kostenloser Kalorienrechner.

Läuft im Browser—keine Anmeldung, keine Installation.

So verwenden Sie den TDEE-Rechner

  1. Geben Sie Ihre Daten ein. Geben Sie Geschlecht, Alter (Jahre), Gewicht (kg), Größe (cm) und Aktivität ein.
  2. Holen Sie sich das Ergebnis. Drücken Sie Berechnen . Die Ergebnisse werden auf der Seite aktualisiert und neu berechnet, während Sie Werte bearbeiten.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist dieser TDEE-Rechner kostenlos?

Ja. Der TDEE-Rechner kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert der TDEE-Rechner auf Mobilgeräten?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
