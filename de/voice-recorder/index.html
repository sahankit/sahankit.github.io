    Nehmen Sie mit drei Klicks auf

    Drücken Sie Starten Sie die Aufnahme, Mikrofonzugriff erlauben und sprechen – die Pegelleiste zeigt Ihre Eingangslautstärke an. Halten Sie an und setzen Sie den Vorgang so oft fort, wie Sie möchten, und drücken Sie dann Stopp. Jede Aufnahme wird in einer Liste angezeigt, in der Sie sie wiedergeben, herunterladen oder löschen können.

    Aufnahmen werden im nativen Format Ihres Browsers gespeichert (WebM/Opus in Chrome, Edge und Firefox; M4A in Safari). Wählen Sie Laden Sie WAV herunter für eine unkomprimierte Datei, die in jedem Audio-Editor oder Media-Player geöffnet werden kann.

    Tipps für klare Aufnahmen

    • Wählen Sie aus der Liste ein Headset oder USB-Mikrofon aus, um einen besseren Klang als ein Laptop-Mikrofon zu erzielen.
    • Halten Sie den Pegelbalken größtenteils im grünen Bereich; Rot bedeutet zu laut.
    • Nehmen Sie in einem ruhigen Raum mit Polstermöbeln auf, um Echos zu reduzieren.

    So verwenden Sie den Diktiergerät

    1. Geben Sie Ihre Daten ein. Füllen Sie „Mikrofon“ aus.
    2. Holen Sie sich das Ergebnis. Drücken Sie Aufnahme starten. Aktualisierung der Ergebnisse auf der Seite.
    3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

    Häufige Fragen

    Gibt es eine Frist?

    Kein festes Limit. Lange Aufnahmen verbrauchen mehr Speicher. Laden Sie sie daher herunter, bevor Sie den Tab schließen.

    Kann ich MP3 herunterladen?

    Browser können MP3 nicht nativ kodieren. Laden Sie WAV herunter und konvertieren Sie es, wenn Sie MP3 benötigen.

    Werden Aufnahmen hochgeladen?

    Nein. Sie verbleiben in diesem Browser-Tab und werden verworfen, wenn Sie ihn schließen.

    Ist dieser Diktiergerät kostenlos?

    Ja. Der Diktiergerät kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

    Verlassen meine Daten das Gerät?

    Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
