Über den prozentualen Unterschied

Berechnen Sie den prozentualen Unterschied zwischen zwei Werten (relativ zu ihrem Durchschnitt).

Läuft im Browser—keine Anmeldung, keine Installation.

So verwenden Sie die prozentuale Differenz

  1. Geben Sie Ihre Daten ein. Geben Sie Wert A und Wert B ein.
  2. Holen Sie sich das Ergebnis. Drücken Sie Differenz . Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist dieser prozentuale Unterschied kostenlos?

Ja. Die prozentuale Differenz kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert der prozentuale Unterschied auf Mobilgeräten?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
