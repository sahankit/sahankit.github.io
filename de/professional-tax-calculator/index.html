Über die Gewerbesteuer

Veranschaulichende monatliche Berufssteuer vom Bruttogehalt anhand vereinfachter Tafeln im Karnataka-Stil. Nicht für alle Staaten offiziell.

Läuft im Browser—keine Anmeldung, keine Installation.

So nutzen Sie die Gewerbesteuer

  1. Geben Sie Ihre Daten ein. Geben Sie das monatliche Bruttogehalt (£) ein.
  2. Holen Sie sich das Ergebnis. Drücken Sie PT schätzen. Die Ergebnisse werden auf der Seite aktualisiert und neu berechnet, während Sie Werte bearbeiten.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist dieser Beruf steuerfrei?

Ja. Die Gewerbesteuer kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert die Gewerbesteuer mobil?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
