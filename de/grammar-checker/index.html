Chrome built-in grammar check

Requires desktop Chrome with built-in AI (Gemini Nano) and enough free disk space. Processing happens on your device.

Paste text and run Check grammar to see suggested fixes from the Proofreader API.

How to use the grammar checker

  1. Enter your details. Check grammar, spelling, and punctuation with Chrome’s built-in Proofreader API. Private, on-device when supported.
  2. Get the result. Press Check grammar . Results update on the page.
  3. Use or copy it. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Lädt dies meinen Text hoch?

Nein. Das Proofreader-Modell wird lokal in Chrome ausgeführt, sofern verfügbar.

Ist grammar checker kostenlos?

Ja. grammar checker ist im Browser kostenlos, ohne Konto.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
