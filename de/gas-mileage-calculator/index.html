Über den Benzinverbrauch (MPG)

Berechnen Sie Meilen pro Gallone aus der zurückgelegten Strecke und den verbrauchten Gallonen. Kostenloser MPG-Rechner.

Läuft im Browser—keine Anmeldung, keine Installation.

Verwendung des Benzinverbrauchs (MPG)

  1. Geben Sie Ihre Daten ein. Geben Sie die Entfernung (Meilen) und die verbrauchten Gallonen ein.
  2. Holen Sie sich das Ergebnis. Drücken Sie MPG. Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist dieser Benzinverbrauch (MPG) kostenlos?

Ja. Der Benzinverbrauch (MPG) kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert der Benzinverbrauch (MPG) auf Mobilgeräten?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
