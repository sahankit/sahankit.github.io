How to use the wheel

Type or paste entries into the box, one per line—names for a classroom, prizes for a giveaway, places to eat, or chores. The wheel redraws as you type. Press Spin (or tap the centre) and the pointer at the top picks the winner.

Tick Entfernen Sie den Gewinner nach jeder Drehung to draw several unique winners in a row, like picking teams or raffle prizes. Your list is saved in this browser so it is still there next time.

Is it really random?

Each spin uses your browser’s cryptographic random number generator (crypto.getRandomValues) to choose the spin strength and stopping angle, so every entry has an equal chance. The animation is only for show—the result is decided fairly.

Häufige Fragen

Wie viele Einträge kann ich hinzufügen?

Bis zu 300. Lange Namen werden auf dem Rad gekürzt, aber vollständig angezeigt, wenn sie gewinnen.

Kann ich einer Option eine größere Chance geben?

Ja – fügen Sie es in mehr als einer Zeile hinzu. Jede Linie ist ein gleicher Ausschnitt des Rades.

Kann ich es für ein Giveaway verwenden?

Ja. Fügen Sie die Teilnehmerliste ein, aktivieren Sie „Gewinner entfernen“ und drehen Sie einmal pro Preis. Nehmen Sie die Drehung auf dem Bildschirm auf, um Transparenz zu gewährleisten.

Ist spin the wheel kostenlos?

Ja. spin the wheel ist im Browser kostenlos, ohne Konto.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
