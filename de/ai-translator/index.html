Private Übersetzung in Chrome

Erfordert Desktop-Chrome mit integrierter KI und ausreichend freiem Speicherplatz. Der Text wird auf Ihrem Gerät verarbeitet – nicht auf Sahankit-Servern.

Bei der ersten Verwendung werden für jedes Paar, das Sie übersetzen, Sprachpakete heruntergeladen.

So verwenden Sie den KI-Übersetzer

  1. Geben Sie Ihre Daten ein. Geben Sie Text, Von, Bis und Übersetzung ein.
  2. Holen Sie sich das Ergebnis. Drücken Sie Übersetzen . Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Wann sollte der KI-Übersetzer verwendet werden?

Übersetzen Sie Text mit der Übersetzer-API von Chrome. Private Übersetzung auf dem Gerät – kein Upload auf Sahankit. Verwenden Sie es, wenn Sie eine schnelle Antwort benötigen, ohne Software zu installieren oder ein Konto zu erstellen.

Alles läuft lokal in Ihrem Browser, wo das Tool es unterstützt – nützlich für Formulare, Rechnungen, Studien und schnelle Überprüfungen unterwegs.

Häufige Fragen

Funktioniert das auf Mobilgeräten?

Nein. Die Übersetzer-API von Chrome ist ab Chrome 138 nur noch für den Desktop verfügbar.

Ist dieser KI-Übersetzer kostenlos?

Ja. Der KI-Übersetzer kann kostenlos in Ihrem Browser verwendet werden, es ist kein Konto erforderlich.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert der KI-Übersetzer auf Mobilgeräten?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
