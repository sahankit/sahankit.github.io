Wie der Test Hz misst

Browser zeichnen Animationsrahmen synchron mit Ihrer Anzeige. Der Test misst Hunderte von Frames und ermittelt die mittlere Lücke: etwa 16,7 ms entsprechen 60 Hz, 8,3 ms entsprechen 120 Hz, 6,9 ms entsprechen 144 Hz und 4,2 ms entsprechen 240 Hz. Ausgelassene Frames werden angezeigt, wenn Ihr Gerät nicht mithalten konnte.

Das sich bewegende Quadrat hinterlässt eine Spur aus Bildmarkierungen – bei höheren Bildwiederholraten liegen die Markierungen näher beieinander und die Bewegung sieht flüssiger aus.

Sehen Sie 60 Hz auf einem 144-Hz-Monitor?

  • Stellen Sie die Bildwiederholfrequenz in Windows (Einstellungen → Anzeige → Erweiterte Anzeige) oder macOS (Systemeinstellungen → Anzeigen) ein.
  • Verwenden Sie ein DisplayPort- oder HDMI 2.0+-Kabel, das hohe Bildwiederholraten unterstützt.
  • Schalten Sie den Batteriesparmodus aus. Laptops haben im Akkubetrieb oft eine Obergrenze von 60 Hz.
  • Verschieben Sie das Browserfenster auf den High-Refresh-Bildschirm, wenn Sie mehrere Monitore verwenden.

So verwenden Sie den Bildwiederholratentest

  1. Geben Sie Ihre Daten ein. Überprüfen Sie online die Bildwiederholfrequenz Ihres Bildschirms in Hz. Sehen Sie Bilder pro Sekunde, Bildzeit und ausgelassene Bilder mit einem Bewegungstest. Überprüfen Sie Ihren 120-Hz-, 144-Hz- oder 240-Hz-Monitor.
  2. Holen Sie sich das Ergebnis. Drücken Sie erneut „Messen“. Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist das Ergebnis korrekt?

Ja, für die meisten Setups – es meldet, was der Browser tatsächlich anzeigt. Variable Aktualisierung (G-Sync/FreeSync) und Energiesparen können zu kleinen Schwankungen führen.

Warum steht dort 30 Hz?

Einige Browser drosseln Hintergrundregisterkarten oder Energiesparmodi. Halten Sie die Lasche vorne und schließen Sie Ihren Laptop an.

Funktioniert es auf Telefonen?

Ja. Es erkennt 90- und 120-Hz-Telefonanzeigen, wenn sich das Telefon nicht im Batteriesparmodus befindet.

Ist dieser Bildwiederholfrequenztest kostenlos?

Ja. Der Aktualisierungsratentest kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
