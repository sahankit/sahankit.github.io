Die Regel

Ein Jahr ist ein Schaltjahr, wenn es durch 4 geteilt wird. Wenn es auch durch 100 geteilt wird, ist es kein Schaltjahr, es sei denn, es wird durch 400 geteilt. 2024 und 2028 sind Schaltjahre. 2100 ist es nicht.

So verwenden Sie den Schaltjahr-Checker

  1. Geben Sie Ihre Daten ein. Tragen Sie das Jahr ein.
  2. Holen Sie sich das Ergebnis. Drücken Sie auf Jahr prüfen. Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Wann sollte der Schaltjahrprüfer verwendet werden?

Prüfen Sie, ob ein Jahr ein Schaltjahr ist. Ein Jahr ist ein Schaltjahr, wenn es durch 4 teilbar ist, mit Ausnahme von Jahrhundertjahren, die durch 400 teilbar sein müssen. Verwenden Sie es, wenn Sie eine schnelle Antwort benötigen, ohne Software zu installieren oder ein Konto zu erstellen.

Alles läuft lokal in Ihrem Browser, wo das Tool es unterstützt – nützlich für Formulare, Rechnungen, Studien und schnelle Überprüfungen unterwegs.

Häufige Fragen

War 2000 ein Schaltjahr?

Ja. 2000 dividiert durch 400, daher gilt die Jahrhundertausnahme nicht.

Ist dieser Schaltjahr-Checker kostenlos?

Ja. Der Schaltjahresprüfer kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert der Schaltjahrprüfer auf Mobilgeräten?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
