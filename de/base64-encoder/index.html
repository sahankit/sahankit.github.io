Base64 in APIs and configs

Base64 encodes binary data as ASCII text—common in JSON web tokens, data URLs, and email. This tool handles Unicode text via UTF-8 before encoding.

How to use the base64 encode/decode

  1. Enter your details. Fill in Text .
  2. Get the result. Press Encode . Results update on the page.
  3. Use or copy it. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Warum ist die Dekodierung fehlgeschlagen?

Die Eingabe muss gültiges Base64 sein (Auffüllung und Zeichensatz). Entfernen Sie Leerzeichen oder Zeilenumbrüche, wenn Sie sie aus Protokollen einfügen.

Ist base64 encode/decode kostenlos?

Ja. base64 encode/decode ist im Browser kostenlos, ohne Konto.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
