Dead pixels vs stuck pixels

  • Dead pixel — always black, most visible on the white screen. Usually permanent.
  • Stuck pixel — stays red, green, blue or white; most visible on black or contrasting colours. Sometimes recovers on its own.
  • Backlight bleed — light leaking at the edges on the black screen in a dark room.
  • Dust — a spot that moves or disappears when you wipe the screen isn’t a pixel fault.

How to test a new monitor or laptop

Wipe the screen with a microfibre cloth, set brightness high and start the test. Look at each colour from a normal viewing distance, then up close, scanning section by section. Do it within your return or warranty window—manufacturers’ dead-pixel policies often require a minimum number of faulty pixels.

Häufige Fragen

Funktioniert es auf Telefonen und Fernsehern?

Ja. Öffnen Sie die Seite auf dem Gerät und tippen Sie, um die Farben zu ändern. Smart-TV-Browser ermöglichen möglicherweise keinen echten Vollbildmodus.

Kann ein festsitzender Pixel behoben werden?

Manchmal. Es kann hilfreich sein, die Stelle bei eingeschaltetem Bildschirm sanft mit einem weichen Tuch zu massieren oder den Bildschirm eine Zeit lang ausgeschaltet zu lassen. Tote Pixel können normalerweise nicht repariert werden.

Wie viele tote Pixel sind akzeptabel?

Dies hängt von den Richtlinien des Herstellers ab (häufig basierend auf den Klassen ISO 9241-307). Überprüfen Sie Ihre Garantiebedingungen.

Ist dead pixel test kostenlos?

Ja. dead pixel test ist im Browser kostenlos, ohne Konto.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
