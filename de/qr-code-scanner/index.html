Zwei Möglichkeiten zum Scannen

Kamera: Drücken Sie „Mit Kamera scannen“ und richten Sie die Kamera auf den QR-Code. Bei Telefonen wird die Rückkamera verwendet. Der Code wird automatisch gelesen und die Kamera stoppt.

Bild: Laden Sie einen Screenshot oder ein Foto hoch, das einen QR-Code enthält – praktisch für Codes, die Sie über WhatsApp oder E-Mail erhalten, oder wenn Sie einen Laptop ohne Kamera verwenden.

Sicher scannen

Links werden niemals automatisch geöffnet. Überprüfen Sie die entschlüsselte Adresse, bevor Sie auf tippen Link öffnen, und seien Sie vorsichtig mit QR-Codes, die nach UPI-Zahlungen oder Anmeldedaten fragen.

So verwenden Sie den QR-Code-Scanner

  1. Geben Sie Ihre Daten ein. Wählen Sie eine Datei von Ihrem Gerät aus. Es wird lokal verarbeitet und niemals auf diese Website hochgeladen.
  2. Holen Sie sich das Ergebnis. Drücken Sie Mit Kamera scannen . Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Kann ich einen QR-Code von einem Screenshot scannen?

Ja. Laden Sie den Screenshot mit der Dateiauswahl hoch.

Liest es UPI-QR-Codes?

Ja, es zeigt den Text des UPI-Zahlungslinks an, sodass Sie den Zahlungsempfänger überprüfen können, bevor Sie in Ihrer UPI-App bezahlen.

Ist etwas hochgeladen?

Nein. Die Dekodierung erfolgt in Ihrem Browser.

Ist dieser QR-Code-Scanner kostenlos?

Ja. Der QR-Code-Scanner kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
