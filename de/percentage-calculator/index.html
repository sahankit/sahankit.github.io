Prozentformeln

  • X % von Y = X ÷ 100 × Y. Beispiel: 15 % von 2.400 = 360.
  • X ist der Prozentsatz von Y = X ÷ Y × 100. Beispiel: 45 von 60 Punkten = 75 %.
  • Prozentuale Änderung = (neu − alt) ÷ alt × 100. Beispiel: 800 → 1.000 ist eine Steigerung um 25 %.
  • Fügen Sie einen Prozentsatz hinzu = Wert × (1 + p ÷ 100). Beispiel: 1.200 + 18 % GST = 1.416.

Alltagsgebrauch

Berechnen Sie Prüfungsnoten als Prozentsatz, Rabatte während eines Verkaufs, Gehaltserhöhungen, Preiserhöhungen, GST oder Mehrwertsteuer auf einer Rechnung sowie Gewinn oder Verlust. Alle vier Rechner werden während der Eingabe aktualisiert, sodass Sie Szenarien schnell vergleichen können.

So verwenden Sie den Prozentrechner

  1. Geben Sie Ihre Daten ein. Finden Sie heraus, wie viel Prozent eine Zahl von einer anderen ist, oder wie viel Prozent davon X Prozent eines Wertes sind. Kostenlos online.

  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Wie berechne ich den Prozentsatz der Noten?

Teilen Sie die erhaltenen Noten durch die Gesamtpunktzahl und multiplizieren Sie sie mit 100. Verwenden Sie den zweiten Rechner: Geben Sie Ihre Noten und die Gesamtpunktzahl ein.

Ist eine prozentuale Steigerung dasselbe wie Prozentpunkte?

Nein. Der Anstieg von 10 % auf 12 % bedeutet einen Anstieg um 2 Prozentpunkte, aber einen Anstieg um 20 % im Vergleich zum Ausgangswert.

Wie wird das Ergebnis gerundet?

Die Ergebnisse werden mit bis zu vier Dezimalstellen angezeigt. Runden Sie die Währung auf zwei Dezimalstellen, wenn Sie sie in einer Rechnung verwenden.

Ist dieser Prozentrechner kostenlos?

Ja. Der Prozentrechner kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.
