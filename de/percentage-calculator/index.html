Percentage formulas

  • X% of Y = X ÷ 100 × Y. Example: 15% of 2,400 = 360.
  • X is what % of Y = X ÷ Y × 100. Example: 45 out of 60 marks = 75%.
  • Prozentuale Änderung = (new − old) ÷ old × 100. Example: 800 → 1,000 is a 25% increase.
  • Add a percentage = value × (1 + p ÷ 100). Example: 1,200 + 18% GST = 1,416.

Frequently asked questions

Wie berechne ich den Prozentsatz der Noten?

Teilen Sie die erhaltenen Noten durch die Gesamtpunktzahl und multiplizieren Sie sie mit 100. Verwenden Sie den zweiten Rechner: Geben Sie Ihre Noten und die Gesamtpunktzahl ein.

Ist eine prozentuale Steigerung dasselbe wie Prozentpunkte?

Nein. Der Anstieg von 10 % auf 12 % bedeutet einen Anstieg um 2 Prozentpunkte, aber einen Anstieg um 20 % im Vergleich zum Ausgangswert.

Wie wird das Ergebnis gerundet?

Die Ergebnisse werden mit bis zu vier Dezimalstellen angezeigt. Runden Sie die Währung auf zwei Dezimalstellen, wenn Sie sie in einer Rechnung verwenden.

Is this percentage calculator free?

Yes. The percentage calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
