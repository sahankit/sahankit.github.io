Über die französische Einkommensteuer

Vereinfachte Schätzung der französischen Einkommensteuer auf das steuerpflichtige Jahresnettoeinkommen (ein Steueranteil).

Läuft im Browser—keine Anmeldung, keine Installation.

So verwenden Sie die französische Einkommenssteuer

  1. Geben Sie Ihre Daten ein. Füllen Sie das zu versteuernde Nettoeinkommen (€/Jahr) und die Steueranteile des Haushalts aus.
  2. Holen Sie sich das Ergebnis. Klicken Sie auf „Steuer schätzen“. Die Ergebnisse werden auf der Seite aktualisiert und neu berechnet, während Sie Werte bearbeiten.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist dieses Frankreich einkommenssteuerfrei?

Ja. Die französische Einkommensteuer kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.

Funktioniert die französische Einkommensteuer auf Mobilgeräten?

Ja. Die Seiten reagieren und die Tools werden in mobilen Browsern genauso ausgeführt wie auf dem Desktop.
