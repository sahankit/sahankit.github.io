How to use the regex builder
  1. Enter your details. Fill in Voreingestellte Vorlagen, Escape-Literal einfügen, Regulärer Ausdruck und Beispieltext.
  2. Get the result. Press Testspiele. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.
Frequently asked questions
Wie unterscheidet sich das vom Regex-Tester?
Der Builder konzentriert sich auf die Zusammenstellung von Mustern aus Voreinstellungen und Teilen; Der Tester erfordert nur minimales Einfügen und Ausführen. Beide laufen lokal.
Welche Regex-Variante?
JavaScript RegExp (dasselbe wie in Browsern und Node). Hier werden die Flags g, i, m und s unterstützt.
Is this regex builder free?
Yes. The regex builder is free to use in your browser with no account required.
Does my data leave my device?
For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
