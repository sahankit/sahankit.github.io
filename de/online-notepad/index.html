Productivity hub

Type faster, plan meetings, and run quick everyday calculations.

A simple notepad that remembers

Start typing and your note is saved to this browser’s local storage within a second. Close the tab, come back later, and it is still there. Word and character counts update as you write.

Use Laden Sie .txt herunter to keep a copy on your device, or Alles kopieren to paste into email, chat or a document.

Privacy

Notes never leave your device—there is no account and no server copy. That also means notes do not sync between devices, and clearing your browser data deletes them, so download anything important.

How to use the online notepad

  1. Enter your details. Fill in Your note (saved automatically in this browser) .
  2. Get the result. Press Download .txt . Results update on the page.
  3. Use or copy it. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Wo wird meine Notiz gespeichert?

Nur im lokalen Speicher Ihres Browsers auf diesem Gerät.

Funktioniert es offline?

Sobald die Seite geladen ist, können Sie ohne Verbindung weiter tippen und speichern.

Kann ich es in zwei Tabs öffnen?

Ja. Auf einer Registerkarte vorgenommene Änderungen werden von der anderen übernommen.

Ist online notepad kostenlos?

Ja. online notepad ist im Browser kostenlos, ohne Konto.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
