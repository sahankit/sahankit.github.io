Wählen Sie eine beliebige Farbe aus einem Foto oder Screenshot

Laden Sie ein Bild hoch oder fügen Sie einen Screenshot ein. Bewegen Sie dann den Mauszeiger, um eine vergrößerte Ansicht anzuzeigen, und klicken Sie genau auf das gewünschte Pixel. Sie erhalten die Farbe in HEX (für „CSS“ und Design-Tools), RGB und HSL – klicken Sie auf einen beliebigen Wert, um ihn zu kopieren. Jede von Ihnen ausgewählte Farbe wird in einer Verlaufszeile gespeichert.

In Chrome und Edge können Sie es auch verwenden Wählen Sie von überall auf dem Bildschirm aus um eine Farbe von außerhalb des Browsers zu übernehmen, beispielsweise aus einer anderen App.

Automatische Farbpalette

Das Tool findet außerdem die acht häufigsten Farben in Ihrem Bild – praktisch zum Erstellen einer Markenpalette aus einem Logo, zum Zuordnen einer Website zu einem Foto oder zum Auswählen von Farben. Klicken Sie auf ein Farbfeld, um seinen HEX-Code zu kopieren.

So verwenden Sie den Bildfarbwähler

  1. Geben Sie Ihre Daten ein. Wählen Sie eine Datei von Ihrem Gerät aus. Es wird lokal verarbeitet und niemals auf diese Website hochgeladen.
  2. Holen Sie sich das Ergebnis. Das Ergebnis wird während der Eingabe auf der Seite aktualisiert.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist die Farbe genau?

Ja – es liest das tatsächliche Pixel. Sehr große Bilder werden auf 2000 Pixel skaliert, wodurch benachbarte Pixel leicht überblendet werden können.

Kann ich einen Screenshot einfügen?

Ja. Drücken Sie an einer beliebigen Stelle auf der Seite Strg+V (Befehlstaste+V auf dem Mac).

Ist mein Bild hochgeladen?

Nein. Die Verarbeitung erfolgt nur in Ihrem Browser.

Ist dieser Bildfarbwähler kostenlos?

Ja. Die Bildfarbauswahl kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
