Ziehen Sie ein JPG oder PNG, stellen Sie die JPEG-Qualität mit dem Schieberegler ein und laden Sie eine kleinere Datei herunter. Für eine genaue KB-Grenze (z. B. 20 KB-Signatur oder 50 KB-Prüfungsfoto) verwenden Sie das unten verlinkte Tool zum Reduzieren der Bildgröße in KB.

Komprimieren Sie das Bild unter 50 KB oder 100 KB für Formulare

Regierungs- und Prüfungsportale begrenzen Foto-Uploads häufig auf 20–50 KB unter Beibehaltung der Mindestgröße. Dieser Kompressor reduziert die Dateigröße durch Neukodierung in JPEG in der von Ihnen gewählten Qualität – beginnen Sie bei Porträts bei etwa 0,6–0,75.

Brauchen Sie ein genaues Ziel? Offen Bildgröße in KB reduzieren um 20 KB, 50 KB oder 100 KB mit optionalen Breiten-×-Höhen-Grenzwerten zu erreichen.

Private Komprimierung (kein Cloud-Upload)

Das Bild wird auf eine Leinwand gezeichnet und als JPEG in Ihren Browser exportiert. Es wird nichts an ToolHQ-Server gesendet – geeignet für Ausweisnachweise, Unterschriften und Kursarbeitsscans.

So verwenden Sie den Bildkomprimierer

  1. Geben Sie Ihre Daten ein. Wählen Sie eine Datei von Ihrem Gerät aus. Es wird lokal verarbeitet und niemals auf diese Website hochgeladen.
  2. Holen Sie sich das Ergebnis. Drücken Sie Komprimieren und herunterladen. Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Wie komprimiere ich ein Foto unter 50 KB?

Senken Sie den Qualitätsregler und laden Sie herunter. Wenn es immer noch zu groß ist, verwenden Sie „Bildgröße in KB reduzieren“ mit Zielwert 50 und schneiden Sie zuerst den überschüssigen Hintergrund ab.

PNG-Unterstützung?

Sie können PNG hochladen; Die Ausgabe erfolgt im JPEG-Format für eine kleinere Größe. Die Transparenz wird im JPEG weiß.

Ändert die Komprimierung Breite und Höhe?

Dieses Tool behält die Originalpixel bei und ändert nur die JPEG-Qualität. Um die Größe zu ändern, verwenden Sie den Bild-Resizer oder reduzieren Sie die Bildgröße im KB-Tool.

Ist dieser Bildkompressor kostenlos?

Ja. Der Bildkomprimierer kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
