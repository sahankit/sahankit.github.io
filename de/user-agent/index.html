How to use the user agent

  1. Enter your details. Show your browser user agent string and platform info.
  2. Get the result. The result updates on the page as you type.
  3. Use or copy it. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

When to use the user agent

Show your browser user agent string and platform info. Use it when you need a fast answer without installing software or creating an account.

Everything runs locally in your browser where the tool supports it—useful for forms, invoices, study, and quick checks on the go.

Yes. Pages are responsive and tools run in mobile browsers the same way as on desktop.
