DPI from a photo

DPI is pixels divided by inches. A 1200-pixel-wide image printed 4 inches wide is 300 DPI. The same image printed 10 inches wide is 120 DPI and will look soft up close. The calculator also shows the width in millimetres.

How to use the DPI calculator

  1. Enter your details. Fill in Width (pixels) , Width (inches) and DPI .
  2. Get the result. Press DPI from pixels and inches . Results update on the page.
  3. Use or copy it. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist DPI dasselbe wie PPI?

Für diese Summe ja. PPI ist Pixel pro Zoll auf einem Bildschirm oder einer Datei. DPI ist der passende Druckbegriff. Die Zahl ist in beiden Fällen Pixel ÷ Zoll.

Ist DPI-Rechner kostenlos?

Ja. DPI-Rechner ist im Browser kostenlos, ohne Konto.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
