PDF zu JPG

Konvertieren Sie PDF in JPG-, PNG- oder WebP-Bilder in Ihrem Browser. Wählen Sie eine Qualität von bis zu 300 dpi, wählen Sie Seiten aus und laden Sie sie einzeln oder alle als ZIP herunter. Kein Upload.

So konvertieren Sie PDF in JPG

  • Wählen Sie Ihre PDF-Datei.
  • Wählen Sie JPG für kleine Dateien, PNG für gestochen scharfe Texte und Diagramme oder WebP für das kleinste moderne Format.
  • Wählen Sie 150 dpi für Bildschirme und Freigaben oder 300 dpi für den Druck.
  • Optionally enter pages such as 1-3, 5, then press In Bilder konvertieren.
  • Laden Sie die Seiten einzeln oder alle zusammen als ZIP-Datei herunter.

Privat und schnell

Seiten werden mit Mozillas PDF.js-Engine in Ihrem Browser gerendert, sodass Ihr PDF nie hochgeladen wird. Dadurch ist es sicher für Zertifikate, Notenblätter, Rechnungen und Ausweisdokumente und funktioniert nach dem Laden offline.

So verwenden Sie PDF in JPG

  1. Geben Sie Ihre Daten ein. Wählen Sie eine Datei von Ihrem Gerät aus. Es wird lokal verarbeitet und niemals auf diese Website hochgeladen.
  2. Holen Sie sich das Ergebnis. Klicken Sie auf „In Bilder konvertieren“. Die Ergebnisse werden auf der Seite aktualisiert und neu berechnet, während Sie Werte bearbeiten.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Welche Auflösung soll ich wählen?

150 dpi ist ideal für WhatsApp, E-Mail und Websites. Wählen Sie 300 dpi, wenn Sie die Bilder drucken möchten.

Kann ich nur eine Seite konvertieren?

Ja. Geben Sie die Seitenzahl in das Feld „Seiten“ ein, zum Beispiel 2.

Funktioniert es für gescannte PDFs?

Ja. Jede Seite wird genau so gespeichert, wie sie aussieht, unabhängig davon, ob sie Text oder gescannte Bilder enthält.

Ist die Umwandlung von PDF in JPG kostenlos?

Ja. Das PDF in JPG kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
