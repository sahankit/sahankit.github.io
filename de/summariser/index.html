In Chrome integrierte KI-Zusammenfassung

Dieses Tool ruft die Summarizer-API des Browsers (Gemini Nano) auf. Ihr Text wird nicht an Sahankit gesendet – wir betreiben keinen Zusammenfassungsserver.

Erfordert Desktop-Chrome mit integrierter KI (Gemini Nano) und ausreichend freiem Speicherplatz. Die Verarbeitung erfolgt auf Ihrem Gerät – nicht auf Sahankit-Servern.

Zusammenfassungstypen

Wichtige Punkte – Imbissbuden im Bullet-Stil. TL;DR – ein oder zwei Sätze. Überschrift – Zeile im Titelstil. Teaser – kurzer Werbetext.

So verwenden Sie den KI-Zusammenfassungstool

  1. Fügen Sie Ihren Text ein. Fügen Sie einen Artikel, Notizen oder eine beliebige englische Passage in das Textfeld ein.
  2. Wählen Sie Typ und Länge. Wählen Sie Schlüsselpunkte, TL;DR, Überschrift oder Teaser sowie eine kurze, mittlere oder lange Ausgabe aus.
  3. Klicken Sie auf Zusammenfassen. Chrome lädt bei Bedarf das Modell auf dem Gerät herunter und schreibt dann die Zusammenfassung. Kopieren oder bearbeiten Sie das Ergebnis.

Häufige Fragen

Warum steht dort „nicht verfügbar“?

Verwenden Sie Desktop-Chrome, freien Speicherplatz (~ GB für das Modell) und Flags wie summaryr-api-for-gemini-nano, wenn die API deaktiviert ist.

Ist das dasselbe wie ChatGPT?

Nein. Es wird das On-Device-Modell von Google in Chrome verwendet, kein Cloud-Chat-Konto.

Kann ich PDFs zusammenfassen?

Kopieren Sie zuerst den Text aus der PDF-Datei oder verwenden Sie unser PDF-zu-Word-Tool, um Text zu extrahieren, und fügen Sie ihn dann hier ein.

Ist diese KI-Zusammenfassung kostenlos?

Ja. Die AI-Zusammenfassung kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
