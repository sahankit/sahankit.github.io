Maklerrechner

Estimate delivery-trade profit after a flat brokerage per order and STT. Defaults are ₹20 an order and 0.1% STT. Change both if your broker or the tax rule differs.

Es werden zwei Aufträge berechnet: ein Kauf und ein Verkauf. Umtauschgebühren, GST auf Maklergebühren, Stempelsteuer und SEBI-Gebühren sind nicht enthalten. Eine STT von 0,1 % ist eine übliche Lieferrate – bestätigen Sie die am Handelstag gültige Rate.

What is subtracted

Gross profit is the sell value minus the buy value. The calculator then subtracts brokerage twice, once for the buy order and once for the sell order, and STT on both the buy value and the sell value at the percent you enter.

A real contract note also has exchange transaction charges, GST on brokerage, stamp duty and a SEBI fee. Those differ by exchange and by state. Set brokerage to 0 if your plan does not charge it, and set STT to the rate in force on the day you trade.

How to use the brokerage calculator

  1. Enter your details. Fill in Kaufpreis (£), Verkaufspreis (£), Menge, Provision pro Auftrag (£) und STT bei Kauf und Verkauf (%).
  2. Get the result. Press Berechnen. Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Warum beträgt die Standardmaklergebühr ₹20?

Mehrere Discount-Broker begrenzen eine kostenpflichtige Bestellung auf 20 ₹. Lieferpläne kosten oft 0 ₹. Geben Sie die Nummer von der Preisseite Ihres Brokers ein.

Ist 0,1 % der richtige STT?

0,1 % auf beiden Seiten ist die übliche Kennzahl für die Bereitstellung von Eigenkapital, die immer noch verwendet wird. Intraday-STT wird unterschiedlich berechnet, oft nur auf der Verkaufsseite. Ändern Sie das Feld so, dass es dem Segment entspricht.

Is this brokerage calculator free?

Yes. The brokerage calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
