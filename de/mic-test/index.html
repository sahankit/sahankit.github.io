So testen Sie Ihr Mikrofon

Drücken Sie Testen Sie mein Mikrofon und den Zugriff erlauben. Sprechen Sie normal – der Pegelbalken und die Wellenform sollten sich bewegen. Ein Pegel um –30 bis –10 dBFS beim Sprechen ist gesund; Ständig nahe 0 bedeutet, dass der Eingang zu laut ist und möglicherweise verzerrt ist.

Drücken Sie Nehmen Sie 5 Sekunden auf um einen kurzen Clip aufzunehmen und ihn wiederzugeben, um zu hören, wie Sie bei Anrufen klingen. Echounterdrückung und Rauschunterdrückung sind deaktiviert, sodass Sie das unverfälschte Mikrofon hören.

Mikrofon nicht erkannt?

  • Wählen Sie das richtige Gerät aus der Mikrofonliste aus (Headset oder integriertes Mikrofon).
  • Überprüfen Sie die Stummschaltungsschalter an Headsets und die Eingangslautstärke des Systems.
  • Erlauben Sie dieser Site in der Adressleiste die Mikrofonberechtigung.
  • Schließen Sie andere Apps, die möglicherweise das Mikrofon blockieren, und versuchen Sie es dann erneut.

So verwenden Sie den Mikrofontest

  1. Geben Sie Ihre Daten ein. Füllen Sie „Mikrofon“ aus.
  2. Holen Sie sich das Ergebnis. Drücken Sie „Mein Mikrofon testen“ . Aktualisierung der Ergebnisse auf der Seite.
  3. Verwenden oder kopieren Sie es. Ergebnis kopieren oder herunterladen. Nichts wird gespeichert—neu laden zum Zurücksetzen.

Häufige Fragen

Ist meine Stimme hochgeladen?

Nein. Audio wird nur in Ihrem Browser analysiert und aufgezeichnet und verworfen, wenn Sie die Seite verlassen.

Was bedeutet dBFS?

Dezibel relativ zum Vollausschlag. 0 dBFS ist das lautestmögliche Signal; Leisere Geräusche sind negative Zahlen.

Kann ich AirPods oder Bluetooth-Headsets testen?

Ja. Verbinden Sie sie zuerst und wählen Sie sie dann in der Mikrofonliste aus, nachdem Sie die Erlaubnis erteilt haben.

Ist dieser Mikrofontest kostenlos?

Ja. Der Mikrofontest kann kostenlos in Ihrem Browser verwendet werden, ohne dass ein Konto erforderlich ist.

Verlassen meine Daten das Gerät?

Die meisten Tools verarbeiten Eingaben auf dem Gerät. Ruft ein Tool eine öffentliche API auf (z. B. Domain-Alter), steht das auf der Seite.
