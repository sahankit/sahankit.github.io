WCAG contrast requirements

  • AA normal text: at least 4.5:1
  • AA large text (24px, or 18.66px bold): at least 3:1
  • AAA normal text: at least 7:1; AAA large text: 4.5:1
  • UI components and icons (WCAG 2.1): at least 3:1 against adjacent colours

How the ratio is calculated

Each colour’s relative luminance is computed from its sRGB values, then the ratio is (lighter + 0.05) ÷ (darker + 0.05). Ratios range from 1:1 (same colour) to 21:1 (black on white). The displayed value is rounded down so a pass is never overstated.

How to use the color contrast checker

  1. Enter your details. Fill in Text colour and Background colour.
  2. Get the result. Press Swap colours. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

What contrast ratio do I need?

Aim for 4.5:1 for body text to meet WCAG AA, which most accessibility laws reference.

Can I enter short hex codes?

Yes. #333 is read as #333333.

Does it check gradients or images?

No. Check the lightest and darkest parts of the background separately.

Is this color contrast checker free?

Yes. The color contrast checker is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
