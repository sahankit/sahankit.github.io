Pick any colour from a photo or screenshot

Upload an image or paste a screenshot, then hover to see a magnified view and click the exact pixel you want. You get the colour in HEX (for CSS and design tools), RGB and HSL—click any value to copy it. Every colour you pick is kept in a history row.

In Chrome and Edge you can also use Pick from anywhere on screen to grab a colour from outside the browser, such as another app.

Automatic colour palette

The tool also finds the eight most common distinct colours in your image—handy for building a brand palette from a logo, matching a website to a photo, or choosing paint colours. Click a swatch to copy its HEX code.

How to use the image color picker

  1. Enter your details. Choose a file from your device. It is processed locally and never uploaded to this site.
  2. Get the result. The result updates on the page as you type.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is the colour exact?

Yes—it reads the actual pixel. Very large images are scaled to 2000 px, which can blend neighbouring pixels slightly.

Can I paste a screenshot?

Yes. Press Ctrl+V (Cmd+V on Mac) anywhere on the page.

Is my image uploaded?

No. It is processed only in your browser.

Is this image color picker free?

Yes. The image color picker is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
