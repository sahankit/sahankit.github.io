PAN format reference (10 characters)

Permanent Account Number (PAN) uses five letters, four digits, and one letter: AAAAA9999A. The fourth letter indicates holder type.

PositionRuleExample
1–5Letters A–Z (name)ABCDE
6–9Digits 0–91234
10Letter A–Z (checksum)F
4th charP=Person, C=Company, H=HUF, F=Firm, A=AOP, T=TrustP in EPAPS1234F

영구 계좌 번호 레이아웃

PAN은 문자 5개, 숫자 4개, 문자 1개 등 10자입니다. 이 도구는 형식만 확인합니다. 소득세 부서에 문의하거나 PAN이 활성화되어 있음을 증명하지 않습니다.

  • 4번째 문자(엔티티 유형): P = 개인, C = 회사, H = HUF, F = 회사 등
  • 예: AAAPL1234C — pattern only; do not use real PANs from samples in forms

PAN 형식 확인 사용 방법

  1. 세부 정보를 입력하세요. PAN 을 입력하세요.
  2. 결과를 얻으십시오. 형식 확인을 누릅니다. 페이지의 결과가 업데이트됩니다.
  3. 사용하거나 복사하세요. 결과를 복사하거나 다운로드하세요. 저장되지 않습니다. 새로고침하면 처음부터입니다.

PAN 형식 확인을 사용하는 경우

PAN이 표준 형식 AAAAA9999A와 일치하는지 확인하세요. 공식적인 소득세 확인이 아닙니다. 소프트웨어를 설치하거나 계정을 만들지 않고도 빠른 답변이 필요할 때 사용하세요.

모든 것이 도구가 지원하는 브라우저에서 로컬로 실행되므로 양식, 송장, 연구 및 이동 중에 빠른 확인에 유용합니다.

자주 묻는 질문

KYC에 사용할 수 있나요?

공식 검증 채널을 이용하세요. 이것은 KYC가 아닌 타이핑 도우미입니다.

실제 PAN에서 검증이 실패한 이유는 무엇입니까?

혼동되는 문자(O 대 0, I 대 1)가 있는지 확인하세요. 길이가 정확히 10입니다.

이 PAN 형식 검사는 무료인가요?

예. PAN 형식 확인은 계정이 필요 없이 브라우저에서 무료로 사용할 수 있습니다.

데이터가 이 기기를 떠나나요?

대부분의 도구는 기기에서 입력을 처리합니다. 공개 API를 호출하면(도메인 연식 등) 페이지에 안내합니다.

PAN 형식 확인이 모바일에서 작동하나요?

예. 페이지는 반응형이며 도구는 데스크톱에서와 동일한 방식으로 모바일 브라우저에서 실행됩니다.
