  1. 세부 정보를 입력하세요. 텍스트를 입력합니다.
  2. 결과를 얻으십시오. 인코딩을 누릅니다. 페이지의 결과가 업데이트됩니다.
  3. 사용하거나 복사하세요. 결과를 복사하거나 다운로드하세요. 저장되지 않습니다. 새로고침하면 처음부터입니다.

HTML 엔터티를 사용해야 하는 경우

안전한 마크업 및 스니펫을 위해 HTML 항목을 이스케이프하거나 이스케이프 해제하세요. 소프트웨어를 설치하거나 계정을 만들지 않고도 빠른 답변이 필요할 때 사용하세요.

모든 것이 도구가 지원하는 브라우저에서 로컬로 실행되므로 양식, 송장, 연구 및 이동 중에 빠른 확인에 유용합니다.
