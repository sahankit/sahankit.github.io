Accessible color contrast

WCAG suggests at least 4.5:1 contrast for normal text. Use the ratio readout when picking text and background colors for sites and slides.

How to use the color picker

  1. Enter your details. Pick colors, copy HEX and RGB, and check contrast ratio against a second color.
  2. Get the result. The result updates on the page as you type.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this color picker free?

Yes. The color picker is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
