The daily allowance

Remaining data is the plan size minus what you have used. Divide that by the days still left in the cycle, including today if you have not finished it. If used data divided by days already passed is higher than that allowance, the plan runs out early.

How to use the data usage calculator

  1. Enter your details. Fill in Plan size (GB) , Data already used (GB) , Days in the billing cycle and Days already passed .
  2. Get the result. Press Calculate . Results update on the page and recalculate as you edit values.
  3. Use or copy it. 결과를 복사하거나 다운로드하세요. 저장되지 않습니다. 새로고침하면 처음부터입니다.

자주 묻는 질문

MB와 GB가 혼합되어 있나요?

모든 금액을 GB 단위로 입력하세요. 500MB는 0.5GB입니다. 1GB는 운영자가 해당 정의를 사용하는 경우에만 1024MB입니다. 현재 많은 계획이 1000MB를 사용합니다.

data usage calculator은(는) 무료인가요?

네. data usage calculator은(는) 브라우저에서 무료이며 계정이 필요 없습니다.

데이터가 이 기기를 떠나나요?

대부분의 도구는 기기에서 입력을 처리합니다. 공개 API를 호출하면(도메인 연식 등) 페이지에 안내합니다.
