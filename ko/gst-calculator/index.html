Exclusive vs inclusive GST

If your amount excludes GST, the tool adds tax on top. If the amount already includes GST, it backs out the taxable value and tax component—useful for invoices marked GST-inclusive.

GST 계산기 사용 방법

  1. Enter your details. Fill in 금액(₹) 그리고 GST 세율(%).
  2. Get the result. Press 계산하다. Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

어떤 GST 세율이 지원되나요?

5%, 12%, 18%, 28%에 대한 빠른 사전 설정—인도의 일반적인 슬래브 요금.

신고용인가요?

아니요. 규정 준수를 위해 공식 GST 포털과 CA를 사용하세요. 이것은 빠른 수학 도우미입니다.

Is this GST calculator free?

Yes. The GST calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
