Screen resolution vs. viewport

화면 해상도 is the size of your whole display. Browsers report it in CSS pixels; multiply by the device pixel ratio to get physical pixels. A 4K monitor at 150% scaling, for example, reports 2560 × 1440 CSS pixels with a ratio of 1.5 (3840 × 2160 physical).

The viewport is the visible area of the web page inside the browser window. Web designers use it to test responsive layouts.

Common resolutions

  • 1920 × 1080 (Full HD, 16:9) — the most common desktop size
  • 1366 × 768 — many budget laptops
  • 2560 × 1440 (QHD) and 3840 × 2160 (4K UHD)
  • 390 × 844 and 412 × 915 — common phone viewports in CSS pixels

How to use the screen resolution

  1. Enter your details. Instantly see your screen resolution, physical pixels, browser viewport size, device pixel ratio, colour depth and orientation. Updates live as you resize.

자주 묻는 질문

해상도가 모니터 사양보다 낮은 이유는 무엇입니까?

Windows 또는 macOS의 디스플레이 크기 조정으로 인해 브라우저는 CSS 크기를 더 작게 보고합니다. 물리적 픽셀은 실제 패널 해상도를 나타냅니다.

장치 픽셀 비율이란 무엇입니까?

CSS 픽셀당 물리적 픽셀 수입니다. Retina 및 높은 DPI 화면은 일반적으로 2 또는 3입니다.

데이터가 수집되나요?

아니요. 값은 브라우저에서 읽혀지며 귀하에게만 표시됩니다.

screen resolution은(는) 무료인가요?

네. screen resolution은(는) 브라우저에서 무료이며 계정이 필요 없습니다.

데이터가 이 기기를 떠나나요?
