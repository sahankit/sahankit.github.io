Frequently asked questions

새로운 퍼즐이 생성되나요?

새로운 퍼즐은 오늘과 동일한 쉬운 스타터 그리드를 다시 로드합니다. 새 퍼즐을 사용하여 항목을 지우고 다시 시도하세요.

수표는 무엇을 하나요?

채워진 셀을 솔루션과 비교하여 잘못되었거나 불완전한 것이 있는지 알려줍니다.

Is this sudoku game free?

Yes. The sudoku game is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
