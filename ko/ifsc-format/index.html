IFSC 형식 검사기

IFSC는 은행 문자 4개 + 0 + 지점 문자 6개(예: SBIN0001234) 등 11자입니다. 이 도구는 패턴만 확인하며 분기가 존재하는지 여부는 확인하지 않습니다.

이것은 단지 패턴 (4자리 + 0 + 6자리 영숫자). 지점이 존재하는지 확인하지 않습니다. 공식 확인을 위해 은행이나 RBI를 이용하세요.

IFSC format reference (11 characters)

Indian Financial System Code identifies bank and branch for NEFT/RTGS/IMPS: AAAA0BBBBBB (4 bank + 0 + 6 branch).

SegmentRuleExample
1–4Bank code (letters)HDFC
5Always 00
6–11Branch code (alphanumeric)000123

IFSC 구조(형식만 해당)

인도 금융 시스템 코드는 은행 문자 4개, 0, 지점 문자 6개로 구성된 11자입니다. 이 검사기는 모양만 검증합니다. 실제 지점을 확인하려면 은행이나 RBI 소스를 이용하세요.

  • 예(패턴): HDFC0000123 — HDFC bank, branch segment 000123
  • 일반적인 실수: 10자를 사용하거나 5번째 문자를 바꿉니다(표준 코드에서는 0이어야 함).

IFSC 형식 확인을 사용하는 방법

  1. 세부 정보를 입력하세요. IFSC 코드를 입력하세요.
  2. 결과를 얻으십시오. 형식 확인을 누릅니다. 페이지의 결과가 업데이트됩니다.
  3. 사용하거나 복사하세요. 결과를 복사하거나 다운로드하세요. 저장되지 않습니다. 새로고침하면 처음부터입니다.

IFSC 형식 확인을 사용하는 경우

IFSC 코드가 표준 11자 형식과 일치하는지 확인하세요. RBI로 확인하지 않습니다. 소프트웨어를 설치하거나 계정을 만들지 않고도 빠른 답변이 필요할 때 사용하세요.

모든 것이 도구가 지원하는 브라우저에서 로컬로 실행되므로 양식, 송장, 연구 및 이동 중에 빠른 확인에 유용합니다.

자주 묻는 질문

이렇게 하면 지점이 존재하는지 확인됩니까?

아니요. 코드가 일반적인 패턴과 일치하는지만 확인합니다.

IFSC는 SWIFT와 동일합니까?

아니요. IFSC는 인도 국내 NEFT/RTGS/IMPS용입니다. SWIFT/BIC는 국제 송금에 사용됩니다.

이 IFSC 형식 검사는 무료입니까?

예. IFSC 형식 확인은 계정이 필요 없이 브라우저에서 무료로 사용할 수 있습니다.

데이터가 이 기기를 떠나나요?

대부분의 도구는 기기에서 입력을 처리합니다. 공개 API를 호출하면(도메인 연식 등) 페이지에 안내합니다.

IFSC 형식 확인이 모바일에서 작동합니까?

예. 페이지는 반응형이며 도구는 데스크톱에서와 동일한 방식으로 모바일 브라우저에서 실행됩니다.
