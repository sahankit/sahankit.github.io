백분율에 대해 → CGPA

백분율 표시를 10점 척도(많은 인도 대학에서 사용되는 9.5 규칙)의 CGPA로 변환합니다.

브라우저에서 실행—가입·설치 없음.

백분율 사용 방법 → CGPA

  1. 세부 정보를 입력하세요. 백분율(%)을 입력합니다.
  2. 결과를 얻으십시오. 변환 을 누릅니다. 결과는 페이지에서 업데이트되고 값을 편집하면 다시 계산됩니다.
  3. 사용하거나 복사하세요. 결과를 복사하거나 다운로드하세요. 저장되지 않습니다. 새로고침하면 처음부터입니다.

데이터가 이 기기를 떠나나요?

대부분의 도구는 기기에서 입력을 처리합니다. 공개 API를 호출하면(도메인 연식 등) 페이지에 안내합니다.

백분율 → CGPA가 모바일에서 작동합니까?

예. 페이지는 반응형이며 도구는 데스크톱에서와 동일한 방식으로 모바일 브라우저에서 실행됩니다.
