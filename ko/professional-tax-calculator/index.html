전문세(그림)

단순화된 Karnataka 스타일 슬래브를 사용하여 총 급여에서 월별 전문세를 예시합니다. 모든 주에서 공식적인 것은 아닙니다.

주정부는 서로 다른 슬래브를 설정합니다. 이는 계획을 위해서만 단순화된 Karnataka 스타일의 월별 테이블을 사용합니다.

관련 도구

소득세 계산기

FY 2026-27 · 새로운 체제와 기존 체제.

전문세에 대하여

단순화된 Karnataka 스타일 슬래브를 사용하여 총 급여에서 월별 전문세를 예시합니다. 모든 주에서 공식적인 것은 아닙니다.

브라우저에서 실행—가입·설치 없음.

전문세 사용 방법

  1. 세부 정보를 입력하세요. 총 월급(₹)을 입력합니다.
  2. 결과를 얻으십시오. PT 추정 을 누릅니다. 결과는 페이지에서 업데이트되고 값을 편집하면 다시 계산됩니다.
  3. 사용하거나 복사하세요. 결과를 복사하거나 다운로드하세요. 저장되지 않습니다. 새로고침하면 처음부터입니다.

예. 페이지는 반응형이며 도구는 데스크톱에서와 동일한 방식으로 모바일 브라우저에서 실행됩니다.
