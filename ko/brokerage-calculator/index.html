What is subtracted

Gross profit is the sell value minus the buy value. The calculator then subtracts brokerage twice, once for the buy order and once for the sell order, and STT on both the buy value and the sell value at the percent you enter.

A real contract note also has exchange transaction charges, GST on brokerage, stamp duty and a SEBI fee. Those differ by exchange and by state. Set brokerage to 0 if your plan does not charge it, and set STT to the rate in force on the day you trade.

How to use the brokerage calculator

  1. Enter your details. Fill in 구매 가격(₹), 판매 가격(₹), 수량, 주문당 중개비(₹) 그리고 매수 및 매도 STT(%).
  2. Get the result. Press 계산하다. Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

기본 중개 수수료가 ₹20인 이유는 무엇인가요?

몇몇 할인 중개인은 청구 주문 금액을 ₹20로 제한합니다. 배달 계획은 대개 ₹0입니다. 브로커의 가격 페이지에 표시된 숫자를 입력하세요.

0.1%가 올바른 STT인가요?

양측의 0.1%는 사람들이 여전히 사용하는 일반적인 주식 인도 수치입니다. 일중 STT는 다르게 청구되며, 종종 판매 측에서만 청구됩니다. 세그먼트와 일치하도록 필드를 변경합니다.

Is this brokerage calculator free?

Yes. The brokerage calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
