PDF 압축

브라우저에서 PDF 파일을 압축하세요. 강력함, 권장 또는 무손실 압축을 선택하고 저장된 크기를 확인한 후 다운로드하세요. 귀하의 PDF는 업로드되지 않습니다.

강력함, 권장함, 약함은 각 페이지를 압축된 이미지로 변환하므로 더 이상 텍스트를 선택할 수 없습니다. 텍스트와 링크를 유지하려면 무손실을 선택하세요.

어떤 압축 수준을 선택해야 합니까?

  • 추천 — 대부분의 스캔 문서, 인증서 및 양식에 가장 적합한 균형입니다. 텍스트는 화면과 일반 크기로 인쇄될 때 선명하게 유지됩니다.
  • 강한 — 엄격한 업로드 제한을 위한 가장 작은 파일입니다(예: 정부 및 시험 포털의 경우 100~300KB).
  • 빛 — 작은 글씨나 상세한 이미지가 포함된 문서의 경우 더 높은 품질을 제공합니다.
  • 무손실 — 텍스트 선택 가능, 링크 및 양식 필드를 유지합니다. 파일 구조만 최적화하므로 절감액은 더 적습니다.

작동 방식 및 비공개인 이유

강력함, 권장함, 약함 각 페이지를 다시 그려 새 PDF 내에 압축된 JPEG 이미지로 저장합니다. 이렇게 하면 스캔한 PDF가 크게 줄어들지만 텍스트는 이미지의 일부가 되어 선택하거나 검색할 수 없습니다. 무손실 모드는 압축된 개체 스트림으로 PDF를 다시 작성하고 다른 모든 내용은 변경되지 않은 상태로 유지합니다.

모든 것이 오픈 소스 PDF 라이브러리를 사용하여 장치에서 실행되므로 신분증, 은행 명세서, 증명서와 같은 기밀 문서가 컴퓨터나 휴대폰을 떠나지 않습니다.

압축 사용 방법 PDF

  1. 세부 정보를 입력하세요. 장치에서 파일을 선택하십시오. 로컬에서 처리되며 이 사이트에 업로드되지 않습니다.
  2. 결과를 얻으십시오. 압축 PDF를 누릅니다. 페이지의 결과가 업데이트됩니다.
  3. 사용하거나 복사하세요. 결과를 복사하거나 다운로드하세요. 저장되지 않습니다. 새로고침하면 처음부터입니다.

자주 묻는 질문

PDF를 200KB 미만으로 압축하려면 어떻게 해야 합니까?

강력함을 선택하세요. 그래도 너무 크면 PDF를 분할하여 필요한 페이지만 업로드하거나 스캔 페이지 수를 줄이세요.

내 PDF가 작아지지 않은 이유는 무엇입니까?

대부분 텍스트로 구성된 PDF는 이미 컴팩트합니다. 이미지로 변환하면 더 커질 수 있습니다. 무손실 모드를 사용하거나 원본을 유지하세요.

파일 크기나 페이지 제한이 있나요?

정해진 제한은 없지만 매우 큰 PDF(수백 페이지)에는 휴대폰에서 더 많은 메모리와 시간이 필요합니다.

이 압축 PDF은 무료인가요?

예. 압축 PDF는 계정이 필요 없이 브라우저에서 무료로 사용할 수 있습니다.

데이터가 이 기기를 떠나나요?

대부분의 도구는 기기에서 입력을 처리합니다. 공개 API를 호출하면(도메인 연식 등) 페이지에 안내합니다.
