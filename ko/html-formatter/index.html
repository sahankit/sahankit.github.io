축소되었거나 들여쓰기가 잘못된 코드를 붙여넣고 다음을 누르세요. 아름답게 하다. 포맷터(오픈 소스 js-beautify 라이브러리로 구동)는 중첩된 태그, CSS 규칙 및 JavaScript 블록을 다시 들여쓰기하고 CSS 및 HTML에 포함된 스크립트 형식도 다시 들여쓰기합니다. 프로젝트에 맞게 스페이스 2개, 스페이스 4개 또는 탭을 선택하세요.

생산을 위해 축소

  • HTML — <pre>, <textarea> 및 <script> 내용을 그대로 유지하면서 주석과 들여쓰기 공백을 제거합니다.
  • CSS — 각 규칙의 주석, 공백 및 마지막 세미콜론을 제거합니다.
  • JSON — 모든 공백을 제거합니다.
  • 자바스크립트 — Terser 또는 esbuild와 같은 빌드 도구를 사용합니다. 안전한 JS 축소에는 전체 파서가 필요합니다.

HTML 포맷터 사용 방법

  1. 세부 정보를 입력하세요. 언어, 들여쓰기, 코드 붙여넣기 및 결과를 입력합니다.
  2. 결과를 얻으십시오. 꾸미기를 누르세요. 페이지의 결과가 업데이트됩니다.
  3. 사용하거나 복사하세요. 결과를 복사하거나 다운로드하세요. 저장되지 않습니다. 새로고침하면 처음부터입니다.

자주 묻는 질문

서식을 지정하면 페이지 작동 방식이 변경되나요?

아름답게 하면 공백만 변경됩니다. HTML을 축소하면 렌더링이 거의 변경되지 않는 추가 공백이 축소됩니다.

내 코드가 서버로 전송되나요?

아니요. 포맷은 브라우저에서 이루어집니다. 포맷터 라이브러리만 다운로드됩니다.

깨진 HTML을 고칠 수 있나요?

사용자가 제공한 내용을 들여쓰기하지만 누락된 태그를 복구하지는 않습니다. 필요한 경우 W3C 유효성 검사기로 유효성을 검사합니다.

이 HTML 포맷터는 무료인가요?

예. HTML 포맷터는 계정이 필요 없이 브라우저에서 무료로 사용할 수 있습니다.

데이터가 이 기기를 떠나나요?

대부분의 도구는 기기에서 입력을 처리합니다. 공개 API를 호출하면(도메인 연식 등) 페이지에 안내합니다.
