    How to set an alarm

    Press Test sound first to check your volume. Turn on notifications to also get a pop-up when the alarm rings while you’re in another app.

    • Choose the alarm time and a sound, and add a label if you like.
    • Press Set alarm. The list shows how long until it rings.
    • Leave this tab open. When it rings, choose Snooze (5 minutes) or Stop alarm.

    Make sure it rings

    • Keep the tab open—closing it or the browser cancels alarms.
    • Stop your computer from sleeping, or tick “Keep the screen awake”.
    • Check the device isn’t muted; the alarm plays at system volume.
    • Alarms are saved, so if you reload the page they’re still set—just click the page once to allow sound.

    How to use the online alarm clock

    1. Enter your details. Fill in Alarm time, Sound and Label (optional).
    2. Get the result. Press Set alarm. Results update on the page.
    3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

    Frequently asked questions

    Will the alarm ring if my laptop sleeps?

    No. Browsers can’t wake a sleeping device. Keep it awake and plugged in.

    Can I set more than one alarm?

    Yes, up to 20. Toggle each on or off, or delete it.

    Does the alarm repeat daily?

    Each alarm rings once at its next occurrence; switch it back on to use it again.

    Is this online alarm clock free?

    Yes. The online alarm clock is free to use in your browser with no account required.

    Does my data leave my device?

    For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
