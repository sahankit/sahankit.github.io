What is XIRR?

XIRR (extended internal rate of return) is the annualised return of a series of cash flows that happen on different dates. It is the right way to measure SIP or mutual fund returns, because each instalment is invested for a different length of time. CAGR only works for a single lump-sum investment.

Mathematically, XIRR is the rate r that makes Σ amount ÷ (1 + r)(days ÷ 365) equal to zero—the same definition Excel and Google Sheets use.

How to enter cash flows

  • Each SIP instalment or purchase: the date and a negative amount, e.g. −10000.
  • Each redemption or dividend received: a positive amount.
  • For current holdings, add today’s date with the current value as a positive amount.

Frequently asked questions

Why is XIRR different from absolute return?

Absolute return ignores time. XIRR annualises the gain based on how long each rupee was invested.

Is a negative XIRR possible?

Yes. If the current value is below what you invested, XIRR is negative.

Does it match Excel?

Yes. It uses the same 365-day convention as Excel’s XIRR function.
