How to use the paycheck calculator

  1. Enter your details. Fill in Gross pay this period ($), Federal income tax (%), State income tax (%) and 401(k) deferral (% of gross).
  2. Get the result. Press Estimate net pay. Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this my exact paycheck?

No. Employers use IRS withholding tables, benefits, and state rules. Use this as a ballpark.

What is FICA?

Social Security and Medicare payroll tax. This tool uses 7.65% of gross as a simple estimate.

Is this paycheck calculator free?

Yes. The paycheck calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
