Частые вопросы

Файлы загружены?

Нет. Преобразование происходит локально в вашем браузере.

Могу ли я конвертировать SVG?

Используйте растровые источники (PNG, JPG, WebP, GIF). SVG может работать в некоторых браузерах, но это не гарантируется.

конвертер изображений бесплатен?

Да. конвертер изображений бесплатен в браузере, без аккаунта.

Большинство инструментов обрабатывают данные на вашем устройстве. Если инструмент вызывает публичный API (например возраст домена), это указано на странице.

Does the image converter work on mobile?

Yes. Pages are responsive and tools run in mobile browsers the same way as on desktop.
