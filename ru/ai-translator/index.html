Частые вопросы

Это работает на мобильном телефоне?

Нет. Начиная с версии Chrome 138, API переводчика Chrome предназначен только для настольных компьютеров.

AI-переводчик бесплатен?

Да. AI-переводчик бесплатен в браузере, без аккаунта.

Уходят ли мои данные с устройства?

Большинство инструментов обрабатывают данные на вашем устройстве. Если инструмент вызывает публичный API (например возраст домена), это указано на странице.
