Частный перевод в Chrome

Требуется настольный Chrome со встроенным искусственным интеллектом и достаточно свободного места на диске. Текст обрабатывается на вашем устройстве, а не на серверах Sahankit.

Языковые пакеты загружаются при первом использовании для каждой переводимой пары.

Как использовать AI-переводчик

  1. Введите свои данные. Заполните поля «Текст», «От», «Кому» и «Перевод».
  2. Получите результат. Нажмите «Перевести». Обновление результатов на странице.
  3. Используйте или скопируйте его. Скопируйте или скачайте результат. Ничего не сохраняется—обновите страницу, чтобы начать заново.

Когда использовать AI-переводчик

Переведите текст с помощью переводчика Chrome API. Частный перевод на устройстве — без загрузки в Sahankit. Используйте его, когда вам нужен быстрый ответ без установки программного обеспечения или создания учетной записи.

Все работает локально в вашем браузере, где инструмент это поддерживает, что полезно для форм, счетов, учебы и быстрых проверок на ходу.

Частые вопросы

Это работает на мобильном телефоне?

Нет. Начиная с версии Chrome 138, API переводчика Chrome предназначен только для настольных компьютеров.

Этот AI-переводчик бесплатный?

Да. AI-переводчик можно использовать бесплатно в вашем браузере без необходимости учетной записи.

Уходят ли мои данные с устройства?

Большинство инструментов обрабатывают данные на вашем устройстве. Если инструмент вызывает публичный API (например возраст домена), это указано на странице.

Работает ли AI-переводчик на мобильном телефоне?

Да. Страницы адаптивны, а инструменты работают в мобильных браузерах так же, как и на настольных компьютерах.
