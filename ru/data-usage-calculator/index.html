The daily allowance

Remaining data is the plan size minus what you have used. Divide that by the days still left in the cycle, including today if you have not finished it. If used data divided by days already passed is higher than that allowance, the plan runs out early.

How to use the data usage calculator

  1. Enter your details. Fill in Размер плана (ГБ), Данные уже использованы (ГБ), Дни в платежном цикле и Дни уже прошли.
  2. Get the result. Press Рассчитать. Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

МБ и ГБ смешаны?

Введите каждую сумму в ГБ. 500 МБ — это 0,5 ГБ. 1 ГБ — это 1024 МБ, только если ваш оператор использует это определение; во многих планах теперь используется 1000 МБ.

Is this data usage calculator free?

Yes. The data usage calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
