Exclusive vs inclusive GST

If your amount excludes GST, the tool adds tax on top. If the amount already includes GST, it backs out the taxable value and tax component—useful for invoices marked GST-inclusive.

  • Exclusive ₹1,000 @ 18%: GST ₹180 → total ₹1,180
  • Inclusive ₹1,180 @ 18%: taxable ≈ ₹1,000, GST ≈ ₹180
  • Intra-state B2B: often shown as CGST + SGST (half the rate each)—inter-state uses IGST

Частые вопросы

Какие ставки GST поддерживаются?

Быстрые настройки для 5%, 12%, 18% и 28% — распространенные ставки для плит в Индии.

How do I remove GST from an inclusive price?

Open the GST inclusive calculator or reverse GST calculator for the same rate presets.

Это для подачи декларации?

Нет. Для обеспечения соответствия используйте официальные порталы GST и свой центр сертификации; это быстрый помощник по математике.

Does this validate my GSTIN?

No. Use the GSTIN format checker for pattern validation only.

Калькулятор налога на товары и услуги бесплатен?

Да. Калькулятор налога на товары и услуги бесплатен в браузере, без аккаунта.

Уходят ли мои данные с устройства?

Большинство инструментов обрабатывают данные на вашем устройстве. Если инструмент вызывает публичный API (например возраст домена), это указано на странице.
