Как использовать escape-код SQL

  1. Введите свои данные. Экранируйте одинарные кавычки для строковых литералов SQL.
  2. Получите результат. Нажмите Escape. Обновление результатов на странице.
  3. Используйте или скопируйте его. Скопируйте или скачайте результат. Ничего не сохраняется—обновите страницу, чтобы начать заново.

Когда использовать escape-код SQL

Экранируйте одинарные кавычки для строковых литералов SQL. Используйте его, когда вам нужен быстрый ответ без установки программного обеспечения или создания учетной записи.

Все работает локально в вашем браузере, где инструмент это поддерживает, что полезно для форм, счетов, учебы и быстрых проверок на ходу.

Частые вопросы

Этот выход из SQL бесплатен?

Да. Экран SQL можно использовать бесплатно в вашем браузере без необходимости учетной записи.

Уходят ли мои данные с устройства?

Большинство инструментов обрабатывают данные на вашем устройстве. Если инструмент вызывает публичный API (например возраст домена), это указано на странице.

Работает ли escape-код SQL на мобильных устройствах?

Да. Страницы адаптивны, а инструменты работают в мобильных браузерах так же, как и на настольных компьютерах.
