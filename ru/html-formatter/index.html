Beautify, then read and debug

Paste minified or badly indented code and press Украсить. The formatter (powered by the open-source js-beautify library) re-indents nested tags, CSS rules and JavaScript blocks, and also formats CSS and scripts embedded in HTML. Choose 2 spaces, 4 spaces or tabs to match your project.

Minify for production

  • HTML — removes comments and indentation whitespace while keeping <pre>, <textarea> and <script> content intact.
  • CSS — strips comments, spaces and the last semicolon in each rule.
  • JSON — removes all whitespace.
  • JavaScript — use a build tool such as Terser or esbuild; safe JS minification needs a full parser.

How to use the HTML formatter

  1. Enter your details. Fill in Language , Indent , Paste your code and Result .
  2. Get the result. Press Beautify . Results update on the page.
  3. Use or copy it. Скопируйте или скачайте результат. Ничего не сохраняется—обновите страницу, чтобы начать заново.

Частые вопросы

Влияет ли форматирование на работу моей страницы?

Украшение только меняет пробелы. При минимизации HTML сжимаются лишние пробелы, что почти никогда не влияет на рендеринг.

Мой код отправляется на сервер?

Нет. Форматирование происходит в вашем браузере; загружается только библиотека форматтера.

Может ли он исправить сломанный HTML?

Он изменяет отступы того, что вы ему даете, но не исправляет отсутствующие теги. При необходимости подтвердите с помощью валидатора W3C.

HTML-форматер бесплатен?

Да. HTML-форматер бесплатен в браузере, без аккаунта.

Уходят ли мои данные с устройства?

Большинство инструментов обрабатывают данные на вашем устройстве. Если инструмент вызывает публичный API (например возраст домена), это указано на странице.
