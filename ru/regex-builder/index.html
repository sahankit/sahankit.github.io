Частые вопросы
Чем это отличается от тестера регулярных выражений?
Конструктор ориентирован на сборку выкроек из пресетов и деталей; тестер требует минимальной установки и запуска. Оба работают локально.
Какой вариант регулярного выражения?
JavaScript RegExp (так же, как в браузерах и Node). Здесь поддерживаются флаги g, i, m и s.
regex builder бесплатен?
Да. regex builder бесплатен в браузере, без аккаунта.
Уходят ли мои данные с устройства?
Большинство инструментов обрабатывают данные на вашем устройстве. Если инструмент вызывает публичный API (например возраст домена), это указано на странице.
Does the regex builder work on mobile?
Yes. Pages are responsive and tools run in mobile browsers the same way as on desktop.
