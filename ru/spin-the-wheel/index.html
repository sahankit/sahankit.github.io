Как пользоваться колесом

Введите или вставьте записи в поле, по одной в каждой строке: названия классов, призы для розыгрышей, места, где можно поесть, или дела по дому. Колесо перерисовывается по мере ввода. Пресса Вращение (или коснитесь центра), и указатель вверху выберет победителя.

Отметьте Удалять победителя после каждого вращения чтобы разыграть несколько уникальных победителей подряд, например, выбрать команду или разыграть призы. Ваш список сохраняется в этом браузере, поэтому в следующий раз он будет там же.

Это действительно случайно?

При каждом вращении используется криптографический генератор случайных чисел вашего браузера (crypto.getRandomValues), чтобы выбрать силу вращения и угол остановки, поэтому каждый вход имеет равные шансы. Анимация предназначена только для галочки — результат решается справедливо.

Частые вопросы

Сколько записей я могу добавить?

До 300. Длинные имена сокращаются на колесе, но при выигрыше отображаются полностью.

Могу ли я дать одному варианту больший шанс?

Да, добавьте его более чем в одну строку. Каждая линия представляет собой один равный срез колеса.

Могу ли я использовать его для подарка?

Да. Вставьте список участников, включите удаление победителя и выполните вращение один раз для каждого приза. Запишите вращение на экране для прозрачности.

Это бесплатное вращение колеса?

Да. Вращение колеса можно использовать бесплатно в вашем браузере без необходимости учетной записи.

Уходят ли мои данные с устройства?

Большинство инструментов обрабатывают данные на вашем устройстве. Если инструмент вызывает публичный API (например возраст домена), это указано на странице.
