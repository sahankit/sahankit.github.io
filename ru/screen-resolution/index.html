Screen resolution vs. viewport

Разрешение экрана is the size of your whole display. Browsers report it in CSS pixels; multiply by the device pixel ratio to get physical pixels. A 4K monitor at 150% scaling, for example, reports 2560 × 1440 CSS pixels with a ratio of 1.5 (3840 × 2160 physical).

The viewport is the visible area of the web page inside the browser window. Web designers use it to test responsive layouts.

Common resolutions

  • 1920 × 1080 (Full HD, 16:9) — the most common desktop size
  • 1366 × 768 — many budget laptops
  • 2560 × 1440 (QHD) and 3840 × 2160 (4K UHD)
  • 390 × 844 and 412 × 915 — common phone viewports in CSS pixels

Частые вопросы

Почему мое разрешение ниже, чем указано в характеристиках моего монитора?

Масштабирование дисплея в Windows или macOS заставляет браузер сообщать об меньшем размере CSS. Физические пиксели показывают реальное разрешение панели.

Что такое соотношение пикселей устройства?

Количество физических пикселей на пиксель CSS. Экранов Retina и экранов с высоким разрешением обычно 2 или 3.

Собираются ли какие-либо данные?

Нет. Значения считываются из вашего браузера и отображаются только вам.

screen resolution бесплатен?

Да. screen resolution бесплатен в браузере, без аккаунта.

Уходят ли мои данные с устройства?

Большинство инструментов обрабатывают данные на вашем устройстве. Если инструмент вызывает публичный API (например возраст домена), это указано на странице.
