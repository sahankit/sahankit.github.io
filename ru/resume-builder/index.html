Частые вопросы

Хранится ли мое резюме в Интернете?

Нет. Содержимое остается в вашем браузере, пока вы не загрузите PDF-файл.

Могу ли я использовать это для ATS?

Макет представляет собой простой текст и заголовки — хорошая основа для ATS. Избегайте таблиц и графиков для строгих анализаторов.

resume builder бесплатен?

Да. resume builder бесплатен в браузере, без аккаунта.

Уходят ли мои данные с устройства?

Большинство инструментов обрабатывают данные на вашем устройстве. Если инструмент вызывает публичный API (например возраст домена), это указано на странице.

Does the resume builder work on mobile?

Yes. Pages are responsive and tools run in mobile browsers the same way as on desktop.
