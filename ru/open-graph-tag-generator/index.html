How to use the open Graph generator

  1. Enter your details. Fill in ох: название, ог: описание, ог: URL и og: URL изображения.
  2. Get the result. Press Генерировать теги. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this open Graph generator free?

Yes. The open Graph generator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
