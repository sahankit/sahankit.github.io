How to use the CSV → JSON

  1. Enter your details. Fill in CSV (строка заголовка).
  2. Get the result. Press Конвертировать. Results update on the page and recalculate as you edit values.

Frequently asked questions

Is this CSV → JSON free?

Yes. The CSV → JSON is free to use in your browser with no account required.

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
