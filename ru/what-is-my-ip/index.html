Поиск общедоступного IP-адреса

Запускается в вашем браузере на Sahankit — без регистрации. Иллюстрация только там, где это указано; не медицинские, налоговые или инвестиционные консультации.

Мы вызываем ipify.org из вашего браузера; Sahankit не регистрирует ваш IP-адрес на бэкэнде.

Как использовать «Какой у меня IP»

  1. Введите свои данные. Посмотрите свой общедоступный IPv4-адрес в браузере. Использует IP-адрес только для чтения API — без установки.
  2. Получите результат. Нажмите «Показать мой общедоступный IP-адрес». Обновление результатов на странице.
  3. Используйте или скопируйте его. Скопируйте или скачайте результат. Ничего не сохраняется—обновите страницу, чтобы начать заново.

Когда использовать «Какой у меня IP»

Посмотрите свой общедоступный IPv4-адрес в браузере. Использует IP-адрес только для чтения API — без установки. Используйте его, когда вам нужен быстрый ответ без установки программного обеспечения или создания учетной записи.

Все работает локально в вашем браузере, где инструмент это поддерживает, что полезно для форм, счетов, учебы и быстрых проверок на ходу.

Частые вопросы

Это что, мой IP бесплатный?

Да. «Какой у меня IP» можно использовать бесплатно в вашем браузере без необходимости учетной записи.

Уходят ли мои данные с устройства?

Большинство инструментов обрабатывают данные на вашем устройстве. Если инструмент вызывает публичный API (например возраст домена), это указано на странице.

Работает ли вопрос «Какой у меня IP» на мобильном телефоне?

Да. Страницы адаптивны, а инструменты работают в мобильных браузерах так же, как и на настольных компьютерах.
