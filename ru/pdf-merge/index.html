How to use the merge PDF

  1. Enter your details. Choose a file from your device. It is processed locally and never uploaded to this site.
  2. Get the result. Press Merge & download . Results update on the page.
  3. Use or copy it. Скопируйте или скачайте результат. Ничего не сохраняется—обновите страницу, чтобы начать заново.

When to use the merge PDF

Combine multiple PDF files into one in the browser. Private merge with pdf-lib. Use it when you need a fast answer without installing software or creating an account.

Everything runs locally in your browser where the tool supports it—useful for forms, invoices, study, and quick checks on the go.

Частые вопросы

Есть ли ограничение на количество файлов?

Ограничено памятью вашего браузера — на мобильных устройствах количество пакетов должно быть скромным.

merge PDF бесплатен?

Да. merge PDF бесплатен в браузере, без аккаунта.

Уходят ли мои данные с устройства?

Большинство инструментов обрабатывают данные на вашем устройстве. Если инструмент вызывает публичный API (например возраст домена), это указано на странице.

Does the merge PDF work on mobile?

Yes. Pages are responsive and tools run in mobile browsers the same way as on desktop.
