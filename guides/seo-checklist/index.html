Simple SEO checklist

  1. Unique title and description on every page
  2. Submit sitemap in Google Search Console
  3. Fast, mobile-friendly pages
  4. Internal links between related tools
  5. Useful content, not duplicate spam

Example project: Y-Chat on GitHub Pages with sitemap and guides.

SEO basics for static sites

Static sites on GitHub Pages can rank when each URL has a unique title, helpful body copy, internal links, and a submitted sitemap. Avoid duplicate thin pages and keyword stuffing.

  • One clear H1 per page matching user intent.
  • Meta description ~150 characters summarizing the page.
  • Link related tools together in prose sections.
  • Submit sitemap.xml in Google Search Console and Bing Webmaster.

Frequently asked questions

How long until Google indexes a new tool page?

Often days to a few weeks for new sites. Request indexing in Search Console after publishing.
