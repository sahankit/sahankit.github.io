Frequently asked questions
How is this different from the regex tester?
The builder focuses on assembling patterns from presets and parts; the tester is minimal paste-and-run. Both run locally.
Which flavor of regex?
JavaScript RegExp (same as in browsers and Node). Flags g, i, m, and s are supported here.
Is this regex builder free?
Yes. The regex builder is free to use in your browser with no account required.
Does my data leave my device?
For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
