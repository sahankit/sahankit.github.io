How to convert an image to text

Choose an image or paste a screenshot with Ctrl+V (Cmd+V on Mac), select the language of the text, and press Extract text. The first run downloads the OCR engine and language data (a few MB); later runs are faster.

When it finishes, copy the text or download it as a .txt file. Recognition uses Tesseract, the open-source OCR engine, running entirely in your browser.

Tips for accurate OCR

  • Use a sharp, well-lit image with dark text on a light background.
  • Crop to just the text area and straighten tilted photos first.
  • Pick the correct language—use English + Hindi for mixed documents.
  • Printed text works best; handwriting accuracy is limited.

How to use the image to text (OCR)

Frequently asked questions

Are my images uploaded?

No. The OCR engine is downloaded to your browser and the image is processed on your device.

Can it read Hindi?

Yes. Choose Hindi or English + Hindi from the language list.

Can it convert a PDF?

Take a screenshot of the page or export it as an image first, then use this tool. For text-based PDFs, the PDF to Word tool is faster.

Is this image to text (OCR) free?

Yes. The image to text (OCR) is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
