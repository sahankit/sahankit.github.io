কিভাবে একটি ইমেজকে টেক্সটে রূপান্তর করা যায়

একটি চিত্র চয়ন করুন বা Ctrl+V (Mac এ Cmd+V) দিয়ে একটি স্ক্রিনশট পেস্ট করুন, পাঠ্যের ভাষা নির্বাচন করুন এবং টিপুন পাঠ্য নিষ্কাশন করুন. প্রথম রান OCR ইঞ্জিন এবং ভাষা ডেটা (কয়েক এমবি) ডাউনলোড করে; পরে রান দ্রুত হয়।

এটি শেষ হলে, পাঠ্যটি অনুলিপি করুন বা এটি একটি .txt ফাইল হিসাবে ডাউনলোড করুন৷ স্বীকৃতি Tesseract ব্যবহার করে, ওপেন-সোর্স OCR ইঞ্জিন, সম্পূর্ণরূপে আপনার ব্রাউজারে চলছে।

সঠিক ওসিআরের জন্য টিপস

  • একটি হালকা পটভূমিতে গাঢ় পাঠ্য সহ একটি ধারালো, ভাল-আলো ছবি ব্যবহার করুন৷
  • শুধু পাঠ্য এলাকায় ক্রপ করুন এবং প্রথমে কাত হওয়া ফটোগুলি সোজা করুন।
  • সঠিক ভাষা চয়ন করুন - মিশ্র নথির জন্য ইংরেজি + হিন্দি ব্যবহার করুন।
  • মুদ্রিত পাঠ্য সবচেয়ে ভাল কাজ করে; হাতের লেখার নির্ভুলতা সীমিত।

কিভাবে ইমেজ টেক্সট ব্যবহার করবেন (OCR)

  1. আপনার বিবরণ লিখুন. আপনার ডিভাইস থেকে একটি ফাইল চয়ন করুন. এটি স্থানীয়ভাবে প্রক্রিয়া করা হয় এবং এই সাইটে আপলোড করা হয় না।
  2. ফলাফল পান। এক্সট্রাক্ট টেক্সট টিপুন। পৃষ্ঠায় ফলাফল আপডেট.
  3. এটি ব্যবহার করুন বা অনুলিপি করুন। আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

সাধারণ প্রশ্ন

আমার ছবি আপলোড করা হয়?

না। OCR ইঞ্জিন আপনার ব্রাউজারে ডাউনলোড করা হয়েছে এবং ছবিটি আপনার ডিভাইসে প্রসেস করা হয়েছে।

এটা কি হিন্দি পড়তে পারে?

হ্যাঁ। ভাষা তালিকা থেকে হিন্দি বা ইংরেজি + হিন্দি বেছে নিন।

এটি একটি PDF রূপান্তর করতে পারেন?

পৃষ্ঠাটির একটি স্ক্রিনশট নিন বা এটিকে প্রথমে একটি চিত্র হিসাবে রপ্তানি করুন, তারপর এই সরঞ্জামটি ব্যবহার করুন৷ টেক্সট-ভিত্তিক পিডিএফের জন্য, পিডিএফ টু ওয়ার্ড টুল দ্রুততর।

এই ইমেজ টু টেক্সট (OCR) বিনামূল্যে?

হ্যাঁ। ইমেজ টু টেক্সট (OCR) কোনো অ্যাকাউন্টের প্রয়োজন ছাড়াই আপনার ব্রাউজারে বিনামূল্যে ব্যবহার করা যায়।

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।
