How to convert an image to text

Choose an image or paste a screenshot with Ctrl+V (Cmd+V on Mac), select the language of the text, and press পাঠ্য নিষ্কাশন করুন. The first run downloads the OCR engine and language data (a few MB); later runs are faster.

When it finishes, copy the text or download it as a .txt file. Recognition uses Tesseract, the open-source OCR engine, running entirely in your browser.

Tips for accurate OCR

  • Use a sharp, well-lit image with dark text on a light background.
  • Crop to just the text area and straighten tilted photos first.
  • Pick the correct language—use English + Hindi for mixed documents.
  • Printed text works best; handwriting accuracy is limited.

How to use the image to text (OCR)

  1. Enter your details. Choose a file from your device. It is processed locally and never uploaded to this site.
  2. Get the result. Press Extract text . Results update on the page.
  3. Use or copy it. আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

সাধারণ প্রশ্ন

আমার ছবি আপলোড করা হয়?

না। OCR ইঞ্জিন আপনার ব্রাউজারে ডাউনলোড করা হয়েছে এবং ছবিটি আপনার ডিভাইসে প্রসেস করা হয়েছে।

এটা কি হিন্দি পড়তে পারে?

হ্যাঁ। ভাষা তালিকা থেকে হিন্দি বা ইংরেজি + হিন্দি বেছে নিন।

এটি একটি PDF রূপান্তর করতে পারেন?

পৃষ্ঠাটির একটি স্ক্রিনশট নিন বা এটিকে প্রথমে একটি চিত্র হিসাবে রপ্তানি করুন, তারপর এই সরঞ্জামটি ব্যবহার করুন৷ টেক্সট-ভিত্তিক পিডিএফের জন্য, পিডিএফ টু ওয়ার্ড টুল দ্রুততর।

image to text (OCR) কি ফ্রি?

হ্যাঁ। image to text (OCR) ব্রাউজারে ফ্রি, অ্যাকাউন্ট লাগে না।

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।
