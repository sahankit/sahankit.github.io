মাইক পরীক্ষা

লেভেল মিটার দিয়ে মাইক্রোফোন চেক করুন।

কিভাবে আপনার স্ক্রীন রেকর্ড করবেন

  • ট্যাব/সিস্টেম অডিও এবং আপনার মাইক্রোফোন অন্তর্ভুক্ত করতে হবে কিনা টিক দিন।
  • চাপুন রেকর্ডিং শুরু করুন এবং সম্পূর্ণ পর্দা, একটি উইন্ডো বা একটি ব্রাউজার ট্যাব চয়ন করুন৷
  • আপনি যা ক্যাপচার করতে চান তা করুন—একটি টিউটোরিয়াল, উপস্থাপনা, বাগ রিপোর্ট বা গেম ক্লিপ।
  • চাপুন রেকর্ডিং বন্ধ করুন (বা ব্রাউজার বারে "শেয়ার করা বন্ধ করুন"), ভিডিওটির পূর্বরূপ দেখুন এবং এটি ডাউনলোড করুন৷

অডিও, বিন্যাস এবং সমর্থন

ক্রোম এবং এজ একটি ব্রাউজার ট্যাব থেকে এবং পুরো সিস্টেম থেকে উইন্ডোজে অডিও ক্যাপচার করতে পারে; macOS শুধুমাত্র ট্যাব অডিও অনুমোদন করে। বর্ণনা করতে আপনার মাইক্রোফোন যোগ করুন। ভিডিওগুলি WebM (বা MP4 যেখানে ব্রাউজার এটি সমর্থন করে) হিসাবে সংরক্ষিত হয়, যা Chrome, Edge, Firefox এবং VLC-তে চলে এবং সরাসরি YouTube-এ আপলোড হয়৷

স্ক্রিন রেকর্ডিংয়ের জন্য একটি ডেস্কটপ ব্রাউজার প্রয়োজন—মোবাইল ব্রাউজারগুলি ওয়েবসাইটগুলিকে স্ক্রীন ক্যাপচার করার অনুমতি দেয় না।

কিভাবে স্ক্রিন রেকর্ডার ব্যবহার করবেন

  1. আপনার বিবরণ লিখুন. সিস্টেম অডিও এবং মাইক্রোফোন দিয়ে অনলাইনে আপনার স্ক্রীন, একটি উইন্ডো বা একটি ব্রাউজার ট্যাব রেকর্ড করুন৷ কোন ডাউনলোড নেই, কোন ওয়াটারমার্ক নেই, কোন সময়সীমা নেই। ভিডিওটি আপনার ডিভাইসে সেভ করুন।
  2. ফলাফল পান। রেকর্ডিং শুরু করুন টিপুন। পৃষ্ঠায় ফলাফল আপডেট.
  3. এটি ব্যবহার করুন বা অনুলিপি করুন। আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

সাধারণ প্রশ্ন

একটি জলছাপ বা সময় সীমা আছে?

না। রেকর্ডিং দৈর্ঘ্য শুধুমাত্র আপনার ডিভাইসের মেমরি দ্বারা সীমাবদ্ধ।

কোন শব্দ নেই কেন?

ব্রাউজারের শেয়ারিং ডায়ালগে আপনি "শেয়ার ট্যাব অডিও" বা "শেয়ার সিস্টেম অডিও" টিক চিহ্ন দিয়েছেন তা নিশ্চিত করুন। macOS শুধুমাত্র ট্যাব অডিও সমর্থন করে।

আমার রেকর্ডিং আপলোড করা হয়?

না। আপনি ডাউনলোড না করা পর্যন্ত ভিডিওটি আপনার ব্রাউজারে তৈরি এবং সংরক্ষণ করা হবে।

এই পর্দা রেকর্ডার বিনামূল্যে?

হ্যাঁ। স্ক্রিন রেকর্ডারটি আপনার ব্রাউজারে ব্যবহার করার জন্য বিনামূল্যে কোন অ্যাকাউন্টের প্রয়োজন নেই৷

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।
