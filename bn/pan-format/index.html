Permanent Account Number layout

PANs are 10 characters: five letters, four digits, one letter. This tool checks format only. It does not query the Income Tax Department or prove a PAN is active.

  • 4th character (entity type): P = individual, C = company, H = HUF, F = firm, etc.
  • Example: AAAPL1234C — pattern only; do not use real PANs from samples in forms

How to use the PAN format check

  1. Enter your details. Fill in PAN .
  2. Get the result. Press Check format . Results update on the page.
  3. Use or copy it. আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

When to use the PAN format check

Check if a PAN matches the standard format AAAAA9999A. Not an official Income Tax verification. Use it when you need a fast answer without installing software or creating an account.

Everything runs locally in your browser where the tool supports it—useful for forms, invoices, study, and quick checks on the go.

Why did validation fail on a real PAN?

Check for confusing characters (O vs 0, I vs 1) and that length is exactly 10.

প্যান ফরম্যাট চেক করুন কি ফ্রি?
