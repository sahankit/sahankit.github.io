PAN format reference (10 characters)

Permanent Account Number (PAN) uses five letters, four digits, and one letter: AAAAA9999A. The fourth letter indicates holder type.

PositionRuleExample
1–5Letters A–Z (name)ABCDE
6–9Digits 0–91234
10Letter A–Z (checksum)F
4th charP=Person, C=Company, H=HUF, F=Firm, A=AOP, T=TrustP in EPAPS1234F

স্থায়ী অ্যাকাউন্ট নম্বর লেআউট

প্যানগুলি হল 10টি অক্ষর: পাঁচটি অক্ষর, চারটি সংখ্যা, একটি অক্ষর৷ এই টুলটি শুধুমাত্র ফরম্যাট চেক করে। এটি আয়কর বিভাগকে জিজ্ঞাসাবাদ করে না বা একটি প্যান সক্রিয় রয়েছে তা প্রমাণ করে না।

  • ৪র্থ অক্ষর (সত্তার ধরন): P = ব্যক্তি, C = কোম্পানি, H = HUF, F = দৃঢ়, ইত্যাদি।
  • উদাহরণ: AAAPL1234C — pattern only; do not use real PANs from samples in forms

কিভাবে PAN ফরম্যাট চেক ব্যবহার করবেন

  1. আপনার বিবরণ লিখুন. PAN পূরণ করুন।
  2. ফলাফল পান। চেক ফরম্যাট টিপুন। পৃষ্ঠায় ফলাফল আপডেট.
  3. এটি ব্যবহার করুন বা অনুলিপি করুন। আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

কখন প্যান ফরম্যাট ব্যবহার করবেন তা পরীক্ষা করুন

একটি প্যান স্ট্যান্ডার্ড ফর্ম্যাট AAAAA9999A এর সাথে মেলে কিনা তা পরীক্ষা করুন৷ একটি অফিসিয়াল আয়কর যাচাইকরণ নয়। সফ্টওয়্যার ইনস্টল না করে বা অ্যাকাউন্ট তৈরি না করেই আপনার দ্রুত উত্তরের প্রয়োজন হলে এটি ব্যবহার করুন।

সবকিছুই আপনার ব্রাউজারে স্থানীয়ভাবে চলে যেখানে টুলটি এটিকে সমর্থন করে — ফর্ম, ইনভয়েস, অধ্যয়ন এবং যেতে যেতে দ্রুত চেকের জন্য দরকারী।

সাধারণ প্রশ্ন

আমি কি এটি কেওয়াইসির জন্য ব্যবহার করতে পারি?

অফিসিয়াল ভেরিফিকেশন চ্যানেল ব্যবহার করুন। এটি একটি টাইপিং সহায়ক, KYC নয়।

কেন একটি আসল PAN-এ বৈধতা ব্যর্থ হয়েছে?

বিভ্রান্তিকর অক্ষর পরীক্ষা করুন (O বনাম 0, আমি বনাম 1) এবং সেই দৈর্ঘ্য ঠিক 10।

এই প্যান ফরম্যাট কি বিনামূল্যে পরীক্ষা করা হয়?

হ্যাঁ। PAN ফরম্যাট চেক আপনার ব্রাউজারে বিনামূল্যে ব্যবহার করা যায় কোনো অ্যাকাউন্টের প্রয়োজন নেই।

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।

প্যান ফরম্যাট চেক কি মোবাইলে কাজ করে?

হ্যাঁ। পৃষ্ঠাগুলি প্রতিক্রিয়াশীল এবং সরঞ্জামগুলি মোবাইল ব্রাউজারে ডেস্কটপের মতোই চলে৷

জেনেরিক প্যান ফরম্যাট চেক সার্চ ফলাফল থেকে এটি কীভাবে আলাদা?

এই পৃষ্ঠাটি ক্যালকুলেটর বা ইউটিলিটিকে সংক্ষিপ্ত উত্তর, প্রায়শই জিজ্ঞাসিত প্রশ্নাবলী এবং একই কর্মপ্রবাহের পরবর্তী ধাপের লিঙ্কগুলির সাথে একত্রিত করে।
