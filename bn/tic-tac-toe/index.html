About the tic tac toe

Free tic tac toe game against a simple computer opponent. You are X and move first.

How to use the tic tac toe

  1. Enter your details. Free tic tac toe game against a simple computer opponent. You are X and move first.
  2. Get the result. Press New game . Results update on the page.
  3. Use or copy it. আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

সাধারণ প্রশ্ন

আমি কি প্রথম খেলি?

হ্যাঁ। আপনি X এবং কম্পিউটার O বাজানোর আগে 3×3 বোর্ডে একটি বর্গক্ষেত্রে ট্যাপ করুন৷

কম্পিউটার কি অপরাজেয়?

এটা অবিলম্বে জয় ব্লক করে কিন্তু নিখুঁত নয়। ভালো চাল দিয়ে জিততে পারেন।

tic tac toe কি ফ্রি?

হ্যাঁ। tic tac toe ব্রাউজারে ফ্রি, অ্যাকাউন্ট লাগে না।

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।
