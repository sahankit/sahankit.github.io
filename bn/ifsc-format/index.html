IFSC ফরম্যাট পরীক্ষক

একটি IFSC হল 11টি অক্ষর: 4টি ব্যাঙ্ক অক্ষর + 0 + 6 শাখা অক্ষর (যেমন SBIN0001234)। এই টুলটি শুধুমাত্র প্যাটার্ন চেক করে - শাখাটি বিদ্যমান কিনা তা নয়।

এই শুধুমাত্র চেক প্যাটার্ন (4 অক্ষর + 0 + 6 আলফানিউমেরিক)। এটি শাখার অস্তিত্ব নিশ্চিত করে না। অফিসিয়াল ভেরিফিকেশনের জন্য আপনার ব্যাঙ্ক বা আরবিআই ব্যবহার করুন।

IFSC format reference (11 characters)

Indian Financial System Code identifies bank and branch for NEFT/RTGS/IMPS: AAAA0BBBBBB (4 bank + 0 + 6 branch).

SegmentRuleExample
1–4Bank code (letters)HDFC
5Always 00
6–11Branch code (alphanumeric)000123

IFSC কাঠামো (শুধুমাত্র বিন্যাস)

ইন্ডিয়ান ফাইন্যান্সিয়াল সিস্টেম কোড 11টি অক্ষর: চারটি ব্যাঙ্ক অক্ষর, একটি শূন্য, তারপর ছয়টি শাখা অক্ষর। এই চেকার শুধুমাত্র আকৃতি যাচাই করে। একটি লাইভ শাখা নিশ্চিত করতে, আপনার ব্যাঙ্ক বা আরবিআই সূত্র ব্যবহার করুন।

  • উদাহরণ (প্যাটার্ন): HDFC0000123 — HDFC bank, branch segment 000123
  • সাধারণ ভুল: 10টি অক্ষর ব্যবহার করা বা 5ম অক্ষর অদলবদল করা (স্ট্যান্ডার্ড কোডে 0 হতে হবে)

কিভাবে IFSC ফরম্যাট চেক ব্যবহার করবেন

  1. আপনার বিবরণ লিখুন. IFSC কোড পূরণ করুন।
  2. ফলাফল পান। চেক ফরম্যাট টিপুন। পৃষ্ঠায় ফলাফল আপডেট.
  3. এটি ব্যবহার করুন বা অনুলিপি করুন। আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

IFSC ফরম্যাট চেক কখন ব্যবহার করবেন

একটি IFSC কোড মান 11-অক্ষরের বিন্যাসের সাথে মেলে কিনা তা পরীক্ষা করুন। RBI এর সাথে যাচাই করে না। সফ্টওয়্যার ইনস্টল না করে বা অ্যাকাউন্ট তৈরি না করেই আপনার দ্রুত উত্তরের প্রয়োজন হলে এটি ব্যবহার করুন।

সবকিছুই আপনার ব্রাউজারে স্থানীয়ভাবে চলে যেখানে টুলটি এটিকে সমর্থন করে — ফর্ম, ইনভয়েস, অধ্যয়ন এবং যেতে যেতে দ্রুত চেকের জন্য দরকারী।

সাধারণ প্রশ্ন

এটি কি শাখার অস্তিত্ব যাচাই করে?

না। এটি শুধুমাত্র চেক করে যে কোডটি স্বাভাবিক প্যাটার্নের সাথে মেলে।

IFSC কি SWIFT এর মতই?

না। IFSC হল ভারতে ঘরোয়া NEFT/RTGS/IMPS-এর জন্য। SWIFT/BIC আন্তর্জাতিক তারের জন্য ব্যবহৃত হয়।

এই IFSC ফরম্যাট চেক বিনামূল্যে?

হ্যাঁ। IFSC ফরম্যাট চেক আপনার ব্রাউজারে বিনামূল্যে ব্যবহার করা যায় কোনো অ্যাকাউন্টের প্রয়োজন নেই।

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।

IFSC ফরম্যাট চেক কি মোবাইলে কাজ করে?

হ্যাঁ। পৃষ্ঠাগুলি প্রতিক্রিয়াশীল এবং সরঞ্জামগুলি মোবাইল ব্রাউজারে ডেস্কটপের মতোই চলে৷

জেনেরিক IFSC ফরম্যাট চেক অনুসন্ধান ফলাফল থেকে এটি কীভাবে আলাদা?

এই পৃষ্ঠাটি ক্যালকুলেটর বা ইউটিলিটিকে সংক্ষিপ্ত উত্তর, প্রায়শই জিজ্ঞাসিত প্রশ্নাবলী এবং একই কর্মপ্রবাহের পরবর্তী ধাপের লিঙ্কগুলির সাথে একত্রিত করে।
