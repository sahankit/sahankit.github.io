About the simon game

Watch the colour pattern and repeat it. Each round adds one more step in this Simon memory game.

ব্রাউজারে চলে—সাইন আপ বা ইনস্টল নেই।

How to use the simon game

  1. Enter your details. Watch the colour pattern and repeat it. Each round adds one more step in this Simon memory game.
  2. Get the result. Press Start . Results update on the page.
  3. Use or copy it. আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

simon game কি ফ্রি?

হ্যাঁ। simon game ব্রাউজারে ফ্রি, অ্যাকাউন্ট লাগে না।

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।
