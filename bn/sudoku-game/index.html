How to use the sudoku game

  1. Enter your details. Play Sudoku in the browser. Fill the grid so each row, column and 3×3 box has digits 1–9 once.
  2. Get the result. Press Check . Results update on the page.
  3. Use or copy it. আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

সাধারণ প্রশ্ন

এটা কি নতুন ধাঁধা তৈরি করে?

নতুন ধাঁধা আজ একই সহজ স্টার্টার গ্রিড পুনরায় লোড করে। আপনার এন্ট্রি পরিষ্কার করতে নতুন ধাঁধা ব্যবহার করুন এবং আবার চেষ্টা করুন।

চেক কি করে?

এটি আপনার ভরা কক্ষগুলিকে সমাধানের সাথে তুলনা করে এবং কিছু ভুল বা অসম্পূর্ণ কিনা তা আপনাকে বলে৷

sudoku game কি ফ্রি?

হ্যাঁ। sudoku game ব্রাউজারে ফ্রি, অ্যাকাউন্ট লাগে না।

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।
