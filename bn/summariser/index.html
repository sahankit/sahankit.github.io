Chrome built-in AI summariser

This tool calls the browser’s Summarizer API (Gemini Nano). Your text is not sent to Sahankit—we do not run a summarization server.

Requires desktop Chrome with built-in AI (Gemini Nano) and enough free disk space. Processing happens on your device—not on Sahankit servers.

Summary types

Key points — bullet-style takeaways. TL;DR — one or two sentences. Headline — title-style line. Teaser — short promo blurb.

How to use the AI summariser

  1. Paste your text. টেক্সট বক্সে একটি নিবন্ধ, নোট বা যেকোনো ইংরেজি প্যাসেজ যোগ করুন।
  2. Choose type and length. মূল পয়েন্ট, TL;DR, শিরোনাম, বা টিজার এবং সংক্ষিপ্ত, মাঝারি বা দীর্ঘ আউটপুট বেছে নিন।
  3. Click Summarise. প্রয়োজন হলে Chrome অন-ডিভাইস মডেল ডাউনলোড করে, তারপর সারাংশ লিখে। ফলাফল কপি বা সম্পাদনা করুন.

সাধারণ প্রশ্ন

কেন এটা অনুপলব্ধ বলেন?

এপিআই বন্ধ থাকলে ডেস্কটপ ক্রোম, ফ্রি ডিস্ক স্পেস (মডেলের জন্য ~ GB), এবং ফ্ল্যাগ যেমন summarizer-api-for-gemini-nano ব্যবহার করুন।

এটি কি ChatGPT এর মতো?

না। এটি Chrome-এ Google-এর অন-ডিভাইস মডেল ব্যবহার করে, ক্লাউড চ্যাট অ্যাকাউন্ট নয়।

আমি কি PDF সংক্ষিপ্ত করতে পারি?

প্রথমে PDF থেকে টেক্সট কপি করুন, অথবা টেক্সট এক্সট্রাক্ট করতে আমাদের PDF to Word টুল ব্যবহার করুন, তারপর এখানে পেস্ট করুন।

এআই সারাংশকার কি ফ্রি?

হ্যাঁ। এআই সারাংশকার ব্রাউজারে ফ্রি, অ্যাকাউন্ট লাগে না।

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।
