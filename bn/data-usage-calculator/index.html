The daily allowance

Remaining data is the plan size minus what you have used. Divide that by the days still left in the cycle, including today if you have not finished it. If used data divided by days already passed is higher than that allowance, the plan runs out early.

How to use the data usage calculator

  1. Enter your details. Fill in পরিকল্পনা আকার (GB), ইতিমধ্যে ব্যবহৃত ডেটা (GB), বিলিং চক্রের দিন এবং ইতিমধ্যে দিন কেটে গেছে.
  2. Get the result. Press হিসাব করুন. Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

এমবি এবং জিবি মিশ্রিত হয়?

জিবি-তে প্রতিটি পরিমাণ লিখুন। 500 MB হল 0.5 GB। 1 GB হল 1024 MB শুধুমাত্র যদি আপনার অপারেটর সেই সংজ্ঞা ব্যবহার করে; অনেক প্ল্যান এখন 1000 MB ব্যবহার করে।

Is this data usage calculator free?

Yes. The data usage calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
