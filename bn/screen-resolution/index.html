Screen resolution vs. viewport

স্ক্রীন রেজোলিউশন is the size of your whole display. Browsers report it in CSS pixels; multiply by the device pixel ratio to get physical pixels. A 4K monitor at 150% scaling, for example, reports 2560 × 1440 CSS pixels with a ratio of 1.5 (3840 × 2160 physical).

The viewport is the visible area of the web page inside the browser window. Web designers use it to test responsive layouts.

Common resolutions

  • 1920 × 1080 (Full HD, 16:9) — the most common desktop size
  • 1366 × 768 — many budget laptops
  • 2560 × 1440 (QHD) and 3840 × 2160 (4K UHD)
  • 390 × 844 and 412 × 915 — common phone viewports in CSS pixels

সাধারণ প্রশ্ন

কেন আমার রেজোলিউশন আমার মনিটরের স্পেকের চেয়ে কম?

Windows বা macOS-এ ডিসপ্লে স্কেলিং ব্রাউজার রিপোর্টকে একটি ছোট CSS সাইজ করে। শারীরিক পিক্সেল বাস্তব প্যানেল রেজোলিউশন দেখায়.

ডিভাইস পিক্সেল অনুপাত কি?

CSS পিক্সেল প্রতি ফিজিক্যাল পিক্সেলের সংখ্যা। রেটিনা এবং হাই-ডিপিআই স্ক্রিন সাধারণত 2 বা 3 হয়।

কোন তথ্য সংগ্রহ করা হয়?

না। মান আপনার ব্রাউজার থেকে পড়া হয় এবং শুধুমাত্র আপনাকে দেখানো হয়।

screen resolution কি ফ্রি?

হ্যাঁ। screen resolution ব্রাউজারে ফ্রি, অ্যাকাউন্ট লাগে না।

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।
