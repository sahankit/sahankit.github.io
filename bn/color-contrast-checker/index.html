WCAG contrast requirements

  • AA normal text: at least 4.5:1
  • AA large text (24px, or 18.66px bold): at least 3:1
  • AAA normal text: at least 7:1; AAA large text: 4.5:1
  • UI components and icons (WCAG 2.1): at least 3:1 against adjacent colours

How the ratio is calculated

Each colour’s relative luminance is computed from its sRGB values, then the ratio is (lighter + 0.05) ÷ (darker + 0.05). Ratios range from 1:1 (same colour) to 21:1 (black on white). The displayed value is rounded down so a pass is never overstated.

How to use the color contrast checker

  1. Enter your details. Fill in Text colour and Background colour .
  2. Get the result. Press Swap colours . Results update on the page.
  3. Use or copy it. আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

সাধারণ প্রশ্ন

আমার কি বৈসাদৃশ্য অনুপাত প্রয়োজন?

WCAG AA এর সাথে মিলিত হওয়ার জন্য বডি টেক্সটের জন্য 4.5:1 লক্ষ্য করুন, যা বেশিরভাগ অ্যাক্সেসিবিলিটি আইন উল্লেখ করে।

আমি কি ছোট হেক্স কোড লিখতে পারি?

হ্যাঁ। #333 #333333 হিসাবে পড়া হয়েছে।

এটা গ্রেডিয়েন্ট বা ইমেজ চেক করে?

না। ব্যাকগ্রাউন্ডের হালকা এবং অন্ধকার অংশ আলাদাভাবে পরীক্ষা করুন।

color contrast checker কি ফ্রি?

হ্যাঁ। color contrast checker ব্রাউজারে ফ্রি, অ্যাকাউন্ট লাগে না।

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।
