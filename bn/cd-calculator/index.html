About the CD calculator

Calculate certificate of deposit maturity value from deposit, APY, and term in months or years.

Runs in your browser—no signup and no install.

How to use the CD calculator

  1. Enter your details. Fill in জমা ($), APY (%) এবং মেয়াদ (মাস).
  2. Get the result. Press হিসাব করুন. Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this CD calculator free?

Yes. The CD calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
