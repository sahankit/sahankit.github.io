সাধারণ প্রশ্ন
কিভাবে এটি regex পরীক্ষক থেকে ভিন্ন?
নির্মাতা প্রিসেট এবং অংশ থেকে নিদর্শন একত্রিত করার উপর দৃষ্টি নিবদ্ধ করে; পরীক্ষক হল ন্যূনতম পেস্ট-এন্ড-রান। উভয়ই স্থানীয়ভাবে চলে।
Regex এর কোন স্বাদ?
JavaScript RegExp (ব্রাউজার এবং নোডের মতোই)। পতাকা g, i, m, এবং s এখানে সমর্থিত।
regex builder কি ফ্রি?
হ্যাঁ। regex builder ব্রাউজারে ফ্রি, অ্যাকাউন্ট লাগে না।
আমার ডেটা কি ডিভাইস ছেড়ে যায়?
এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।
