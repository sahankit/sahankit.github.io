Beautify, then read and debug

Paste minified or badly indented code and press সুন্দর করা. The formatter (powered by the open-source js-beautify library) re-indents nested tags, CSS rules and JavaScript blocks, and also formats CSS and scripts embedded in HTML. Choose 2 spaces, 4 spaces or tabs to match your project.

Minify for production

  • HTML — removes comments and indentation whitespace while keeping <pre>, <textarea> and <script> content intact.
  • CSS — strips comments, spaces and the last semicolon in each rule.
  • JSON — removes all whitespace.
  • JavaScript — use a build tool such as Terser or esbuild; safe JS minification needs a full parser.

How to use the HTML formatter

  1. Enter your details. Fill in Language , Indent , Paste your code and Result .
  2. Get the result. Press Beautify . Results update on the page.
  3. Use or copy it. আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

সাধারণ প্রশ্ন

আমার পৃষ্ঠা কীভাবে কাজ করে তা কি বিন্যাস পরিবর্তন করে?

সৌন্দর্যায়ন শুধুমাত্র হোয়াইটস্পেস পরিবর্তন করে। এইচটিএমএল ছোট করার ফলে অতিরিক্ত স্পেস ভেঙে যায়, যা প্রায় কখনই রেন্ডারিং পরিবর্তন করে না।

আমার কোড একটি সার্ভারে পাঠানো হয়?

না। আপনার ব্রাউজারে ফরম্যাটিং হয়; শুধুমাত্র ফরম্যাটার লাইব্রেরি ডাউনলোড করা হয়।

এটা ভাঙা HTML ঠিক করতে পারে?

আপনি যা দেন তা ইন্ডেন্ট করে কিন্তু অনুপস্থিত ট্যাগ মেরামত করে না। প্রয়োজনে W3C যাচাইকারীর সাথে যাচাই করুন।

এইচটিএমএল ফরম্যাটার কি ফ্রি?

হ্যাঁ। এইচটিএমএল ফরম্যাটার ব্রাউজারে ফ্রি, অ্যাকাউন্ট লাগে না।

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।
