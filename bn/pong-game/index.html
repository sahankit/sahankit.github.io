পং খেলা সম্পর্কে

আপনার ব্রাউজারে ক্লাসিক পং। মাউস বা তীর কী দিয়ে আপনার প্যাডেল সরান এবং কম্পিউটার বীট.

ব্রাউজারে চলে—সাইন আপ বা ইনস্টল নেই।

পং গেমটি কীভাবে ব্যবহার করবেন

  1. আপনার বিবরণ লিখুন. আপনার ব্রাউজারে ক্লাসিক পং। মাউস বা তীর কী দিয়ে আপনার প্যাডেল সরান এবং কম্পিউটার বীট.
  2. ফলাফল পান। রিসেট স্কোর টিপুন। পৃষ্ঠায় ফলাফল আপডেট.
  3. এটি ব্যবহার করুন বা অনুলিপি করুন। আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

সাধারণ প্রশ্ন

আমি কিভাবে প্যাডেল সরাতে পারি?

ক্যানভাসের উপর মাউস সরান বা টাচ স্ক্রিনে আপনার আঙুল টেনে আনুন।

গতি কি বৃদ্ধি পায়?

প্রতিটি প্যাডেল আঘাত করার পরে বলের গতি কিছুটা বাড়ে।

এই পং খেলা বিনামূল্যে?

হ্যাঁ। পং গেমটি আপনার ব্রাউজারে বিনামূল্যে ব্যবহার করার জন্য কোনো অ্যাকাউন্টের প্রয়োজন নেই।

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।

পং গেম কি মোবাইলে কাজ করে?

হ্যাঁ। পৃষ্ঠাগুলি প্রতিক্রিয়াশীল এবং সরঞ্জামগুলি মোবাইল ব্রাউজারে ডেস্কটপের মতোই চলে৷

এটি কীভাবে একটি সাধারণ পং গেম অনুসন্ধান ফলাফল থেকে আলাদা?

এই পৃষ্ঠাটি ক্যালকুলেটর বা ইউটিলিটিকে সংক্ষিপ্ত উত্তর, প্রায়শই জিজ্ঞাসিত প্রশ্নাবলী এবং একই কর্মপ্রবাহের পরবর্তী ধাপের লিঙ্কগুলির সাথে একত্রিত করে।
