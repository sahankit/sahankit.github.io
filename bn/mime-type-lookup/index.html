How to use the MIME type lookup

  1. Enter your details. Fill in File name or extension .
  2. Get the result. Press Lookup . Results update on the page.
  3. Use or copy it. আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

MIME type lookup কি ফ্রি?

হ্যাঁ। MIME type lookup ব্রাউজারে ফ্রি, অ্যাকাউন্ট লাগে না।

আমার ডেটা কি ডিভাইস ছেড়ে যায়?
