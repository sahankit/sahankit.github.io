নমুনা আকার সম্পর্কে

ত্রুটির মার্জিন সহ অনুপাতের জন্য সমীক্ষার নমুনার আকার অনুমান করুন। বিনামূল্যে পরিসংখ্যান নমুনা ক্যালকুলেটর.

ব্রাউজারে চলে—সাইন আপ বা ইনস্টল নেই।

নমুনার আকার কিভাবে ব্যবহার করবেন

  1. আপনার বিবরণ লিখুন. প্রত্যাশিত অনুপাত পূরণ করুন (0-1, অনিশ্চিত হলে 0.5 ব্যবহার করুন), ত্রুটির মার্জিন (যেমন 0.05 = ±5%) এবং Z-স্কোর (1.96 = 95%)।
  2. ফলাফল পান। নমুনা আকার n টিপুন। পৃষ্ঠায় ফলাফল আপডেট.
  3. এটি ব্যবহার করুন বা অনুলিপি করুন। আউটপুট কপি বা ডাউনলোড করুন। কিছু সেভ হয় না—রিফ্রেশ করে আবার শুরু করুন।

সাধারণ প্রশ্ন

এই নমুনা আকার বিনামূল্যে?

হ্যাঁ। নমুনা আকার কোন অ্যাকাউন্ট প্রয়োজন ছাড়া আপনার ব্রাউজারে ব্যবহার করার জন্য বিনামূল্যে.

আমার ডেটা কি ডিভাইস ছেড়ে যায়?

এই সাইটের বেশিরভাগ টুল আপনার ডিভাইসেই ইনপুট প্রক্রিয়া করে। কোনো টুল পাবলিক API কল করলে (যেমন ডোমেইন বয়স) পেজে লেখা থাকে।

নমুনা আকার মোবাইলে কাজ করে?

হ্যাঁ। পৃষ্ঠাগুলি প্রতিক্রিয়াশীল এবং সরঞ্জামগুলি মোবাইল ব্রাউজারে ডেস্কটপের মতোই চলে৷

এটি কিভাবে একটি জেনেরিক নমুনা আকার অনুসন্ধান ফলাফল থেকে ভিন্ন?

এই পৃষ্ঠাটি ক্যালকুলেটর বা ইউটিলিটিকে সংক্ষিপ্ত উত্তর, প্রায়শই জিজ্ঞাসিত প্রশ্নাবলী এবং একই কর্মপ্রবাহের পরবর্তী ধাপের লিঙ্কগুলির সাথে একত্রিত করে।
