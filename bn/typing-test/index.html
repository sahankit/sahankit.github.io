How to use the typing speed test

  1. Enter your details. Fill in এখানে টাইপ করুন.

Frequently asked questions

একটি ভাল WPM কি?

40-60 WPM দৈনন্দিন ব্যবহারের জন্য সাধারণ; 70+ অফিসের কাজের জন্য দ্রুত।

Is this typing speed test free?

Yes. The typing speed test is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
