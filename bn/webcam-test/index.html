How to test your webcam

Press আমার ওয়েবক্যাম পরীক্ষা করুন and allow camera access when your browser asks. If the preview appears, your camera works. The tool then shows the resolution it is streaming (for example 1280 × 720 or 1920 × 1080), the measured frame rate, aspect ratio and megapixels.

Have more than one camera? Pick it from the list. Use স্ন্যাপশট নিন to save a still image to check focus and lighting before a video call.

Webcam not working? Try this

  • Allow camera permission for this site from the camera icon in the address bar.
  • Close Zoom, Teams, Meet or other apps that may be using the camera.
  • On Windows, check Settings → Privacy → Camera. On macOS, check System Settings → Privacy & Security → Camera.
  • Check for a physical privacy shutter or a camera function key on laptops.

How to use the webcam test

  1. Enter your details. Fill in ক্যামেরা.
  2. Get the result. Press আমার ওয়েবক্যাম পরীক্ষা করুন. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

আমার ভিডিও রেকর্ড বা আপলোড করা হয়?

না। ভিডিওটি আপনার ডিভাইসে থাকবে। স্ন্যাপশটগুলি স্থানীয়ভাবে তৈরি করা হয় এবং আপনি সেগুলি ডাউনলোড করলেই কেবল সংরক্ষিত হয়৷

রেজোলিউশন আমার ক্যামেরার স্পেকের চেয়ে কম কেন?

ব্রাউজার পারফরম্যান্সের জন্য একটি নিম্ন মোড বেছে নিতে পারে এবং কিছু USB পোর্ট বা অ্যাপ এটিকে সীমিত করে। দেখানো মান আপনার ক্যামেরা আসলে কি স্ট্রিমিং হয়.

এটা কি ফোনে কাজ করে?

হ্যাঁ, আধুনিক মোবাইল ব্রাউজারে। সামনে এবং পিছনের ক্যামেরাগুলির মধ্যে স্যুইচ করতে ক্যামেরা তালিকা ব্যবহার করুন।

Is this webcam test free?

Yes. The webcam test is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
