How to find broken keys

Press every key one by one. Working keys turn green and stay marked, so any key that never lights up is not registering. If a key stays purple after you let go, it may be sticking. The counter shows how many different keys you have tested.

The panel also shows event.key, event.code and keyCode—useful for developers and for checking a keyboard layout.

Limits of browser keyboard tests

Some keys are reserved by the operating system or browser and never reach web pages—for example Fn, Print Screen on some systems, and shortcuts like Ctrl+W or Cmd+Q. Media keys vary by device.

Frequently asked questions

Can it test key rollover (NKRO)?

Hold several keys at once—each held key lights up. If some stop lighting, you have reached your keyboard’s rollover limit.

Why doesn’t the Fn key show?

Fn is handled inside the keyboard hardware and is not reported to the browser.

Does it record what I type?

No. Key presses are only shown on this page and never sent anywhere.

Is this keyboard tester free?

Yes. The keyboard tester is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
