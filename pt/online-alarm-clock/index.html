    Como definir um alarme

    Pressione Testar som primeiro para verificar seu volume. Ative as notificações para também receber um pop-up quando o alarme tocar enquanto você estiver em outro aplicativo.

    • Escolha a hora do alarme e um som e adicione um rótulo, se desejar.
    • Pressione Definir alarme. A lista mostra quanto tempo até tocar.
    • Deixe esta aba aberta. Quando tocar, escolha Soneca (5 minutos) ou Parar alarme.

    Certifique-se de que toca

    • Mantenha a guia aberta – feche-a ou o navegador cancelará os alarmes.
    • Impeça o seu computador de hibernar ou marque “Manter a tela ativa”.
    • Verifique se o dispositivo não está silenciado; o alarme toca no volume do sistema.
    • Os alarmes são salvos, portanto, se você recarregar a página, eles ainda estarão configurados – basta clicar na página uma vez para permitir o som.

    Como usar o despertador online

    1. Insira seus dados. Preencha a hora do alarme, som e etiqueta (opcional).
    2. Obtenha o resultado. Pressione Definir alarme. Atualização de resultados na página.
    3. Use ou copie. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

    Perguntas frequentes

    O alarme tocará se meu laptop dormir?

    Não. Os navegadores não conseguem ativar um dispositivo em suspensão. Mantenha-o acordado e conectado.

    Posso definir mais de um alarme?

    Sim, até 20. Ative ou desative cada um deles ou exclua-os.

    O alarme repete diariamente?

    Cada alarme toca uma vez na próxima ocorrência; ligue-o novamente para usá-lo novamente.

    Este despertador online é gratuito?

    Sim. O despertador online é gratuito para uso em seu navegador, sem necessidade de conta.

    Meus dados saem do dispositivo?

    Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
