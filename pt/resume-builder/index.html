Frequently asked questions

Meu currículo é armazenado online?

Não. O conteúdo permanece no seu navegador, a menos que você baixe um PDF.

Posso usar isso para ATS?

O layout é composto por texto e títulos simples – uma boa base para ATS. Evite tabelas e gráficos para analisadores rigorosos.

Is this resume builder free?

Yes. The resume builder is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
