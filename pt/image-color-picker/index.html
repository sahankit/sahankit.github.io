Escolha cores, exporte gradientes, mescle PDFs e compacte imagens no seu dispositivo.

Pick any colour from a photo or screenshot

Upload an image or paste a screenshot, then hover to see a magnified view and click the exact pixel you want. You get the colour in HEX (for CSS and design tools), RGB and HSL—click any value to copy it. Every colour you pick is kept in a history row.

In Chrome and Edge you can also use Escolha em qualquer lugar da tela to grab a colour from outside the browser, such as another app.

Automatic colour palette

The tool also finds the eight most common distinct colours in your image—handy for building a brand palette from a logo, matching a website to a photo, or choosing paint colours. Click a swatch to copy its HEX code.

How to use the image color picker

  1. Enter your details. Choose a file from your device. It is processed locally and never uploaded to this site.
  2. Get the result. The result updates on the page as you type.
  3. Use or copy it. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Perguntas frequentes

A cor é exata?

Sim, ele lê o pixel real. Imagens muito grandes são dimensionadas para 2.000 px, o que pode misturar ligeiramente os pixels vizinhos.

Posso colar uma captura de tela?

Sim. Pressione Ctrl+V (Cmd+V no Mac) em qualquer lugar da página.

Minha imagem foi carregada?

Não. Ele é processado apenas no seu navegador.

image color picker é grátis?

Sim. image color picker é grátis no navegador, sem conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
