Verificação gramatical integrada do Chrome

Requer Chrome para desktop com IA integrada (Gemini Nano) e espaço livre suficiente em disco. O processamento acontece no seu dispositivo.

Cole o texto e execute Verificar gramática para ver as correções sugeridas do Revisor API.

Como usar o verificador gramatical

  1. Insira seus dados. Verifique gramática, ortografia e pontuação com o Revisor API integrado do Chrome. Privado, no dispositivo quando compatível.
  2. Obtenha o resultado. Pressione Verificar gramática. Atualização de resultados na página.
  3. Use ou copie. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Quando usar o verificador gramatical

Verifique gramática, ortografia e pontuação com o Revisor API integrado do Chrome. Privado, no dispositivo quando compatível. Use-o quando precisar de uma resposta rápida sem instalar software ou criar uma conta.

Tudo é executado localmente em seu navegador, onde a ferramenta oferece suporte - útil para formulários, faturas, estudos e verificações rápidas em qualquer lugar.

Perguntas frequentes

Isso carrega meu texto?

Não. O modelo Proofreader é executado localmente no Chrome, quando disponível.

Este verificador gramatical é gratuito?

Sim. O verificador gramatical é gratuito para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.

O verificador gramatical funciona em dispositivos móveis?

Sim. As páginas são responsivas e as ferramentas são executadas em navegadores móveis da mesma forma que em computadores.
