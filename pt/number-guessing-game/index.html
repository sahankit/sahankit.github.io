About the number guessing game

Guess the secret number between 1 and 100. The game tells you higher or lower until you win.

Runs in your browser—no signup and no install.

How to use the number guessing game

  1. Enter your details. Fill in Seu palpite (1–100).
  2. Get the result. Press Adivinhe. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

O número é sempre o mesmo?

Não. O novo número escolhe um novo número inteiro aleatório de 1 a 100.

O que é uma boa pontuação?

A pesquisa binária geralmente encontra isso em cerca de sete tentativas ou menos.

Is this number guessing game free?

Yes. The number guessing game is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
