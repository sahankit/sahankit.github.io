Como converter PDF para JPG

  • Escolha seu arquivo PDF.
  • Escolha JPG para arquivos pequenos, PNG para textos e diagramas nítidos ou WebP para o menor formato moderno.
  • Escolha 150 dpi para telas e compartilhamento ou 300 dpi para impressão.
  • Optionally enter pages such as 1-3, 5, then press Converter em imagens.
  • Baixe as páginas uma por uma ou todas juntas como um arquivo ZIP.

Privado e rápido

As páginas são renderizadas com o mecanismo PDF.js da Mozilla dentro do seu navegador, então seu PDF nunca é carregado. Isso o torna seguro para certificados, planilhas, faturas e documentos de identificação, e funciona offline depois de carregado.

Como usar o PDF para JPG

  1. Insira seus dados. Escolha um arquivo do seu dispositivo. Ele é processado localmente e nunca carregado neste site.
  2. Obtenha o resultado. Pressione Converter em imagens. Os resultados são atualizados na página e recalculados à medida que você edita os valores.
  3. Use ou copie. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Perguntas frequentes

Que resolução devo escolher?

150 dpi é ideal para WhatsApp, e-mail e sites. Escolha 300 dpi se você planeja imprimir as imagens.

Posso converter apenas uma página?

Sim. Digite o número da página na caixa Páginas, por exemplo 2.

Funciona para PDFs digitalizados?

Sim. Cada página é salva exatamente como parece, quer contenha texto ou imagens digitalizadas.

Este PDF para JPG é gratuito?

Sim. O PDF para JPG é gratuito para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
