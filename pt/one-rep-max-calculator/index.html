Sobre uma repetição máxima (1RM)

Estime seu máximo de uma repetição (1RM) a partir do peso submáximo e das repetições. Calculadora de força gratuita (fórmula de Epley).

Funciona no navegador—sem cadastro nem instalação.

Como usar uma repetição máxima (1RM)

  1. Insira seus dados. Preencha Peso levantado e Reps concluídas.
  2. Obtenha o resultado. Pressione Estimativa 1RM. Os resultados são atualizados na página e recalculados à medida que você edita os valores.
  3. Use ou copie. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Perguntas frequentes

Este é um representante máximo (1RM) gratuito?

Sim. O one rep max (1RM) é gratuito para uso em seu navegador, sem necessidade de conta.

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.

O máximo de uma repetição (1RM) funciona no celular?

Sim. As páginas são responsivas e as ferramentas são executadas em navegadores móveis da mesma forma que em computadores.
