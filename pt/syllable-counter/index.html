How to use the syllable counter

  1. Enter your details. Fill in Texto.
  2. Get the result. Press Contar sílabas. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this syllable counter free?

Yes. The syllable counter is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
