How to convert an image to text

Choose an image or paste a screenshot with Ctrl+V (Cmd+V on Mac), select the language of the text, and press Extrair texto. The first run downloads the OCR engine and language data (a few MB); later runs are faster.

When it finishes, copy the text or download it as a .txt file. Recognition uses Tesseract, the open-source OCR engine, running entirely in your browser.

Tips for accurate OCR

  • Use a sharp, well-lit image with dark text on a light background.
  • Crop to just the text area and straighten tilted photos first.
  • Pick the correct language—use English + Hindi for mixed documents.
  • Printed text works best; handwriting accuracy is limited.

How to use the image to text (OCR)

  1. Enter your details. Choose a file from your device. It is processed locally and never uploaded to this site.
  2. Get the result. Press Extract text . Results update on the page.
  3. Use or copy it. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Perguntas frequentes

Minhas imagens são carregadas?

Não. O mecanismo de OCR é baixado no seu navegador e a imagem é processada no seu dispositivo.

Ele consegue ler hindi?

Sim. Escolha Hindi ou Inglês + Hindi na lista de idiomas.

Ele pode converter um PDF?

Faça uma captura de tela da página ou exporte-a primeiro como uma imagem e depois use esta ferramenta. Para PDFs baseados em texto, a ferramenta PDF to Word é mais rápida.

image to text (OCR) é grátis?

Sim. image to text (OCR) é grátis no navegador, sem conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
