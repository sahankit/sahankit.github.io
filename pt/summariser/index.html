Chrome built-in AI summariser

This tool calls the browser’s Summarizer API (Gemini Nano). Your text is not sent to Sahankit—we do not run a summarization server.

Requires desktop Chrome with built-in AI (Gemini Nano) and enough free disk space. Processing happens on your device—not on Sahankit servers.

Summary types

Key points — bullet-style takeaways. TL;DR — one or two sentences. Headline — title-style line. Teaser — short promo blurb.

How to use the AI summariser

  1. Paste your text. Adicione um artigo, notas ou qualquer passagem em inglês na caixa de texto.
  2. Choose type and length. Escolha pontos-chave, TL;DR, título ou teaser e resultados curtos, médios ou longos.
  3. Click Summarise. O Chrome baixa o modelo no dispositivo, se necessário, e depois escreve o resumo. Copie ou edite o resultado.

Perguntas frequentes

Por que diz indisponível?

Use o Chrome para desktop, espaço livre em disco (~ GB para o modelo) e sinalizadores como summaryer-api-for-gemini-nano se a API estiver desativada.

É o mesmo que ChatGPT?

Não. Ele usa o modelo no dispositivo do Google no Chrome, não uma conta de bate-papo na nuvem.

Posso resumir PDFs?

Copie o texto do PDF primeiro ou use nossa ferramenta PDF para Word para extrair o texto e cole aqui.

Resumidor de IA é grátis?

Sim. Resumidor de IA é grátis no navegador, sem conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
