Como usar o formatador SQL

  1. Insira seus dados. Preencha SQL.
  2. Obtenha o resultado. Pressione Formatar . Atualização de resultados na página.

Perguntas frequentes

Este formatador SQL é gratuito?

Sim. O formatador SQL é gratuito para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.

O formatador SQL funciona em dispositivos móveis?

Sim. As páginas são responsivas e as ferramentas são executadas em navegadores móveis da mesma forma que em computadores.
