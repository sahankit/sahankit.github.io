Como usar o gerador de código QR

  1. Insira seus dados. Preencha URL ou texto e Tamanho (px) .
  2. Obtenha o resultado. Pressione Gerar . Atualização de resultados na página.
  3. Use ou copie. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Quando usar o gerador de código QR

Crie códigos QR de URL ou texto. Baixar PNG. Gerador de código QR gratuito no seu navegador. Use-o quando precisar de uma resposta rápida sem instalar software ou criar uma conta.

Tudo é executado localmente em seu navegador, onde a ferramenta oferece suporte - útil para formulários, faturas, estudos e verificações rápidas em qualquer lugar.

Perguntas frequentes

Os códigos QR expiram?

Os códigos QR estáticos não expiram – os dados estão na imagem. Se você alterar o URL posteriormente, gere um novo código.

Este gerador de código QR é gratuito?

Sim. O gerador de código QR é gratuito para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.

O gerador de código QR funciona em dispositivos móveis?

Sim. As páginas são responsivas e as ferramentas são executadas em navegadores móveis da mesma forma que em computadores.
