Perguntas frequentes

Os códigos QR expiram?

Os códigos QR estáticos não expiram – os dados estão na imagem. Se você alterar o URL posteriormente, gere um novo código.

Gerador de código QR é grátis?

Sim. Gerador de código QR é grátis no navegador, sem conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.

Does the QR code generator work on mobile?

Yes. Pages are responsive and tools run in mobile browsers the same way as on desktop.
