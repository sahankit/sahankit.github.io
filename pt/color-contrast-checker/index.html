Verificador de contraste de cores

Verificador de contraste de cores WCAG gratuito. Insira as cores do texto e do plano de fundo para obter a taxa de contraste e aprovação ou reprovação AA/AAA para texto normal, texto grande e elementos da interface do usuário.

Amostra de texto grande (24px)

Corpo de texto normal em 16px. A rápida raposa marrom salta sobre o cachorro preguiçoso.

Requisitos de contraste WCAG

  • Texto normal AA: pelo menos 4,5:1
  • AA texto grande (24px ou 18,66px em negrito): pelo menos 3:1
  • Texto normal AAA: pelo menos 7:1; Texto grande AAA: 4.5:1
  • Componentes e ícones da UI (WCAG 2.1): pelo menos 3:1 contra cores adjacentes

Como a proporção é calculada

A luminância relativa de cada cor é calculada a partir de seus valores sRGB, então a proporção é (mais claro + 0,05) ÷ (mais escuro + 0,05). As proporções variam de 1:1 (mesma cor) a 21:1 (preto sobre branco). O valor exibido é arredondado para baixo para que uma aprovação nunca seja exagerada.

Como usar o verificador de contraste de cores

  1. Insira seus dados. Preencha a cor do texto e a cor do plano de fundo.
  2. Obtenha o resultado. Pressione Trocar cores. Atualização de resultados na página.
  3. Use ou copie. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Perguntas frequentes

Qual taxa de contraste eu preciso?

Apontar para 4,5:1 para o corpo do texto para atender às WCAG AA, às quais a maioria das leis de acessibilidade faz referência.

Posso inserir códigos hexadecimais curtos?

Sim. #333 é lido como #333333.

Ele verifica gradientes ou imagens?

Não. Verifique as partes mais claras e mais escuras do fundo separadamente.

Este verificador de contraste de cores é gratuito?

Sim. O verificador de contraste de cores é gratuito para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
