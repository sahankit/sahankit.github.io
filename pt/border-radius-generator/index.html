The four-value order

When the corners differ, CSS reads the four lengths clockwise from the top left: top left, top right, bottom right, bottom left. A single length applies to every corner. The copied line is ready to paste into a style rule.

How to use the border radius generator

  1. Enter your details. Fill in Todos os cantos (px), Canto superior esquerdo (px), Canto superior direito (px), Canto inferior direito (px) e Canto inferior esquerdo (px).
  2. Get the result. The result updates on the page as you type.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Posso usar porcentagem em vez de pixels?

Este gerador grava pixels. Um raio percentual é relativo ao tamanho da caixa, que muda conforme o elemento cresce.

Is this border radius generator free?

Yes. The border radius generator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
