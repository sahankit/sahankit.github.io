Como usar o gerador de raio de borda

Quando usar o gerador de raio de borda

Defina cada canto em pixels, visualize a caixa e copie o raio da borda CSS. Um valor arredonda todos os quatro cantos. Use-o quando precisar de uma resposta rápida sem instalar software ou criar uma conta.

Tudo é executado localmente em seu navegador, onde a ferramenta oferece suporte - útil para formulários, faturas, estudos e verificações rápidas em qualquer lugar.

Perguntas frequentes

Posso usar porcentagem em vez de pixels?

Este gerador grava pixels. Um raio percentual é relativo ao tamanho da caixa, que muda conforme o elemento cresce.

Este gerador de raio de borda é gratuito?

Sim. O gerador de raio de borda é gratuito para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.

O gerador de raio de borda funciona em dispositivos móveis?

Sim. As páginas são responsivas e as ferramentas são executadas em navegadores móveis da mesma forma que em computadores.
