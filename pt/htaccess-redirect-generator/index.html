Sobre o redirecionamento .htaccess
Gere linhas de redirecionamento Apache .htaccess para movimentos 301 ou 302. Copie para a configuração do seu servidor.
Funciona no navegador—sem cadastro nem instalação.
Como usar o redirecionamento .htaccess
  1. Insira seus dados. Preencha From path , To URL e Type .
  2. Obtenha o resultado. Pressione Gerar . Atualização de resultados na página.
  3. Use ou copie. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.
Perguntas frequentes
Este redirecionamento .htaccess é gratuito?
Sim. O redirecionamento .htaccess é gratuito para uso em seu navegador, sem necessidade de conta.
Meus dados saem do dispositivo?
Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
O redirecionamento .htaccess funciona em dispositivos móveis?
Sim. As páginas são responsivas e as ferramentas são executadas em navegadores móveis da mesma forma que em computadores.
