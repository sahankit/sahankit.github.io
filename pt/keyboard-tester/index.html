How to find broken keys

Press every key one by one. Working keys turn green and stay marked, so any key that never lights up is not registering. If a key stays purple after you let go, it may be sticking. The counter shows how many different keys you have tested.

The panel also shows evento.key, evento.código e código-chave—useful for developers and for checking a keyboard layout.

Limits of browser keyboard tests

Some keys are reserved by the operating system or browser and never reach web pages—for example Fn, Print Screen on some systems, and shortcuts like Ctrl+W or Cmd+Q. Media keys vary by device.

How to use the keyboard tester

  1. Enter your details. Free online keyboard tester. Press keys to check they work: keys light up while held and stay marked once tested. Shows event key, code and keyCode.
  2. Get the result. Press Redefinir teste. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Ele pode testar a substituição de chave (NKRO)?

Segure várias teclas ao mesmo tempo – cada tecla pressionada acende. Se alguma iluminação parar, você atingiu o limite de rollover do teclado.

Por que a tecla Fn não aparece?

Fn é manipulado dentro do hardware do teclado e não é relatado ao navegador.

Ele grava o que eu digito?

Não. As teclas pressionadas são mostradas apenas nesta página e nunca são enviadas a lugar nenhum.

Is this keyboard tester free?

Yes. The keyboard tester is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
