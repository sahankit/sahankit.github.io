Quando usar os fusos horários da reunião

Compare os horários das reuniões em diferentes fusos horários. Planejador de fuso horário gratuito para equipes remotas. Use-o quando precisar de uma resposta rápida sem instalar software ou criar uma conta.

Perguntas frequentes

Os fusos horários desta reunião são gratuitos?

Sim. Os fusos horários da reunião são gratuitos para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.

Os fusos horários das reuniões funcionam em dispositivos móveis?

Sim. As páginas são responsivas e as ferramentas são executadas em navegadores móveis da mesma forma que em computadores.
