Ouça qualquer texto

Cole um artigo, notas ou um e-mail e pressione Fale. Escolha uma voz para alterar o sotaque ou o idioma: hindi, inglês (Índia, EUA, Reino Unido) e muitas outras vozes estão disponíveis dependendo do seu dispositivo. Diminua a velocidade para aprender ou acelere para folhear.

O texto longo é dividido em frases para que continue sendo reproduzido sem problemas. Use Pausar, Retomar e Parar a qualquer momento.

Quais vozes verei?

A ferramenta usa o Web Speech API, que reproduz vozes instaladas no seu dispositivo ou fornecidas pelo seu navegador. Chrome e Edge incluem vozes online extras; O Safari usa vozes do sistema Apple; Vozes do Windows e Android podem ser adicionadas nas configurações do sistema.

Como usar o texto para fala

  1. Insira seus dados. Preencha Texto para ler em voz alta, Voz, Velocidade e Tom.
  2. Obtenha o resultado. Pressione Falar. Atualização de resultados na página.
  3. Use ou copie. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Perguntas frequentes

Posso baixar o discurso como MP3?

Não com esta ferramenta – os navegadores não permitem salvar a saída do Web Speech. Você pode gravá-lo com software de gravação de tela ou áudio.

Suporta hindi?

Sim, se uma voz em hindi estiver disponível no seu dispositivo. Procure “hi-IN” na lista de vozes.

Meu texto é enviado para um servidor?

O texto é processado pelo mecanismo de fala do seu navegador. Algumas vozes online fornecidas pelo navegador podem enviar texto para o serviço de fala desse navegador.

Este texto para fala é gratuito?

Sim. O texto para fala é gratuito para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
