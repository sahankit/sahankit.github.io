Listen to any text

Paste an article, notes or an email and press Fale. Choose a voice to change the accent or language—Hindi, English (India, US, UK) and many other voices are available depending on your device. Slow the speed down for learning or speed it up to skim.

Long text is split into sentences so it keeps playing smoothly. Use Pause, Resume and Stop at any time.

Which voices will I see?

The tool uses the Web Speech API, which plays voices installed on your device or provided by your browser. Chrome and Edge include extra online voices; Safari uses Apple system voices; Windows and Android voices can be added in system settings.

How to use the text to speech

  1. Enter your details. Fill in Texto para ler em voz alta, Voz, Velocidade e Argumento.
  2. Get the result. Press Fale. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Posso baixar o discurso como MP3?

Não com esta ferramenta – os navegadores não permitem salvar a saída do Web Speech. Você pode gravá-lo com software de gravação de tela ou áudio.

Suporta hindi?

Sim, se uma voz em hindi estiver disponível no seu dispositivo. Procure “hi-IN” na lista de vozes.

Meu texto é enviado para um servidor?

O texto é processado pelo mecanismo de fala do seu navegador. Algumas vozes online fornecidas pelo navegador podem enviar texto para o serviço de fala desse navegador.

Is this text to speech free?

Yes. The text to speech is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
