Verificador de formato PAN

Um PAN válido possui 10 caracteres: cinco letras, quatro dígitos, uma letra (por exemplo, ABCDE1234F). Este verificador valida apenas o formato – não o status do banco de dados do Imposto de Renda.

PAN format reference (10 characters)

Permanent Account Number (PAN) uses five letters, four digits, and one letter: AAAAA9999A. The fourth letter indicates holder type.

PositionRuleExample
1–5Letters A–Z (name)ABCDE
6–9Digits 0–91234
10Letter A–Z (checksum)F
4th charP=Person, C=Company, H=HUF, F=Firm, A=AOP, T=TrustP in EPAPS1234F

Layout do número de conta permanente

PANs têm 10 caracteres: cinco letras, quatro dígitos, uma letra. Esta ferramenta verifica apenas o formato. Não consulta o Imposto de Renda nem comprova que o PAN está ativo.

  • 4º caractere (tipo de entidade): P = indivíduo, C = empresa, H = HUF, F = empresa, etc.
  • Exemplo: AAAPL1234C — pattern only; do not use real PANs from samples in forms

Como usar a verificação do formato PAN

  1. Insira seus dados. Preencha PAN.
  2. Obtenha o resultado. Pressione Verificar formato. Atualização de resultados na página.
  3. Use ou copie. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Quando usar a verificação do formato PAN

Verifique se um PAN corresponde ao formato padrão AAAAA9999A. Não é uma verificação oficial do Imposto de Renda. Use-o quando precisar de uma resposta rápida sem instalar software ou criar uma conta.

Tudo é executado localmente em seu navegador, onde a ferramenta oferece suporte - útil para formulários, faturas, estudos e verificações rápidas em qualquer lugar.

Perguntas frequentes

Posso usar isso para KYC?

Use canais de verificação oficiais. Este é um auxiliar de digitação, não KYC.

Por que a validação falhou em um PAN real?

Verifique se há caracteres confusos (O vs 0, I vs 1) e se o comprimento é exatamente 10.

Esta verificação do formato PAN é gratuita?

Sim. A verificação do formato PAN é gratuita para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.

A verificação do formato PAN funciona em dispositivos móveis?

Sim. As páginas são responsivas e as ferramentas são executadas em navegadores móveis da mesma forma que em computadores.
