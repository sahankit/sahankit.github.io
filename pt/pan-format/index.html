Permanent Account Number layout

PANs are 10 characters: five letters, four digits, one letter. This tool checks format only. It does not query the Income Tax Department or prove a PAN is active.

How to use the PAN format check

  1. Enter your details. Fill in PAN .
  2. Get the result. Press Check format . Results update on the page.
  3. Use or copy it. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Perguntas frequentes

Posso usar isso para KYC?

Use canais de verificação oficiais. Este é um auxiliar de digitação, não KYC.

Verificação do formato PAN é grátis?

Sim. Verificação do formato PAN é grátis no navegador, sem conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
