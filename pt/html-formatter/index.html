Cole o código minificado ou mal recuado e pressione Embelezar. O formatador (alimentado pela biblioteca js-beautify de código aberto) recua tags aninhadas, regras CSS e blocos JavaScript, e também formata CSS e scripts incorporados em HTML. Escolha 2 espaços, 4 espaços ou abas para combinar com seu projeto.

Minificar para produção

  • HTML — remove comentários e espaços em branco de indentação enquanto mantém o conteúdo <pre>, <textarea> e <script> intacto.
  • CSS — remove comentários, espaços e o último ponto e vírgula em cada regra.
  • JSON — remove todos os espaços em branco.
  • JavaScript — use uma ferramenta de construção como Terser ou esbuild; a minificação segura de JS precisa de um analisador completo.

Como usar o formatador HTML

  1. Insira seus dados. Preencha Language , Indent , Paste your code e Result .
  2. Obtenha o resultado. Pressione Embelezar. Atualização de resultados na página.
  3. Use ou copie. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Perguntas frequentes

A formatação altera o funcionamento da minha página?

Embelezar apenas altera os espaços em branco. Minimizar o HTML recolhe espaços extras, o que quase nunca altera a renderização.

Meu código é enviado para um servidor?

Não. A formatação acontece no seu navegador; apenas a biblioteca do formatador é baixada.

Ele pode consertar HTML quebrado?

Ele recua o que você fornece, mas não repara tags ausentes. Valide com o validador W3C, se necessário.

Este formatador HTML é gratuito?

Sim. O formatador HTML é gratuito para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
