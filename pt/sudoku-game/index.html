About the sudoku game

Play Sudoku in the browser. Fill the grid so each row, column and 3×3 box has digits 1–9 once.

Funciona no navegador—sem cadastro nem instalação.

How to use the sudoku game

  1. Enter your details. Play Sudoku in the browser. Fill the grid so each row, column and 3×3 box has digits 1–9 once.
  2. Get the result. Press Check . Results update on the page.
  3. Use or copy it. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Perguntas frequentes

Isso gera novos quebra-cabeças?

O novo quebra-cabeça recarrega a mesma grade inicial fácil hoje. Use Novo quebra-cabeça para limpar suas entradas e tente novamente.

O que o Check faz?

Ele compara as células preenchidas com a solução e informa se algo está errado ou incompleto.
