Sobre o jogo sudoku

Funciona no navegador—sem cadastro nem instalação.

Como usar o jogo sudoku

  1. Insira seus dados. Jogue Sudoku no navegador. Preencha a grade de forma que cada linha, coluna e caixa 3×3 tenha dígitos de 1 a 9 uma vez.
  2. Obtenha o resultado. Pressione Verificar . Atualização de resultados na página.
  3. Use ou copie. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Perguntas frequentes

Isso gera novos quebra-cabeças?

O novo quebra-cabeça recarrega a mesma grade inicial fácil hoje. Use Novo quebra-cabeça para limpar suas entradas e tente novamente.

O que o Check faz?

Ele compara as células preenchidas com a solução e informa se algo está errado ou incompleto.

Este jogo de sudoku é gratuito?

Sim. O jogo sudoku é gratuito para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.

O jogo sudoku funciona no celular?

Sim. As páginas são responsivas e as ferramentas são executadas em navegadores móveis da mesma forma que em computadores.
