How to use the regex builder
  1. Enter your details. Fill in Preset templates , Insert escaped literal , Regular expression and Sample text .
  2. Get the result. Press Test matches . Results update on the page.
  3. Use or copy it. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.
Perguntas frequentes
Como isso é diferente do testador de regex?
O construtor se concentra na montagem de padrões a partir de predefinições e peças; o testador é mínimo para colar e executar. Ambos são executados localmente.
Qual sabor de regex?
JavaScript RegExp (igual aos navegadores e Node). Os sinalizadores g, i, m e s são suportados aqui.
regex builder é grátis?
Sim. regex builder é grátis no navegador, sem conta.
Meus dados saem do dispositivo?
Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
