Requires desktop Chrome with built-in AI and enough free disk space. Text is processed on your device—not on Sahankit servers.

Language packs download on first use for each pair you translate.

How to use the AI translator

  1. Enter your details. Fill in Text , From , To and Translation .
  2. Get the result. Press Translate . Results update on the page.
  3. Use or copy it. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Perguntas frequentes

Isso funciona no celular?

Não. A API Translator do Chrome é apenas para desktop a partir do Chrome 138.

Tradutor de IA é grátis?

Sim. Tradutor de IA é grátis no navegador, sem conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
