Como usar o tradutor de IA

  1. Insira seus dados. Preencha Texto, De, Para e Tradução.
  2. Obtenha o resultado. Pressione Traduzir. Atualização de resultados na página.
  3. Use ou copie. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Quando usar o tradutor de IA

Traduza texto com o Tradutor API do Chrome. Tradução privada no dispositivo – sem upload para Sahankit. Use-o quando precisar de uma resposta rápida sem instalar software ou criar uma conta.

Tudo é executado localmente em seu navegador, onde a ferramenta oferece suporte - útil para formulários, faturas, estudos e verificações rápidas em qualquer lugar.

Perguntas frequentes

Isso funciona no celular?

Não. A API Translator do Chrome é apenas para desktop a partir do Chrome 138.

Este tradutor de IA é gratuito?

Sim. O tradutor de IA é gratuito para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.

O tradutor de IA funciona em dispositivos móveis?

Sim. As páginas são responsivas e as ferramentas são executadas em navegadores móveis da mesma forma que em computadores.
