How to use the AI translator

  1. Enter your details. Fill in Texto, De, Para e Tradução.
  2. Get the result. Press Traduzir. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Isso funciona no celular?

Não. A API Translator do Chrome é apenas para desktop a partir do Chrome 138.

Is this AI translator free?

Yes. The AI translator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
