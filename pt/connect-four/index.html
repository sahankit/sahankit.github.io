About the connect Four

Drop discs and connect four in a row before the computer does. Free Connect 4 game in your browser.

Funciona no navegador—sem cadastro nem instalação.

How to use the connect Four

  1. Enter your details. Drop discs and connect four in a row before the computer does. Free Connect 4 game in your browser.
  2. Get the result. Press New game . Results update on the page.
  3. Use or copy it. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Perguntas frequentes

Como faço para descartar um disco?

Clique na seta acima de uma coluna. O disco cai para a linha livre mais baixa dessa coluna.

Quem vai primeiro?

Você joga com o vermelho e se move primeiro. O computador joga amarelo.

connect Four é grátis?

Sim. connect Four é grátis no navegador, sem conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
