Calculadora HRA (Índia)

Para muitos empregados assalariados sob o antigo regime de imposto de renda, o HRA isento é o mínimo de três valores: HRA real recebido, aluguel pago menos 10% do salário base e 50% do básico (metro) ou 40% do básico (não metro).

Estimativa HRA isenta no antigo regime tributário. A isenção é a menos de três quantias. Não é um substituto para o Formulário 16 ou aconselhamento da CA.

Como a isenção HRA é calculada

Para muitos empregados assalariados sob o antigo regime de imposto de renda, o HRA isento é o mínimo de três valores: HRA real recebido, aluguel pago menos 10% do salário base e 50% do básico (metro) ou 40% do básico (não metro).

Use isso com nossa calculadora de imposto de renda para comparar o regime novo e o antigo quando o HRA for uma grande dedução.

Como usar a calculadora HRA

  1. Insira seus dados. Preencha Salário básico ($$ anual), HRA recebido ($$ anual) e Aluguel pago ($$ anual).
  2. Obtenha o resultado. Pressione Calcular isenção. Os resultados são atualizados na página e recalculados à medida que você edita os valores.
  3. Use ou copie. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Quando usar a calculadora HRA

Calcule a isenção de impostos HRA para funcionários assalariados na Índia. Metrô x não metrô, salário base e aluguel pago. Use-o quando precisar de uma resposta rápida sem instalar software ou criar uma conta.

Tudo é executado localmente em seu navegador, onde a ferramenta oferece suporte - útil para formulários, faturas, estudos e verificações rápidas em qualquer lugar.

Perguntas frequentes

O HRA se aplica no novo regime tributário?

Geralmente não – a isenção HRA não está disponível no novo regime. Esta ferramenta é para o planejamento do antigo regime.

O recibo do aluguel é obrigatório?

Os empregadores e o departamento fiscal podem exigir contratos de aluguel e recibos para HRA reivindicada – esta página apenas estima matemática.

Esta calculadora HRA é gratuita?

Sim. A calculadora HRA é gratuita para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.

A calculadora HRA funciona no celular?

Sim. As páginas são responsivas e as ferramentas são executadas em navegadores móveis da mesma forma que em computadores.
