Percentage formulas

  • X% of Y = X ÷ 100 × Y. Example: 15% of 2,400 = 360.
  • X is what % of Y = X ÷ Y × 100. Example: 45 out of 60 marks = 75%.
  • Alteração percentual = (new − old) ÷ old × 100. Example: 800 → 1,000 is a 25% increase.
  • Add a percentage = value × (1 + p ÷ 100). Example: 1,200 + 18% GST = 1,416.

Frequently asked questions

Como calculo a porcentagem de notas?

Divida as notas obtidas pelo total de notas e multiplique por 100. Use a segunda calculadora: insira suas notas e o total.

O aumento percentual é igual a pontos percentuais?

Não. Passar de 10% para 12% é um aumento de 2 pontos percentuais, mas um aumento de 20% em relação ao valor inicial.

Como o resultado é arredondado?

Os resultados mostram até quatro casas decimais. Arredonde a moeda para duas casas decimais ao usá-la em uma fatura.

Is this percentage calculator free?

Yes. The percentage calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
