Perguntas frequentes

Como posso ganhar?

Vire duas cartas de cada vez. Quando ambos mostram o mesmo emoji, eles ficam voltados para cima. Limpe todo o tabuleiro.

Ele monitora minha melhor pontuação?

Somente para esta sessão. Atualizar inicia uma nova ordem aleatória.

Este jogo de memória é grátis?

Sim. O jogo da memória é gratuito para uso em seu navegador, sem necessidade de conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.

O jogo da memória funciona no celular?

Sim. As páginas são responsivas e as ferramentas são executadas em navegadores móveis da mesma forma que em computadores.
