Screen resolution vs. viewport

Resolução da tela is the size of your whole display. Browsers report it in CSS pixels; multiply by the device pixel ratio to get physical pixels. A 4K monitor at 150% scaling, for example, reports 2560 × 1440 CSS pixels with a ratio of 1.5 (3840 × 2160 physical).

The viewport is the visible area of the web page inside the browser window. Web designers use it to test responsive layouts.

Common resolutions

  • 1920 × 1080 (Full HD, 16:9) — the most common desktop size
  • 1366 × 768 — many budget laptops
  • 2560 × 1440 (QHD) and 3840 × 2160 (4K UHD)
  • 390 × 844 and 412 × 915 — common phone viewports in CSS pixels

Perguntas frequentes

Por que minha resolução é inferior às especificações do meu monitor?

O dimensionamento de exibição no Windows ou macOS faz com que o navegador relate um tamanho CSS menor. Pixels físicos mostram a resolução real do painel.

Qual é a proporção de pixels do dispositivo?

O número de pixels físicos por pixel CSS. As telas Retina e de alto DPI geralmente têm 2 ou 3.

Algum dado é coletado?

Não. Os valores são lidos no seu navegador e mostrados apenas para você.

screen resolution é grátis?

Sim. screen resolution é grátis no navegador, sem conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
