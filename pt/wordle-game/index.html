About the wordle game

Free Wordle-style game. Guess the five-letter word in six tries. Green means correct spot, yellow means wrong spot.

Funciona no navegador—sem cadastro nem instalação.

How to use the wordle game

  1. Enter your details. Free Wordle-style game. Guess the five-letter word in six tries. Green means correct spot, yellow means wrong spot.
  2. Get the result. Press Guess . Results update on the page.
  3. Use or copy it. Copie ou baixe o resultado. Nada é salvo—atualize para recomeçar.

Perguntas frequentes

Este é o Wordle oficial?

Não. É um jogo original de adivinhação de palavras com regras de cores semelhantes, jogado apenas nesta página.

Quantos palpites eu recebo?

Seis. Cada palpite deve ter cinco letras. Use Nova palavra para outra resposta aleatória.

wordle game é grátis?

Sim. wordle game é grátis no navegador, sem conta.

Meus dados saem do dispositivo?

Na maioria das ferramentas, os dados ficam no seu dispositivo. Se uma ferramenta chama uma API pública (idade de domínio, por exemplo), isso está na página.
