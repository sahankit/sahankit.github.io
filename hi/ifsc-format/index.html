आईएफएससी प्रारूप चेकर

एक IFSC 11 अक्षर का होता है: 4 बैंक अक्षर + 0 + 6 शाखा अक्षर (उदाहरण के लिए SBIN0001234)। यह उपकरण केवल पैटर्न की जाँच करता है—यह नहीं कि शाखा मौजूद है या नहीं।

यह केवल जाँच करता है पैटर्न (4 अक्षर + 0 + 6 अक्षरांकीय). यह पुष्टि नहीं करता कि शाखा मौजूद है। आधिकारिक सत्यापन के लिए अपने बैंक या आरबीआई का उपयोग करें।

इस वर्कफ़्लो में संबंधित

पैन प्रारूप की जांच

केवल पैन पैटर्न को मान्य करें।

UPI प्रारूप की जाँच करें

वीपीए पैटर्न को मान्य करें।

IFSC format reference (11 characters)

Indian Financial System Code identifies bank and branch for NEFT/RTGS/IMPS: AAAA0BBBBBB (4 bank + 0 + 6 branch).

SegmentRuleExample
1–4Bank code (letters)HDFC
5Always 00
6–11Branch code (alphanumeric)000123

आईएफएससी संरचना (केवल प्रारूप)

भारतीय वित्तीय प्रणाली कोड 11 अक्षर के होते हैं: चार बैंक अक्षर, एक शून्य, फिर छह शाखा अक्षर। यह चेकर केवल आकृति को मान्य करता है। किसी सक्रिय शाखा की पुष्टि करने के लिए, अपने बैंक या आरबीआई स्रोतों का उपयोग करें।

  • उदाहरण (पैटर्न): HDFC0000123 — HDFC bank, branch segment 000123
  • सामान्य गलती: 10 वर्णों का उपयोग करना या 5वें वर्ण की अदला-बदली करना (मानक कोड में 0 होना चाहिए)

आईएफएससी प्रारूप जांच का उपयोग कैसे करें

  1. अपना विवरण दर्ज करें. आईएफएससी कोड भरें.
  2. परिणाम प्राप्त करें. चेक फ़ॉर्मेट दबाएँ. परिणाम पेज पर अपडेट होते हैं।
  3. इसका उपयोग करें या इसकी प्रतिलिपि बनाएँ। आउटपुट कॉपी या डाउनलोड करें। कुछ सेव नहीं होता—रीफ़्रेश करके फिर शुरू करें।

आईएफएससी प्रारूप जांच का उपयोग कब करें

जांचें कि क्या आईएफएससी कोड मानक 11-वर्ण प्रारूप से मेल खाता है। RBI से सत्यापन नहीं करता. जब आपको सॉफ़्टवेयर इंस्टॉल किए बिना या खाता बनाए बिना त्वरित उत्तर की आवश्यकता हो तो इसका उपयोग करें।

सब कुछ आपके ब्राउज़र में स्थानीय रूप से चलता है जहां टूल इसका समर्थन करता है - फॉर्म, चालान, अध्ययन और चलते-फिरते त्वरित जांच के लिए उपयोगी।

अक्सर पूछे जाने वाले प्रश्न

क्या यह सत्यापित करता है कि शाखा मौजूद है?

नहीं, यह केवल यह जांचता है कि कोड सामान्य पैटर्न से मेल खाता है या नहीं।

क्या IFSC स्विफ्ट के समान है?

नहीं, IFSC भारत में घरेलू NEFT/RTGS/IMPS के लिए है। स्विफ्ट/बीआईसी का उपयोग अंतरराष्ट्रीय तारों के लिए किया जाता है।

क्या यह IFSC प्रारूप वाला चेक मुफ़्त है?

हाँ। बिना किसी खाते की आवश्यकता के आपके ब्राउज़र में आईएफएससी प्रारूप जांच का उपयोग निःशुल्क है।

क्या मेरा डेटा डिवाइस से बाहर जाता है?

इस साइट के ज़्यादातर टूल आपका इनपुट आपके डिवाइस पर ही प्रोसेस करते हैं। अगर कोई टूल सार्वजनिक API कॉल करता है (जैसे डोमेन आयु), तो यह पेज पर लिखा होता है।

क्या IFSC प्रारूप चेक मोबाइल पर काम करता है?

हाँ। पेज प्रतिक्रियाशील होते हैं और टूल मोबाइल ब्राउज़र में डेस्कटॉप की तरह ही चलते हैं।

यह सामान्य आईएफएससी प्रारूप जांच खोज परिणाम से किस प्रकार भिन्न है?

यह पृष्ठ कैलकुलेटर या उपयोगिता को संक्षिप्त उत्तरों, अक्सर पूछे जाने वाले प्रश्नों और उसी वर्कफ़्लो में अगले चरण के लिंक के साथ जोड़ता है।
