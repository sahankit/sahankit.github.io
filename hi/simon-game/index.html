Watch the colour pattern and repeat it. Each round adds one more step in this Simon memory game.

How to use the simon game

  1. Enter your details. Watch the colour pattern and repeat it. Each round adds one more step in this Simon memory game.
  2. Get the result. Press Start . Results update on the page.
  3. Use or copy it. आउटपुट कॉपी या डाउनलोड करें। कुछ सेव नहीं होता—रीफ़्रेश करके फिर शुरू करें।
