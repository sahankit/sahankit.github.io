अक्सर पूछे जाने वाले प्रश्न
यह रेगेक्स परीक्षक से किस प्रकार भिन्न है?
बिल्डर प्रीसेट और भागों से पैटर्न को असेंबल करने पर ध्यान केंद्रित करता है; परीक्षक न्यूनतम पेस्ट-एंड-रन है। दोनों स्थानीय स्तर पर चलते हैं।
रेगेक्स का कौन सा स्वाद?
जावास्क्रिप्ट रेगएक्सपी (ब्राउज़र और नोड के समान)। झंडे g, i, m, और s यहां समर्थित हैं।
क्या यह regex builder मुफ़्त है?
हाँ। regex builder ब्राउज़र में मुफ़्त है, खाता नहीं चाहिए।
क्या मेरा डेटा डिवाइस से बाहर जाता है?
इस साइट के ज़्यादातर टूल आपका इनपुट आपके डिवाइस पर ही प्रोसेस करते हैं। अगर कोई टूल सार्वजनिक API कॉल करता है (जैसे डोमेन आयु), तो यह पेज पर लिखा होता है।

Yes. Pages are responsive and tools run in mobile browsers the same way as on desktop.
