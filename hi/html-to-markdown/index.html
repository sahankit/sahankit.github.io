मार्कडाउन के लिए HTML के बारे में

अपने ब्राउज़र में HTML स्निपेट्स को मार्कडाउन में कनवर्ट करें। HTML चिपकाएँ, डॉक्स और GitHub के लिए साफ़ MD प्राप्त करें।

ब्राउज़र में चलता है—रजिस्टर या इंस्टॉल नहीं।

मार्कडाउन के लिए HTML का उपयोग कैसे करें

  1. अपना विवरण दर्ज करें. HTML और Markdown भरें।
  2. परिणाम प्राप्त करें. कन्वर्ट दबाएँ. जैसे ही आप मान संपादित करते हैं, परिणाम पृष्ठ पर अपडेट हो जाते हैं और पुनर्गणना हो जाती है।
  3. इसका उपयोग करें या इसकी प्रतिलिपि बनाएँ। आउटपुट कॉपी या डाउनलोड करें। कुछ सेव नहीं होता—रीफ़्रेश करके फिर शुरू करें।

अक्सर पूछे जाने वाले प्रश्न

क्या यह HTML मार्कडाउन के लिए मुफ़्त है?

हाँ। मार्कडाउन के लिए HTML बिना किसी खाते की आवश्यकता के आपके ब्राउज़र में उपयोग करने के लिए निःशुल्क है।

क्या मेरा डेटा डिवाइस से बाहर जाता है?

इस साइट के ज़्यादातर टूल आपका इनपुट आपके डिवाइस पर ही प्रोसेस करते हैं। अगर कोई टूल सार्वजनिक API कॉल करता है (जैसे डोमेन आयु), तो यह पेज पर लिखा होता है।

क्या HTML से मार्कडाउन मोबाइल पर काम करता है?

हाँ। पेज प्रतिक्रियाशील होते हैं और टूल मोबाइल ब्राउज़र में डेस्कटॉप की तरह ही चलते हैं।

यह सामान्य HTML से मार्कडाउन खोज परिणाम से किस प्रकार भिन्न है?

यह पृष्ठ कैलकुलेटर या उपयोगिता को संक्षिप्त उत्तरों, अक्सर पूछे जाने वाले प्रश्नों और उसी वर्कफ़्लो में अगले चरण के लिंक के साथ जोड़ता है।
