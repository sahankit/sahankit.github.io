How to use the sudoku game

  1. Enter your details. Play Sudoku in the browser. Fill the grid so each row, column and 3×3 box has digits 1–9 once.
  2. Get the result. Press Check . Results update on the page.
  3. Use or copy it. आउटपुट कॉपी या डाउनलोड करें। कुछ सेव नहीं होता—रीफ़्रेश करके फिर शुरू करें।

क्या यह नई पहेलियाँ उत्पन्न करता है?

नई पहेली आज उसी आसान स्टार्टर ग्रिड को पुनः लोड करती है। अपनी प्रविष्टियाँ साफ़ करने और पुनः प्रयास करने के लिए नई पहेली का उपयोग करें।

चेक क्या करता है?

यह आपकी भरी हुई कोशिकाओं की तुलना समाधान से करता है और आपको बताता है कि क्या कुछ गलत या अधूरा है।

क्या यह sudoku game मुफ़्त है?

हाँ। sudoku game ब्राउज़र में मुफ़्त है, खाता नहीं चाहिए।

क्या मेरा डेटा डिवाइस से बाहर जाता है?

इस साइट के ज़्यादातर टूल आपका इनपुट आपके डिवाइस पर ही प्रोसेस करते हैं। अगर कोई टूल सार्वजनिक API कॉल करता है (जैसे डोमेन आयु), तो यह पेज पर लिखा होता है।
