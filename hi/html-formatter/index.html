Beautify, then read and debug

Paste minified or badly indented code and press सुशोभित करें. The formatter (powered by the open-source js-beautify library) re-indents nested tags, CSS rules and JavaScript blocks, and also formats CSS and scripts embedded in HTML. Choose 2 spaces, 4 spaces or tabs to match your project.

Minify for production

  • HTML — removes comments and indentation whitespace while keeping <pre>, <textarea> and <script> content intact.
  • CSS — strips comments, spaces and the last semicolon in each rule.
  • JSON — removes all whitespace.
  • JavaScript — use a build tool such as Terser or esbuild; safe JS minification needs a full parser.

How to use the HTML formatter

  1. Enter your details. Fill in Language , Indent , Paste your code and Result .
  2. Get the result. Press Beautify . Results update on the page.
  3. Use or copy it. आउटपुट कॉपी या डाउनलोड करें। कुछ सेव नहीं होता—रीफ़्रेश करके फिर शुरू करें।

अक्सर पूछे जाने वाले प्रश्न

क्या फ़ॉर्मेटिंग से मेरे पेज के काम करने का तरीका बदल जाता है?

सौंदर्यीकरण से केवल रिक्त स्थान बदलता है। HTML को छोटा करने से अतिरिक्त स्थान समाप्त हो जाते हैं, जिससे रेंडरिंग लगभग कभी नहीं बदलती।

क्या मेरा कोड किसी सर्वर पर भेजा गया है?

नहीं, फ़ॉर्मेटिंग आपके ब्राउज़र में होती है; केवल फ़ॉर्मेटर लाइब्रेरी डाउनलोड की गई है।

क्या यह टूटे हुए HTML को ठीक कर सकता है?

यह आप जो देते हैं उसे इंडेंट करता है लेकिन गुम टैग की मरम्मत नहीं करता है। यदि आवश्यक हो तो W3C सत्यापनकर्ता के साथ सत्यापन करें।

क्या यह HTML फ़ॉर्मेटर मुफ़्त है?

हाँ। HTML फ़ॉर्मेटर ब्राउज़र में मुफ़्त है, खाता नहीं चाहिए।

क्या मेरा डेटा डिवाइस से बाहर जाता है?

इस साइट के ज़्यादातर टूल आपका इनपुट आपके डिवाइस पर ही प्रोसेस करते हैं। अगर कोई टूल सार्वजनिक API कॉल करता है (जैसे डोमेन आयु), तो यह पेज पर लिखा होता है।
