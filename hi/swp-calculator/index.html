How to use the SWP calculator

  1. Enter your details. Fill in आरंभिक कोष (₹), मासिक निकासी (₹) और अपेक्षित वार्षिक रिटर्न (%).
  2. Get the result. Press अनुमानित अवधि. Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this SWP calculator free?

Yes. The SWP calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
