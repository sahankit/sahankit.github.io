ऑनलाइन परीक्षण

कॉल या गेम से पहले अपनी इंटरनेट स्पीड, कैमरा, माइक्रोफ़ोन, कीबोर्ड और स्क्रीन की जाँच करें - या अपनी क्लिकिंग, रिफ्लेक्सिस और टाइपिंग का परीक्षण करें। डिवाइस परीक्षण आपके ब्राउज़र में चलते हैं; कुछ भी रिकॉर्ड या अपलोड नहीं किया गया है.

Screen resolution vs. viewport

स्क्रीन रिज़ॉल्यूशन is the size of your whole display. Browsers report it in CSS pixels; multiply by the device pixel ratio to get physical pixels. A 4K monitor at 150% scaling, for example, reports 2560 × 1440 CSS pixels with a ratio of 1.5 (3840 × 2160 physical).

The viewport is the visible area of the web page inside the browser window. Web designers use it to test responsive layouts.

Common resolutions

  • 1920 × 1080 (Full HD, 16:9) — the most common desktop size
  • 1366 × 768 — many budget laptops
  • 2560 × 1440 (QHD) and 3840 × 2160 (4K UHD)
  • 390 × 844 and 412 × 915 — common phone viewports in CSS pixels

How to use the screen resolution

  1. Enter your details. Instantly see your screen resolution, physical pixels, browser viewport size, device pixel ratio, colour depth and orientation. Updates live as you resize.
  2. Get the result. The result updates on the page as you type.
  3. Use or copy it. आउटपुट कॉपी या डाउनलोड करें। कुछ सेव नहीं होता—रीफ़्रेश करके फिर शुरू करें।

अक्सर पूछे जाने वाले प्रश्न

मेरा रिज़ॉल्यूशन मेरे मॉनिटर की विशिष्टता से कम क्यों है?

विंडोज़ या मैकओएस में डिस्प्ले स्केलिंग ब्राउज़र को छोटे सीएसएस आकार की रिपोर्ट बनाती है। भौतिक पिक्सेल वास्तविक पैनल रिज़ॉल्यूशन दिखाता है।

डिवाइस पिक्सेल अनुपात क्या है?

प्रति CSS पिक्सेल भौतिक पिक्सेल की संख्या. रेटिना और हाई-डीपीआई स्क्रीन आमतौर पर 2 या 3 होती हैं।

क्या कोई डेटा एकत्र किया गया है?

नहीं, मान आपके ब्राउज़र से पढ़े जाते हैं और केवल आपको दिखाए जाते हैं।

क्या यह screen resolution मुफ़्त है?

हाँ। screen resolution ब्राउज़र में मुफ़्त है, खाता नहीं चाहिए।

क्या मेरा डेटा डिवाइस से बाहर जाता है?

इस साइट के ज़्यादातर टूल आपका इनपुट आपके डिवाइस पर ही प्रोसेस करते हैं। अगर कोई टूल सार्वजनिक API कॉल करता है (जैसे डोमेन आयु), तो यह पेज पर लिखा होता है।
