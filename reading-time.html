Frequently asked questions

What WPM should I use?

200 words per minute is a common default for English prose; adjust down for dense or technical content.

Is this reading time free?

Yes. The reading time is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
