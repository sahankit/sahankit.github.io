Beautify, then read and debug

Paste minified or badly indented code and press Beautify. The formatter (powered by the open-source js-beautify library) re-indents nested tags, CSS rules and JavaScript blocks, and also formats CSS and scripts embedded in HTML. Choose 2 spaces, 4 spaces or tabs to match your project.

Minify for production

  • HTML — removes comments and indentation whitespace while keeping <pre>, <textarea> and <script> content intact.
  • CSS — strips comments, spaces and the last semicolon in each rule.
  • JSON — removes all whitespace.
  • JavaScript — use a build tool such as Terser or esbuild; safe JS minification needs a full parser.

How to use the HTML formatter

  1. Enter your details. Fill in Language, Indent, Paste your code and Result.
  2. Get the result. Press Beautify. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Does formatting change how my page works?

Beautifying only changes whitespace. Minifying HTML collapses extra spaces, which almost never changes rendering.

Is my code sent to a server?

No. Formatting happens in your browser; only the formatter library is downloaded.

Can it fix broken HTML?

It indents what you give it but doesn’t repair missing tags. Validate with the W3C validator if needed.

Is this HTML formatter free?

Yes. The HTML formatter is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
