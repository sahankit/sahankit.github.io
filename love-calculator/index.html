How the FLAMES game works

  • Write both names and cross out letters they have in common, one for one.
  • Count the letters that are left.
  • Count through the word F-L-A-M-E-S using that number, crossing out the letter you land on.
  • Start counting again from the next letter, repeating until one letter remains.
  • F = Friends, L = Lovers, A = Affection, M = Marriage, E = Enemies, S = Siblings.

Just for fun

The love percentage is calculated from the letters in both names, so the same pair always gets the same score, whichever order you type them. It isn’t science—real compatibility is about respect, communication and shared values. Names are never stored or sent anywhere.

How to use the love calculator

  1. Enter your details. Fill in Your name and Their name.
  2. Get the result. Press Calculate love. Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Does the order of names matter?

No. Swapping the names gives the same percentage and FLAMES result.

Are the names saved?

No. Everything happens in your browser.

Why is my FLAMES result “Same name”?

If every letter cancels out, there are no letters left to count.

Is this love calculator free?

Yes. The love calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
