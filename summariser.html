Chrome built-in AI summariser

This tool calls the browser’s Summarizer API (Gemini Nano). Your text is not sent to Sahankit—we do not run a summarization server.

Requires desktop Chrome with built-in AI (Gemini Nano) and enough free disk space. Processing happens on your device—not on Sahankit servers.

Summary types

Key points — bullet-style takeaways. TL;DR — one or two sentences. Headline — title-style line. Teaser — short promo blurb.

Frequently asked questions

Why does it say unavailable?

Use desktop Chrome, free disk space (~GB for the model), and flags such as summarizer-api-for-gemini-nano if the API is off.

Is this the same as ChatGPT?

No. It uses Google’s on-device model in Chrome, not a cloud chat account.

Can I summarise PDFs?

Copy text from the PDF first, or use our PDF to Word tool to extract text, then paste here.

Is this AI summariser free?

Yes. The AI summariser is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
