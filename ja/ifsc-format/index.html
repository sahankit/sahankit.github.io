IFSC format reference (11 characters)

Indian Financial System Code identifies bank and branch for NEFT/RTGS/IMPS: AAAA0BBBBBB (4 bank + 0 + 6 branch).

SegmentRuleExample
1–4Bank code (letters)HDFC
5Always 00
6–11Branch code (alphanumeric)000123

IFSC 構造 (フォーマットのみ)

インドの金融システム コードは 11 文字で構成されています。4 つの銀行文字、1 つのゼロ、そして 6 つの支店文字です。このチェッカーは形状のみを検証します。ライブブランチを確認するには、銀行または RBI ソースを使用します。

  • 例（パターン）： HDFC0000123 — HDFC bank, branch segment 000123
  • よくある間違い: 10 文字を使用するか、5 番目の文字を交換します (標準コードでは 0 でなければなりません)

IFSCフォーマットチェックの使用方法

  1. 詳細を入力してください。 IFSC コードを入力します。
  2. 結果を取得します。 [フォーマットの確認] を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

IFSC 形式チェックを使用する場合

IFSC コードが標準の 11 文字形式と一致するかどうかを確認します。打点での検証は行っておりません。ソフトウェアをインストールしたりアカウントを作成したりせずに、迅速な回答が必要な場合に使用してください。

ツールがサポートしているブラウザではすべてがローカルで実行されるため、フォーム、請求書、調査、外出先での簡単なチェックに役立ちます。

よくある質問

これによりブランチが存在することが確認されますか?

いいえ。コードが通常のパターンと一致するかどうかをチェックするだけです。

IFSC は SWIFT と同じですか?

いいえ、IFSC はインド国内の NEFT/RTGS/IMPS を対象としています。国際電線にはSWIFT/BICが使用されます。

この IFSC 形式チェックは無料ですか?

はい。 IFSC 形式チェックは、アカウントを必要とせずにブラウザで無料で使用できます。

データはこの端末から出ますか？

IFSC 形式チェックはモバイルでも機能しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
