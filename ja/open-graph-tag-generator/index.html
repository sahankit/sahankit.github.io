オープングラフジェネレーターについて

リンク プレビュー用の Open Graph および Twitter Card メタ タグを生成します。ページヘッダーの HTML をコピーします。

ブラウザで動作—登録もインストールも不要。

オープングラフジェネレーターの使用方法

  1. 詳細を入力してください。 og:title 、 og:description 、 og:url 、および og:image URL を入力します。
  2. 結果を取得します。 [タグの生成] を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。
