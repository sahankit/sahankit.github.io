Frequently asked questions

私の履歴書はオンラインで保存されますか?

いいえ。PDF をダウンロードしない限り、コンテンツはブラウザーに残ります。

ATSに使用できますか?

レイアウトはシンプルなテキストと見出しであり、ATS のベースラインとして適しています。厳密なパーサーの場合は表やグラフィックを避けてください。

Is this resume builder free?

Yes. The resume builder is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
