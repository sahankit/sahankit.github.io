JSON から XML への変換について
ブラウザーでフラットな JSON オブジェクトを単純な XML 文字列に変換します。深くネストされたスキーマには向きません。
ブラウザで動作—登録もインストールも不要。
JSON を XML に使用する方法
  1. 詳細を入力してください。 JSON を入力します。
  2. 結果を取得します。 [変換] を押します。結果はページ上で更新され、値を編集すると再計算されます。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。
よくある質問
これ JSON から XML への変換は無料ですか?
はい。 JSON から XML への変換は、アカウントを必要とせずにブラウザーで無料で使用できます。
データはこの端末から出ますか？
ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。
JSON から XML への変換はモバイルでも機能しますか?
はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
