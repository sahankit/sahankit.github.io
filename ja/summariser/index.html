Chrome built-in AI summariser

This tool calls the browser’s Summarizer API (Gemini Nano). Your text is not sent to Sahankit—we do not run a summarization server.

Requires desktop Chrome with built-in AI (Gemini Nano) and enough free disk space. Processing happens on your device—not on Sahankit servers.

Summary types

Key points — bullet-style takeaways. TL;DR — one or two sentences. Headline — title-style line. Teaser — short promo blurb.

How to use the AI summariser

  1. Paste your text. テキスト ボックスに記事、メモ、または英語の一節を追加します。
  2. Choose type and length. 重要なポイント、TL;DR、見出し、またはティーザー、および短、中、または長の出力を選択します。
  3. Click Summarise. Chrome は必要に応じてオンデバイス モデルをダウンロードし、概要を書き込みます。結果をコピーまたは編集します。

よくある質問

利用不可と表示されるのはなぜですか?

デスクトップ Chrome、空きディスク容量 (モデルの場合は ~GB)、API がオフの場合は summaryer-api-for-gemini-nano などのフラグを使用します。

これはChatGPTと同じですか？

いいえ。クラウド チャット アカウントではなく、Chrome の Google オンデバイス モデルを使用します。

PDFを要約することはできますか?

まず PDF からテキストをコピーするか、PDF to Word ツールを使用してテキストを抽出し、ここに貼り付けます。

AIサマライザーは無料ですか？

はい。AIサマライザーはブラウザで無料、登録不要です。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。
