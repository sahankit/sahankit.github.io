ブラウザはディスプレイと同期してアニメーション フレームを描画します。テストでは数百のフレームを測定し、ギャップの中央値を取得します。約 16.7 ミリ秒は 60 Hz、8.3 ミリ秒は 120 Hz、6.9 ミリ秒は 144 Hz、4.2 ミリ秒は 240 Hz です。ドロップされたフレームは、デバイスが対応できなかったときに表示されます。

テストでの Hz の測定方法

ブラウザはディスプレイと同期してアニメーション フレームを描画します。テストでは数百のフレームを測定し、ギャップの中央値を取得します。約 16.7 ミリ秒は 60 Hz、8.3 ミリ秒は 120 Hz、6.9 ミリ秒は 144 Hz、4.2 ミリ秒は 240 Hz です。ドロップされたフレームは、デバイスが対応できなかったときに表示されます。

移動する四角形はフレーム マーカーの跡を残します。リフレッシュ レートが高いと、マーカーがより近くに配置され、動きがよりスムーズに見えます。

144 Hz のモニターで 60 Hz が表示されますか?

  • Windows (設定 → ディスプレイ → 詳細表示) または macOS (システム設定 → ディスプレイ) でリフレッシュ レートを設定します。
  • 高リフレッシュ レートをサポートする DisplayPort または HDMI 2.0+ ケーブルを使用してください。
  • バッテリーセーバーをオフにしてください。ラップトップでは、多くの場合、バッテリーの上限が 60 Hz になります。
  • 複数のモニターを使用している場合は、ブラウザー ウィンドウを高リフレッシュ画面に移動します。

リフレッシュ レート テストの使用方法

  1. 詳細を入力してください。 オンラインで画面のリフレッシュ レートを Hz で確認します。モーション テストを使用して、1 秒あたりのフレーム数、フレーム時間、ドロップされたフレームを確認します。 120 Hz、144 Hz、または 240 Hz のモニターを確認します。
  2. 結果を取得します。 もう一度「測定」を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

よくある質問

結果は正確ですか?

ほとんどの設定ではい。ブラウザが実際に表示している内容を報告します。可変リフレッシュ (G-Sync/FreeSync) および省電力により、わずかな変動が発生する可能性があります。

なぜ30Hzと書かれているのでしょうか？

一部のブラウザーは、バックグラウンド タブまたは低電力モードを抑制します。タブを前にしてラップトップを接続します。

電話でも機能しますか?

はい。電話機がバッテリー セーバー モードではない場合、90 Hz および 120 Hz の電話機のディスプレイを検出します。

このリフレッシュ レート テストは無料ですか?

はい。リフレッシュ レート テストは、アカウントを必要とせずにブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。
