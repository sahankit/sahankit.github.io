完全な体験をご希望ですか?を使用します。 AIサマライザー ページ（同じ Chrome Summarizer API）。

AIサマライザーの使い方

  1. 詳細を入力してください。 [概要のタイプ] と [長さ] を入力します。
  2. 結果を取得します。 [要約] を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

AI サマライザーを使用する場合

Chrome の組み込み Summarizer API を使用して長いテキストを要約します。重要なポイントはデバイス上に残ります。ソフトウェアをインストールしたりアカウントを作成したりせずに、迅速な回答が必要な場合に使用してください。

ツールがサポートしているブラウザではすべてがローカルで実行されるため、フォーム、請求書、調査、外出先での簡単なチェックに役立ちます。
