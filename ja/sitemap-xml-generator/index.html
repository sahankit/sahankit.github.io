About the sitemap generator

Generate a basic sitemap.xml from a list of page URLs. Free XML sitemap builder for small sites.

Runs in your browser—no signup and no install.

How to use the sitemap generator

  1. Enter your details. Fill in サイトのベースURL そして ページのパスまたは完全な URL (1 行に 1 つ).
  2. Get the result. Press sitemap.xml を生成する. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this sitemap generator free?

Yes. The sitemap generator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
