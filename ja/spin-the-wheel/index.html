How to use the wheel

Type or paste entries into the box, one per line—names for a classroom, prizes for a giveaway, places to eat, or chores. The wheel redraws as you type. Press Spin (or tap the centre) and the pointer at the top picks the winner.

Tick 各スピン後に勝者を削除します to draw several unique winners in a row, like picking teams or raffle prizes. Your list is saved in this browser so it is still there next time.

Is it really random?

Each spin uses your browser’s cryptographic random number generator (crypto.getRandomValues) to choose the spin strength and stopping angle, so every entry has an equal chance. The animation is only for show—the result is decided fairly.

よくある質問

エントリはいくつ追加できますか?

最大 300。長い名前はホイール上で短縮されますが、勝利すると完全に表示されます。

1 つのオプションに大きなチャンスを与えることはできますか?

はい。複数行に追加します。各ラインはホイールの 1 つの等しいスライスです。

プレゼントに使ってもいいですか？

はい。参加者リストを貼り付け、勝者の削除を有効にし、賞品ごとに 1 回スピンします。透明性を高めるためにスピンを画面録画します。

spin the wheelは無料ですか？

はい。spin the wheelはブラウザで無料、登録不要です。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。
