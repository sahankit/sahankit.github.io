よくある質問

私が先にプレイしますか？

はい。あなたは X で、コンピューターが O をプレイする前に、3×3 ボード上の正方形をタップします。

コンピューターは無敵ですか？

即時の勝利を阻止しますが、完璧ではありません。良い動きをすれば勝てます。

この三目並べは無料ですか？

はい。三目並べは、アカウントを必要とせずにブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。

三目並べはモバイルでも動作しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
