スクリーンPPIについて

画面解像度と対角サイズ (インチ単位) から 1 インチあたりのピクセル数 (PPI) を計算します。

ブラウザで動作—登録もインストールも不要。

スクリーンPPIの使い方

  1. 詳細を入力してください。 幅 (px) 、高さ (px) 、対角線 (インチ) を入力します。
  2. 結果を取得します。 PPI を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

この画面は PPI フリーですか?

はい。スクリーン PPI は、アカウントを必要とせずにブラウザで無料で使用できます。

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。

スクリーン PPI はモバイルでも機能しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
