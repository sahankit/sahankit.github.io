独占的 vs 包括的 GST

金額に GST が含まれていない場合、ツールは税金を上乗せします。金額にすでに GST が含まれている場合は、課税対象額と税額が差し引かれます。これは、GST 込みとマークされた請求書に役立ちます。

  • 独占 ₹1,000 @ 18%: GST ₹180 → 合計 ₹1,180
  • 込み ₹1,180 @ 18%: 課税対象 ≈ ₹1,000、GST ≈ ₹180
  • 州内の B2B: 多くの場合、CGST + SGST (それぞれ半分のレート) として表示されます。州間では IGST が使用されます。

How to use the GST calculator

  1. 詳細を入力してください。 金額 (₹) と GST 率 (%) を入力します。
  2. 結果を取得します。 [計算] を押します。結果はページ上で更新され、値を編集すると再計算されます。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

よくある質問

どの GST レートがサポートされていますか?

インドで一般的なスラブ率である 5%、12%、18%、28% のクイック プリセット。

込み込み価格から GST を削除するにはどうすればよいですか?

同じレートのプリセットに対して GST 包括計算機または逆算 GST 計算機を開きます。

これは確定申告用ですか？

いいえ。コンプライアンスのためには公式の GST ポータルと CA を使用してください。これは簡単な数学ヘルパーです。

これは私の GSTIN を検証しますか?

いいえ。GSTIN 形式チェッカーはパターン検証のみに使用してください。

このGST 計算機は無料ですか?

はい。 GST 計算機は、アカウントを必要とせずにブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。
