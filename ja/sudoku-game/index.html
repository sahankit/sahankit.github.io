About the sudoku game

Play Sudoku in the browser. Fill the grid so each row, column and 3×3 box has digits 1–9 once.

ブラウザで動作—登録もインストールも不要。

How to use the sudoku game

  1. Enter your details. Play Sudoku in the browser. Fill the grid so each row, column and 3×3 box has digits 1–9 once.
  2. Get the result. Press Check . Results update on the page.
  3. Use or copy it. 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

よくある質問

新しいパズルが生まれるでしょうか？

今日、新しいパズルが同じ簡単なスターター グリッドをリロードします。新しいパズルを使用してエントリをクリアし、もう一度試してください。

チェックって何をするの？

塗りつぶされたセルを解決策と比較し、何かが間違っているか不完全かどうかを示します。

sudoku gameは無料ですか？

はい。sudoku gameはブラウザで無料、登録不要です。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。
