タイピング速度テストの使い方

  1. 詳細を入力してください。 ここにタイプを入力します。
  2. 結果を取得します。 [新しいテスト] を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

タイピング速度テストをいつ使用するか

1分間のタイピングテスト。ブラウザーで 1 分あたりの単語数と精度を測定します。ソフトウェアをインストールしたりアカウントを作成したりせずに、迅速な回答が必要な場合に使用してください。

ツールがサポートしているブラウザではすべてがローカルで実行されるため、フォーム、請求書、調査、外出先での簡単なチェックに役立ちます。

よくある質問

優れた WPM とは何ですか?

日常使用では 40 ～ 60 WPM が一般的です。 70以上はオフィスワークとしては速いです。

このタイピング速度テストは無料ですか?

はい。タイピング速度テストは、アカウントを必要とせずにブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。

タイピング速度テストはモバイルでも機能しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
