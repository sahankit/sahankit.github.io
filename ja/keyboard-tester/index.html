All online tests

Check your internet speed, camera, microphone, keyboard and screen before a call or game—or test your clicking, reflexes and typing. Device tests run in your browser; nothing is recorded or uploaded.

How to find broken keys

Press every key one by one. Working keys turn green and stay marked, so any key that never lights up is not registering. If a key stays purple after you let go, it may be sticking. The counter shows how many different keys you have tested.

The panel also shows event.key, event.code and keyCode—useful for developers and for checking a keyboard layout.

Limits of browser keyboard tests

Some keys are reserved by the operating system or browser and never reach web pages—for example Fn, Print Screen on some systems, and shortcuts like Ctrl+W or Cmd+Q. Media keys vary by device.

How to use the keyboard tester

  1. Enter your details. Free online keyboard tester. Press keys to check they work: keys light up while held and stay marked once tested. Shows event key, code and keyCode.
  2. Get the result. Press Reset test . Results update on the page.
  3. Use or copy it. 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

よくある質問

キー ロールオーバー (NKRO) をテストできますか?

複数のキーを同時に押します。押したキーがそれぞれ点灯します。一部が点灯しなくなった場合は、キーボードのロールオーバー制限に達しています。

Fnキーが表示されないのはなぜですか?

Fn はキーボード ハードウェア内で処理され、ブラウザには報告されません。

私が入力した内容は記録されますか?

いいえ。キーの押下はこのページにのみ表示され、どこにも送信されることはありません。

keyboard testerは無料ですか？

はい。keyboard testerはブラウザで無料、登録不要です。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。
