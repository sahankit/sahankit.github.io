分割について PDF

ブラウザで PDF からページ範囲を抽出します。 pdf-lib によるプライベート分割 - サーバーへのアップロードはありません。

ブラウザで動作—登録もインストールも不要。

分割の使い方 PDF

  1. 詳細を入力してください。 デバイスからファイルを選択します。ローカルで処理され、このサイトにアップロードされることはありません。
  2. 結果を取得します。 [分割してダウンロード] を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

よくある質問

この分割 PDF は無料ですか?

はい。分割された PDF は、アカウントを必要とせずにブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。

分割 PDF はモバイルでも機能しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
