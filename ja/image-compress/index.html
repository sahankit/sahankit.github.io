画像圧縮器

JPG または PNG をドラッグし、スライダーで JPEG 品質を設定し、より小さいファイルをダウンロードします。正確な KB の上限 (例: 20 KB の署名または 50 KB の検査写真) については、以下にリンクされている画像サイズを KB 単位で縮小するツールを使用してください。

PDFを圧縮する

PDF サイズを縮小し、プライベートにします。

フォームの場合は画像を 50 KB または 100 KB 未満に圧縮します

政府機関や試験ポータルでは、最小サイズを維持しながら、写真のアップロードを 20 ～ 50 KB に制限していることがよくあります。このコンプレッサーは、選択した品質 (ポートレートの場合は約 0.6 ～ 0.75) で JPEG に再エンコードすることでファイル サイズを削減します。

正確なターゲットが必要ですか?開く 画像サイズをKB単位で削減します オプションの幅×高さの制限を使用して、20 KB、50 KB、または 100 KB に達します。

プライベート圧縮 (クラウドアップロードなし)

画像がキャンバスに描画され、ブラウザーで JPEG としてエクスポートされます。 ToolHQ サーバーには何も送信されません。ID 証明、署名、コースワークのスキャンに適しています。

画像圧縮ソフトの使い方

  1. 詳細を入力してください。 デバイスからファイルを選択します。ローカルで処理され、このサイトにアップロードされることはありません。
  2. 結果を取得します。 [圧縮してダウンロード] を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

よくある質問

50 KB 未満の写真を圧縮するにはどうすればよいですか?

品質スライダーを下げてダウンロードします。それでも大きすぎる場合は、ターゲット 50 で画像サイズを KB 単位で削減し、最初に余分な背景をトリミングします。

PNGサポート?

PNG をアップロードできます。出力は小さいサイズの JPEG です。 JPEGでは透明が白になります。

圧縮すると幅と高さが変わりますか?

このツールは元のピクセルを保持し、JPEG 品質のみを変更します。寸法を変更するには、画像サイズ変更ツールを使用するか、KB ツールで画像サイズを縮小します。

この画像圧縮ソフトは無料ですか?

はい。画像圧縮ツールは、アカウントを必要とせずにブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。
