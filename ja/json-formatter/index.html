JSON を安全にフォーマットまたは縮小する

API 応答または設定ファイルを貼り付けます。形式は読みやすいインデントを追加します。縮小すると余分な空白が削除されます。無効な JSON では、サイレントに失敗するのではなく、解析エラーが表示されます。

JSON フォーマッタの使用方法

  1. 詳細を入力してください。 JSON を入力します。
  2. 結果を取得します。 フォーマット を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

JSON フォーマッタを使用する場合

ブラウザで JSON をフォーマットして検証します。エラーメッセージ付きの無料のJSON きれいなプリンター。ソフトウェアをインストールしたりアカウントを作成したりせずに、迅速な回答が必要な場合に使用してください。

ツールがサポートしているブラウザではすべてがローカルで実行されるため、フォーム、請求書、調査、外出先での簡単なチェックに役立ちます。

よくある質問

私の JSON はどこかに送信されますか?

解析と書式設定はブラウザーのタブでのみ行われます。

このJSON フォーマッタは無料ですか?

はい。 JSON フォーマッタは、アカウントを必要とせずにブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。

JSON フォーマッタはモバイルでも動作しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
