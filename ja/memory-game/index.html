Frequently asked questions

どうすれば勝てますか？

一度に 2 枚のカードを裏返します。両方が同じ絵文字を表示する場合、表向きのままになります。ボード全体をクリアします。

私のベストスコアを追跡しますか?

このセッションのみ。更新すると、新しいシャッフルが開始されます。

Is this memory game free?

Yes. The memory game is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
