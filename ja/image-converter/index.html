画像形式をプライベートに変換する

画像をキャンバスに描画し、必要な MIME タイプをエクスポートします。 JPEG 変換により、透明度が白い背景に均一になります。

WebP と AVIF はブラウザのサポートに依存します。オプションが無効になっている場合は、代わりに PNG または JPEG を使用してください。

イメージコンバーターの使い方

  1. 詳細を入力してください。 デバイスからファイルを選択します。ローカルで処理され、このサイトにアップロードされることはありません。
  2. 結果を取得します。 [変換してダウンロード] を押します。結果はページ上で更新され、値を編集すると再計算されます。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

イメージコンバーターを使用する場合

ブラウザで画像を PNG、JPEG、WebP、AVIF の間で変換します。プライベート — ファイルがデバイスから流出することはありません。ソフトウェアをインストールしたりアカウントを作成したりせずに、迅速な回答が必要な場合に使用してください。

ツールがサポートしているブラウザではすべてがローカルで実行されるため、フォーム、請求書、調査、外出先での簡単なチェックに役立ちます。

よくある質問

ファイルはアップロードされていますか?

いいえ。変換はブラウザ内でローカルに行われます。

SVGを変換できますか?

ラスター ソース (PNG、JPG、WebP、GIF) を使用します。 SVG は一部のブラウザで動作する可能性がありますが、保証されません。

この画像コンバーターは無料ですか?

はい。画像コンバーターは、アカウントを必要とせずにブラウザーで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。

画像コンバーターはモバイルでも動作しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
