よくある質問

間違った推測は何回ありますか?

6つの命。文字を間違えるたびに 1 つの命が失われます。

言葉は子供に適していますか？

単語は一般的な英語の名詞であり、大人向けのテーマはありませんが、難易度は異なります。

このハングマン ゲームは無料ですか?

はい。 Hangman ゲームは、アカウントを必要とせずにブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。

ハングマン ゲームはモバイルでも動作しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
