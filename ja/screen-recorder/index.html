画面を録画する方法

  • タブ/システムオーディオとマイクを含めるかどうかにチェックを入れます。
  • プレス 録音を開始する をクリックして、画面全体、ウィンドウ、またはブラウザのタブを選択します。
  • チュートリアル、プレゼンテーション、バグレポート、ゲームクリップなど、キャプチャしたいものを実行します。
  • プレス 録音を停止する (またはブラウザ バーの [共有を停止])、ビデオをプレビューしてダウンロードします。

オーディオ、フォーマット、サポート

Chrome と Edge ではブラウザ タブから音声をキャプチャでき、Windows ではシステム全体から音声をキャプチャできます。 macOS ではタブオーディオのみが許可されます。マイクを追加してナレーションを行います。ビデオは WebM (ブラウザがサポートしている場合は MP4) として保存され、Chrome、Edge、Firefox、VLC で再生され、YouTube に直接アップロードされます。

画面の録画にはデスクトップ ブラウザが必要です。モバイル ブラウザでは Web サイトで画面をキャプチャできません。

スクリーンレコーダーの使い方

  1. 詳細を入力してください。 システムオーディオとマイクを使用して、画面、ウィンドウ、ブラウザタブをオンラインで録画します。ダウンロード、ウォーターマーク、時間制限はありません。ビデオをデバイスに保存します。
  2. 結果を取得します。 [録音開始] を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

よくある質問

ウォーターマークや時間制限はありますか?

どちらでもない。録音の長さはデバイスのメモリによってのみ制限されます。

音が出ないのはなぜですか?

ブラウザの共有ダイアログで「タブオーディオを共有」または「システムオーディオを共有」にチェックが入っていることを確認してください。 macOS はタブオーディオのみをサポートします。

私の録音はアップロードされていますか?

いいえ。ビデオは作成され、ダウンロードするまでブラウザ内に保存されます。

このスクリーンレコーダーは無料ですか?

はい。スクリーンレコーダーはアカウント不要でブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。
