Base64 in APIs and configs

Base64 encodes binary data as ASCII text—common in JSON web tokens, data URLs, and email. This tool handles Unicode text via UTF-8 before encoding.

How to use the base64 encode/decode

  1. Enter your details. Fill in Text .
  2. Get the result. Press Encode . Results update on the page.
  3. Use or copy it. 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

入力は有効な Base64 (パディングと文字セット) である必要があります。ログから貼り付けた場合は、余分なスペースや改行を削除します。

base64 encode/decodeは無料ですか？

はい。base64 encode/decodeはブラウザで無料、登録不要です。

データはこの端末から出ますか？
