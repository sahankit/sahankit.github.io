ローカルでテキストを生成する

AI (Gemini Nano) が組み込まれたデスクトップ Chrome と十分な空きディスク容量が必要です。処理はデバイス上で行われます。

AIライターの使い方

  1. 詳細を入力してください。 記入してください何を書けばいいですか？ 、コンテキスト（オプション）、トーンと長さ。
  2. 結果を取得します。 [書き込み] を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

AI ライターを使用する場合

Chrome の組み込み Writer API を使用してプロンプトからテキストを生成します。フォーマルまたはカジュアルなトーン。ソフトウェアをインストールしたりアカウントを作成したりせずに、迅速な回答が必要な場合に使用してください。

ツールがサポートしているブラウザではすべてがローカルで実行されるため、フォーム、請求書、調査、外出先での簡単なチェックに役立ちます。
