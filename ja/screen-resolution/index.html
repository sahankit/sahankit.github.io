Screen resolution vs. viewport

画面解像度 is the size of your whole display. Browsers report it in CSS pixels; multiply by the device pixel ratio to get physical pixels. A 4K monitor at 150% scaling, for example, reports 2560 × 1440 CSS pixels with a ratio of 1.5 (3840 × 2160 physical).

The viewport is the visible area of the web page inside the browser window. Web designers use it to test responsive layouts.

Common resolutions

  • 1920 × 1080 (Full HD, 16:9) — the most common desktop size
  • 1366 × 768 — many budget laptops
  • 2560 × 1440 (QHD) and 3840 × 2160 (4K UHD)
  • 390 × 844 and 412 × 915 — common phone viewports in CSS pixels

よくある質問

解像度がモニターの仕様より低いのはなぜですか?

Windows または macOS での表示スケーリングにより、ブラウザーのレポートの CSS サイズが小さくなります。物理ピクセルは実際のパネル解像度を示します。

デバイスのピクセル比とは何ですか?

CSS ピクセルごとの物理ピクセル数。 Retina および高 DPI スクリーンは通常 2 または 3 です。

データは収集されていますか?

いいえ。値はブラウザから読み取られ、あなたにのみ表示されます。

screen resolutionは無料ですか？

はい。screen resolutionはブラウザで無料、登録不要です。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。
