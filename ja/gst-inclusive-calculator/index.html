GST込み価格計算機

MRP に既に GST が含まれている場合、課税価格 = 包括的 ÷ (1 + 税率%)。例: ₹1,180 (18% 込み) → 約 ₹1,000 課税 + ₹180 GST。

包括的な例と排他的な例の簡単な例

  • ₹1,050 (5% 込み) → 課税対象 ≈ ₹1,000
  • ₹1,120 (12% 込み) → 課税対象 ≈ ₹1,000
  • ₹1,180 (18% 込み) → 課税対象 ≈ ₹1,000
  • ₹1,280 (28% 込み) → 課税対象 ≈ ₹1,000

GST 込み価格の使用方法

  1. 詳細を入力してください。 GST 込みの金額 (₹) と GST 率 (%) を入力します。
  2. 結果を取得します。 分割金額 を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

GST 込み価格を使用する場合

GST込みの価格から課税対象額とGST金額を見つけます。インド GST 税率は 5%、12%、18%、28%。ソフトウェアをインストールしたりアカウントを作成したりせずに、迅速な回答が必要な場合に使用してください。

ツールがサポートしているブラウザではすべてがローカルで実行されるため、フォーム、請求書、調査、外出先での簡単なチェックに役立ちます。

よくある質問

CGST と SGST 対 IGST?

このツールは合計 GST を分割します。請求書には、供給場所ごとに正しい CGST/SGST または IGST ラベルが必要です。

逆GST電卓との違いは？

どちらも税込み金額から税金を差し引いています。ワークフローに合ったページを使用してください。

この GST 込みの価格は無料ですか?

はい。 GST 込みの価格は、アカウントを必要とせずにブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。

GST 込みの価格はモバイルでも機能しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
