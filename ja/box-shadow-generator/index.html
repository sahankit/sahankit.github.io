ボックスシャドウジェネレーターの使い方

  1. 詳細を入力してください。 水平オフセット (px) 、垂直オフセット (px) 、ぼかし (px) 、スプレッド (px) 、カラー を入力します。
  2. 結果を取得します。 入力すると、ページ上の結果が更新されます。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

ボックス シャドウ ジェネレーターを使用する場合

オフセット、ブラー、スプレッド、カラー、インセットを使用して CSS ボックスシャドウを構築し、宣言をコピーします。ブラウザでプレビューが更新されます。ソフトウェアをインストールしたりアカウントを作成したりせずに、迅速な回答が必要な場合に使用してください。

ツールがサポートしているブラウザではすべてがローカルで実行されるため、フォーム、請求書、調査、外出先での簡単なチェックに役立ちます。

よくある質問

CSS で 16 進カラーを使用できますか?

コピーされた行は rgba を使用しているため、不透明度スライダーが含まれています。カラー ピッカーは 16 進値から開始して変換します。

このボックス シャドウ ジェネレーターは無料ですか?

はい。ボックス シャドウ ジェネレーターは、アカウントを必要とせずにブラウザーで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。

ボックス シャドウ ジェネレーターはモバイルでも動作しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
