Chrome でのプライベート翻訳

AI が組み込まれたデスクトップ Chrome と十分な空きディスク容量が必要です。テキストは Sahankit サーバーではなく、デバイス上で処理されます。

言語パックは、翻訳するペアごとに初回使用時にダウンロードされます。

AI翻訳機の使い方

  1. 詳細を入力してください。 Text 、 From 、 To 、 Translation を入力します。
  2. 結果を取得します。 [翻訳] を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

AI トランスレーターを使用する場合

Chrome の Translator API を使用してテキストを翻訳します。プライベートなオンデバイス翻訳 - Sahankit へのアップロードはありません。ソフトウェアをインストールしたりアカウントを作成したりせずに、迅速な回答が必要な場合に使用してください。

ツールがサポートしているブラウザではすべてがローカルで実行されるため、フォーム、請求書、調査、外出先での簡単なチェックに役立ちます。

はい。 AI 翻訳者は、アカウントを必要とせずにブラウザで無料で使用できます。
