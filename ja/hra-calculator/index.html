HRA 免除の計算方法

旧所得税制度に基づく多くの給与所得者の場合、非課税 HRA は、実際に受け取った HRA、支払った家賃から基本給の 10% を差し引いた金額、および基本給 (都市部) の 50% または基本給 (非都市部) の 40% の少なくとも 3 つの金額となります。

HRA が多額の控除である場合に、これを所得税計算ツールと併用して、新制度と旧制度を比較します。

HRA 計算ツールの使用方法

  1. 詳細を入力してください。 基本給 (年間 ₹) 、受け取った HRA (年間 ₹) および支払った家賃 (年間 ₹) を入力します。
  2. 結果を取得します。 [免除の計算] を押します。結果はページ上で更新され、値を編集すると再計算されます。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

HRA 計算ツールを使用する場合

インドの給与所得者の HRA 税控除を計算します。メトロと非メトロ、基本給と支払われた家賃。ソフトウェアをインストールしたりアカウントを作成したりせずに、迅速な回答が必要な場合に使用してください。

ツールがサポートしているブラウザではすべてがローカルで実行されるため、フォーム、請求書、調査、外出先での簡単なチェックに役立ちます。

よくある質問

HRA は新しい税制に適用されますか?

一般に、HRA の免除は新しい制度では利用できません。このツールは古い体制の計画用です。

家賃の領収書は必須ですか？

雇用主と税務署は、請求される HRA の家賃契約書と領収書を要求する場合があります。このページは計算上の推定値のみです。

この HRA 計算ツールは無料ですか?

はい。 HRA 計算ツールは、アカウントを必要とせずにブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。

HRA 計算ツールはモバイルでも機能しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
