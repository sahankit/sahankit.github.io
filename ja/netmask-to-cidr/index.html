マスクの使い方→CIDR

  1. 詳細を入力してください。 サブネットマスクを入力します。
  2. 結果を取得します。 [変換] を押します。結果はページ上で更新され、値を編集すると再計算されます。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

マスクを使用する場合 → CIDR

ドット付きサブネット マスクを CIDR プレフィックス長に変換します。ソフトウェアをインストールしたりアカウントを作成したりせずに、迅速な回答が必要な場合に使用してください。

ツールがサポートしているブラウザではすべてがローカルで実行されるため、フォーム、請求書、調査、外出先での簡単なチェックに役立ちます。

よくある質問

このマスク→CIDRフリーですか？

はい。マスク → CIDR はアカウント不要でブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。

マスク → CIDR はモバイルでも機能しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
