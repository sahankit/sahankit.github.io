PDF と画像

Word から PDF (DOCX)

.docx ファイルをアップロードします。 mammoth で HTML に変換し、html2pdf.js で PDF をすべてデバイス上でレンダリングします。

ファイルはデバイス上に残ります。複雑なレイアウト、画像、表は完全に転送できない場合があります。テキストの多いドキュメントに最適です。

アップロード .docx only (modern Word). Legacy .doc is not supported—save as DOCX in Word or Google Docs first.

DOCX からローカルで PDF へ

.docx ファイルをアップロードします。 mammoth で HTML に変換し、html2pdf.js で PDF をすべてデバイス上でレンダリングします。

従来の .doc ファイルはサポートされていません。まず Word で開き、.docx として保存します。

Word を使用して PDF を作成する方法

  1. 詳細を入力してください。 デバイスからファイルを選択します。ローカルで処理され、このサイトにアップロードされることはありません。
  2. 結果を取得します。 「PDFに変換」を押します。結果はページ上で更新され、値を編集すると再計算されます。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

「PDF」という言葉をいつ使用するか

ブラウザで Word の .docx ファイルを PDF に変換します。 Mammoth と html2pdf を使用したプライベート変換 - クラウド アップロードなし。ソフトウェアをインストールしたりアカウントを作成したりせずに、迅速な回答が必要な場合に使用してください。

ツールがサポートしているブラウザではすべてがローカルで実行されるため、フォーム、請求書、調査、外出先での簡単なチェックに役立ちます。

よくある質問

これは .doc をサポートしていますか?

.docx (Office Open XML) のみ。変換する前に、古い .doc ファイルを .docx として保存します。

画像は保存されていますか？

DOCX に埋め込まれた画像は通常、保存されます。非常に複雑なレイアウトは PDF 内でわずかにずれる場合があります。

PDF へのこの単語は無料ですか?

はい。 Word to PDF は、アカウントを必要とせずにブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。

PDF という言葉はモバイルでも機能しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
