MFリターンについて

一時金、期待される年間収益、および年数から投資信託の価値を予測します。説明のみであり、SEBI のアドバイスではありません。

ブラウザで動作—登録もインストールも不要。

MFリターンの使い方

  1. 詳細を入力してください。 投資 (₹) 、期待収益率 (% p.a.) および年 を入力します。
  2. 結果を取得します。 「プロジェクト」を押します。ページに結果を更新しました。
  3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

よくある質問

このMFの返品は無料ですか？

はい。 MF リターンは、アカウントを必要とせずにブラウザで無料で使用できます。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。

MF リターンはモバイルでも機能しますか?

はい。ページは応答性が高く、ツールはデスクトップと同じようにモバイル ブラウザーで実行されます。
