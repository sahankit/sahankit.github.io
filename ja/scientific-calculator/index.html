関数電卓

sin、cos、tan、log、ln、べき乗、ルート、階乗、度/ラジアンモード、履歴を備えた無料のオンライン関数電卓。キーボードとタッチで動作します。

    この電卓でできること

    • 三角法 — sin、cos、tan を度またはラジアンで表示します (DEG/RAD をタップ)。逆関数の場合は、asin、acos、または atan と入力します。
    • 丸太と根 — log (基数 10)、ln (自然対数)、√ 平方根、立方根の cbrt。
    • 権力 — x² および xʸ、EXP を含む科学表記法 (たとえば、6.02E23)。
    • 階乗とパーセント — 5！ = 120、50% は 0.5 と読み取られます。
    • 定数とメモリ — π、e、Ans (最後の結果)、および最後の 10 回の計算の履歴。

    操作の順序

    式は標準的な優先順位に従います。最初に括弧、次にべき乗、次に乗算と除算、次に加算と減算です。累乗は右結合であるため、2^3^2 = 2^9 = 512、および −2^2 = −4 となります。暗黙の乗算も機能します。2π、3(4+1)、2sin(30) はすべて有効です。不足している右括弧は自動的に追加されます。

    コンピュータでは、式全体を入力して Enter キーを押します。乗算には * または x を、除算には / を使用します。

    関数電卓の使い方

    1. 詳細を入力してください。 式 を入力します。
    2. 結果を取得します。 入力すると、ページ上の結果が更新されます。
    3. 使用またはコピーしてください。 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

    よくある質問

    sin(30) では 0.5 が得られるのに、sin(π/6) では別の値が得られるのはなぜですか?

    計算機は度モードで開始するため、sin(30) は 30° を意味します。 π/6 などのラジアンを使用する前に、DEG をタップして RAD に切り替えます。

    科学表記法を入力するにはどうすればよいですか?

    EXP キーを使用するか、大文字の E を入力します (たとえば、3.2 × 10⁻⁵ の場合は 3.2E-5)。

    私の履歴は保存されていますか?

    履歴はページが開いている間のみ保持されます。サーバーには何も送信されません。

    この関数電卓は無料ですか?

    はい。関数電卓は、アカウントを必要とせずにブラウザで無料で使用できます。

    データはこの端末から出ますか？

    ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。
