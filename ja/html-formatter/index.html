Beautify, then read and debug

Paste minified or badly indented code and press 美しくする. The formatter (powered by the open-source js-beautify library) re-indents nested tags, CSS rules and JavaScript blocks, and also formats CSS and scripts embedded in HTML. Choose 2 spaces, 4 spaces or tabs to match your project.

Minify for production

  • HTML — removes comments and indentation whitespace while keeping <pre>, <textarea> and <script> content intact.
  • CSS — strips comments, spaces and the last semicolon in each rule.
  • JSON — removes all whitespace.
  • JavaScript — use a build tool such as Terser or esbuild; safe JS minification needs a full parser.

How to use the HTML formatter

  1. Enter your details. Fill in Language , Indent , Paste your code and Result .
  2. Get the result. Press Beautify . Results update on the page.
  3. Use or copy it. 結果をコピーまたはダウンロード。保存されません。再読み込みでやり直し。

よくある質問

書式設定によりページの動作が変わりますか?

美化は空白部分のみを変更します。 HTML を縮小すると余分なスペースが折りたたまれますが、レンダリングが変わることはほとんどありません。

私のコードはサーバーに送信されますか?

いいえ。フォーマットはブラウザ内で行われます。フォーマッタ ライブラリのみがダウンロードされます。

壊れたHTMLを修正できるでしょうか?

与えたものをインデントしますが、失われたタグは修復しません。必要に応じて、W3C バリデーターを使用して検証します。

HTMLフォーマッタは無料ですか？

はい。HTMLフォーマッタはブラウザで無料、登録不要です。

データはこの端末から出ますか？

ほとんどのツールは端末内で処理します。公開 API を使う場合（ドメイン年齢など）はページに記載します。
