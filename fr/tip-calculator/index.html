Split a bill with tip

Enter the bill amount, tip percentage, and number of people. The tool shows the grand total and fair share per person—handy for restaurants and group orders.

How to use the tip calculator

  1. Enter your details. Fill in Facture ( ₹ ), Pourboire (%) et Les gens.
  2. Get the result. Press Calculer. Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Est-ce que ça tourne par personne ?

Les montants par personne indiquent deux décimales ; les arrondis réels peuvent différer légèrement.

Is this tip calculator free?

Yes. The tip calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
