About the memory game

Flip cards and find matching pairs. Train your memory with this free concentration game.

Fonctionne dans le navigateur—sans compte ni installation.

How to use the memory game

  1. Enter your details. Flip cards and find matching pairs. Train your memory with this free concentration game.
  2. Get the result. Press Shuffle . Results update on the page.
  3. Use or copy it. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Comment puis-je gagner ?

Retournez deux cartes à la fois. Lorsque les deux affichent le même emoji, ils restent face visible. Videz tout le tableau.

Uniquement pour cette séance. L'actualisation démarre une nouvelle lecture aléatoire.
