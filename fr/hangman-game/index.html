Questions fréquentes

Combien de fausses suppositions ?

Six vies. Chaque mauvaise lettre coûte une vie.

Les mots sont-ils adaptés aux enfants ?

Les mots sont des noms anglais généraux sans thèmes adultes, mais la difficulté varie.

Ce jeu du pendu est-il gratuit ?

Oui. Le jeu du pendu est gratuit et peut être utilisé dans votre navigateur sans aucun compte requis.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.

Le jeu du pendu fonctionne-t-il sur mobile ?

Oui. Les pages sont réactives et les outils fonctionnent dans les navigateurs mobiles de la même manière que sur ordinateur.
