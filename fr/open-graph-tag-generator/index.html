À propos du générateur de graphiques ouvert

Générez des balises méta Open Graph et Twitter Card pour les aperçus de liens. Copiez HTML pour votre en-tête de page.

Fonctionne dans le navigateur—sans compte ni installation.

Comment utiliser le générateur de graphiques ouvert

  1. Entrez vos coordonnées. Remplissez og:title , og:description , og:url et og:image URL .
  2. Obtenez le résultat. Appuyez sur Générer des balises . Mise à jour des résultats sur la page.
  3. Utilisez-le ou copiez-le. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Ce générateur de graphiques ouvert est-il gratuit ?

Oui. Le générateur de graphiques ouvert est gratuit et peut être utilisé dans votre navigateur sans aucun compte requis.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.

Le générateur de graphiques ouvert fonctionne-t-il sur mobile ?

Oui. Les pages sont réactives et les outils fonctionnent dans les navigateurs mobiles de la même manière que sur ordinateur.
