WCAG contrast requirements

  • AA normal text: at least 4.5:1
  • AA large text (24px, or 18.66px bold): at least 3:1
  • AAA normal text: at least 7:1; AAA large text: 4.5:1
  • UI components and icons (WCAG 2.1): at least 3:1 against adjacent colours

How the ratio is calculated

Each colour’s relative luminance is computed from its sRGB values, then the ratio is (lighter + 0.05) ÷ (darker + 0.05). Ratios range from 1:1 (same colour) to 21:1 (black on white). The displayed value is rounded down so a pass is never overstated.

Questions fréquentes

De quel rapport de contraste ai-je besoin ?

Visez un rapport de 4,5 : 1 pour le corps du texte afin de respecter les WCAG AA, auxquels font référence la plupart des lois sur l'accessibilité.

Puis-je saisir des codes hexadécimaux courts ?

Oui. #333 se lit comme #333333.

Est-ce qu'il vérifie les dégradés ou les images ?

Non. Vérifiez séparément les parties les plus claires et les plus sombres de l’arrière-plan.

color contrast checker est-il gratuit ?

Oui. color contrast checker est gratuit dans le navigateur, sans compte.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.
