Comment utiliser les jours entre les dates

  1. Entrez vos coordonnées. Remplissez Date de début et Date de fin .
  2. Obtenez le résultat. Appuyez sur Compter les jours . Mise à jour des résultats sur la page.
  3. Utilisez-le ou copiez-le. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Ces jours entre les dates sont-ils gratuits ?

Oui. Les jours entre les dates peuvent être utilisés gratuitement dans votre navigateur sans aucun compte requis.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.

Les jours entre les dates fonctionnent-ils sur mobile ?

Oui. Les pages sont réactives et les outils fonctionnent dans les navigateurs mobiles de la même manière que sur ordinateur.
