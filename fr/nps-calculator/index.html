How to use the NPS calculator

  1. Enter your details. Fill in Promoteurs (9-10), Passifs (7-8) et Détracteurs (0-6).
  2. Get the result. Press NPS. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this NPS calculator free?

Yes. The NPS calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
