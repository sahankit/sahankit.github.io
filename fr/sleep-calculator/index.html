    Find wake-up or bedtime options based on 90-minute sleep cycles. Free sleep cycle calculator.

    How to use the sleep calculator

    1. Enter your details. Fill in je veux et Temps.
    2. Get the result. Press Proposer des horaires. Results update on the page.
    3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

    Is this sleep calculator free?

    Yes. The sleep calculator is free to use in your browser with no account required.

    Does my data leave my device?

    For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
