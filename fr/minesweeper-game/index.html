About the minesweeper game

Classic minesweeper in the browser. Clear the 9×9 beginner board without hitting a mine. Flag with right-click or long-press.

Fonctionne dans le navigateur—sans compte ni installation.

How to use the minesweeper game

  1. Enter your details. Classic minesweeper in the browser. Clear the 9×9 beginner board without hitting a mine. Flag with right-click or long-press.
  2. Get the result. Press New game . Results update on the page.
  3. Use or copy it. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Comment signaler une mine ?

Faites un clic droit sur le bureau ou appuyez longuement sur une cellule sur les écrans tactiles.

Le premier clic est-il sécurisé ?

Oui. Les mines sont placées après votre première révélation, donc le clic d'ouverture n'est jamais une mine.

minesweeper game est-il gratuit ?

Oui. minesweeper game est gratuit dans le navigateur, sans compte.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.
