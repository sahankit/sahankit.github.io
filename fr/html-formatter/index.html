Beautify, then read and debug

Paste minified or badly indented code and press Embellir. The formatter (powered by the open-source js-beautify library) re-indents nested tags, CSS rules and JavaScript blocks, and also formats CSS and scripts embedded in HTML. Choose 2 spaces, 4 spaces or tabs to match your project.

Minify for production

  • HTML — removes comments and indentation whitespace while keeping <pre>, <textarea> and <script> content intact.
  • CSS — strips comments, spaces and the last semicolon in each rule.
  • JSON — removes all whitespace.
  • JavaScript — use a build tool such as Terser or esbuild; safe JS minification needs a full parser.

How to use the HTML formatter

  1. Enter your details. Fill in Language , Indent , Paste your code and Result .
  2. Get the result. Press Beautify . Results update on the page.
  3. Use or copy it. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Le formatage modifie-t-il le fonctionnement de ma page ?

L'embellissement ne change que les espaces. La réduction du HTML réduit les espaces supplémentaires, ce qui ne modifie presque jamais le rendu.

Mon code est-il envoyé à un serveur ?

Non. Le formatage s'effectue dans votre navigateur ; seule la bibliothèque du formateur est téléchargée.

Peut-il réparer le code HTML cassé ?

Il met en retrait ce que vous lui donnez mais ne répare pas les balises manquantes. Validez avec le validateur du W3C si nécessaire.

Formateur HTML est-il gratuit ?

Oui. Formateur HTML est gratuit dans le navigateur, sans compte.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.
