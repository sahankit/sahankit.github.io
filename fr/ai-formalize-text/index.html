Comment utiliser le texte formalisé

  1. Entrez vos coordonnées. Rendez le texte informel plus formel avec Rewriter API de Chrome. Idéal pour les e-mails et les rapports.
  2. Obtenez le résultat. Appuyez sur Formaliser . Mise à jour des résultats sur la page.
  3. Utilisez-le ou copiez-le. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Quand utiliser le texte formalisé

Rendez le texte informel plus formel avec Rewriter API de Chrome. Idéal pour les e-mails et les rapports. Utilisez-le lorsque vous avez besoin d'une réponse rapide sans installer de logiciel ni créer de compte.

Tout s'exécute localement dans votre navigateur là où l'outil le prend en charge, ce qui est utile pour les formulaires, les factures, les études et les vérifications rapides en déplacement.

Questions fréquentes

Ce texte formalisé est-il gratuit ?

Oui. Le texte formalisé peut être utilisé gratuitement dans votre navigateur sans aucun compte requis.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.

Le texte formalisé fonctionne-t-il sur mobile ?

Oui. Les pages sont réactives et les outils fonctionnent dans les navigateurs mobiles de la même manière que sur ordinateur.
