Chrome built-in AI summariser

This tool calls the browser’s Summarizer API (Gemini Nano). Your text is not sent to Sahankit—we do not run a summarization server.

Requires desktop Chrome with built-in AI (Gemini Nano) and enough free disk space. Processing happens on your device—not on Sahankit servers.

Summary types

Key points — bullet-style takeaways. TL;DR — one or two sentences. Headline — title-style line. Teaser — short promo blurb.

How to use the AI summariser

  1. Paste your text. Ajoutez un article, des notes ou tout autre passage en anglais dans la zone de texte.
  2. Choose type and length. Choisissez les points clés, TL;DR, le titre ou le teaser, ainsi que la sortie courte, moyenne ou longue.
  3. Click Summarise. Chrome télécharge le modèle sur l'appareil si nécessaire, puis rédige le résumé. Copiez ou modifiez le résultat.

Questions fréquentes

Pourquoi ça dit indisponible ?

Utilisez Chrome sur le bureau, de l'espace disque libre (~ Go pour le modèle) et des indicateurs tels que summum-api-for-gemini-nano si l'API est désactivée.

Est-ce la même chose que ChatGPT ?

Non, il utilise le modèle intégré de Google dans Chrome, et non un compte de chat cloud.

Puis-je résumer des PDF ?

Copiez d'abord le texte du PDF ou utilisez notre outil PDF vers Word pour extraire le texte, puis collez-le ici.

Récapitulateur IA est-il gratuit ?

Oui. Récapitulateur IA est gratuit dans le navigateur, sans compte.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.
