PDF to DOCX in the browser

This tool extracts selectable text from each PDF page and packs it into a .docx file you can open in Microsoft Word, Google Docs, or LibreOffice.

Scanned PDFs (image-only pages) have no text layer—use an OCR tool first, then convert again.

How to use the PDF to Word

  1. Enter your details. Choose a file from your device. It is processed locally and never uploaded to this site.
  2. Get the result. Press Convert to DOCX . Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Mon PDF est-il téléchargé ?

Non. La conversion s'exécute entièrement dans l'onglet de votre navigateur.

Le formatage correspondra-t-il au PDF ?

Principalement du texte brut et des sauts de page. Les colonnes, polices et images du PDF ne sont pas recréées.

PDF vers Word est-il gratuit ?

Oui. PDF vers Word est gratuit dans le navigateur, sans compte.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.
