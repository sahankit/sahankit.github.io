How to find broken keys

Press every key one by one. Working keys turn green and stay marked, so any key that never lights up is not registering. If a key stays purple after you let go, it may be sticking. The counter shows how many different keys you have tested.

The panel also shows event.key, event.code and keyCode—useful for developers and for checking a keyboard layout.

Limits of browser keyboard tests

Some keys are reserved by the operating system or browser and never reach web pages—for example Fn, Print Screen on some systems, and shortcuts like Ctrl+W or Cmd+Q. Media keys vary by device.

How to use the keyboard tester

  1. Enter your details. Free online keyboard tester. Press keys to check they work: keys light up while held and stay marked once tested. Shows event key, code and keyCode.
  2. Get the result. Press Reset test . Results update on the page.
  3. Use or copy it. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Peut-il tester le roulement de clé (NKRO) ?

Maintenez plusieurs touches à la fois : chaque touche tenue s'allume. Si certains arrêtent de s’allumer, vous avez atteint la limite de retournement de votre clavier.

Pourquoi la touche Fn ne s'affiche-t-elle pas ?

Fn est géré à l’intérieur du matériel du clavier et n’est pas signalé au navigateur.

Est-ce qu'il enregistre ce que je tape ?

Non. Les pressions sur les touches sont uniquement affichées sur cette page et ne sont jamais envoyées nulle part.

keyboard tester est-il gratuit ?

Oui. keyboard tester est gratuit dans le navigateur, sans compte.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.
