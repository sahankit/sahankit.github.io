How to use the ROT13

  1. Enter your details. ROT13 encodes and decodes text (same operation twice returns original).
  2. Get the result. Press ROT13. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this ROT13 free?

Yes. The ROT13 is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
