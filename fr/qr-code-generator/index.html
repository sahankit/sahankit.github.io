Create QR codes for menus, posters, and links

QR codes encode a URL or short text so phones can scan and open instantly. Generation happens in your browser; download PNG for print.

How to use the QR code generator

  1. Enter your details. Fill in URL ou texte et Taille (px).
  2. Get the result. Press Générer. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Les codes QR expirent-ils ?

Les codes QR statiques n'expirent pas : les données sont dans l'image. Si vous modifiez l'URL ultérieurement, générez un nouveau code.

Is this QR code generator free?

Yes. The QR code generator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
