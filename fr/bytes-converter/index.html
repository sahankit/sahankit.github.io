How to use the bytes converter

  1. Enter your details. Fill in Valeur, De et À.
  2. Get the result. Press Convertir. Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this bytes converter free?

Yes. The bytes converter is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
