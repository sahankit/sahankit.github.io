About the tic tac toe

Free tic tac toe game against a simple computer opponent. You are X and move first.

Fonctionne dans le navigateur—sans compte ni installation.

How to use the tic tac toe

  1. Enter your details. Free tic tac toe game against a simple computer opponent. You are X and move first.
  2. Get the result. Press New game . Results update on the page.
  3. Use or copy it. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Est-ce que je joue en premier ?

Oui. Vous êtes X et appuyez sur une case du tableau 3 × 3 avant que l'ordinateur ne joue O.

L'ordinateur est-il imbattable ?

Cela bloque les victoires immédiates mais n’est pas parfait. Vous pouvez gagner avec de bons mouvements.

tic tac toe est-il gratuit ?

Oui. tic tac toe est gratuit dans le navigateur, sans compte.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.
