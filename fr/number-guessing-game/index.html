À propos du jeu de devinettes

Devinez le nombre secret entre 1 et 100. Le jeu vous indique un chiffre plus ou moins élevé jusqu'à ce que vous gagniez.

Fonctionne dans le navigateur—sans compte ni installation.

Comment utiliser le jeu de devinettes

  1. Entrez vos coordonnées. Remplissez votre estimation (1-100) .
  2. Obtenez le résultat. Appuyez sur Devinez . Mise à jour des résultats sur la page.
  3. Utilisez-le ou copiez-le. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Le numéro est-il toujours le même ?

Non. Le nouveau numéro sélectionne un nouvel entier aléatoire compris entre 1 et 100.

Qu'est-ce qu'un bon score ?

La recherche binaire le trouve généralement en sept suppositions ou moins.

Ce jeu de devinettes est-il gratuit ?

Oui. Le jeu de devinettes est gratuit et peut être utilisé dans votre navigateur, sans compte requis.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.

Le jeu de devinettes fonctionne-t-il sur mobile ?

Oui. Les pages sont réactives et les outils fonctionnent dans les navigateurs mobiles de la même manière que sur ordinateur.
