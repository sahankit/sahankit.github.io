How to use the regex builder
  1. Enter your details. Fill in Preset templates , Insert escaped literal , Regular expression and Sample text .
  2. Get the result. Press Test matches . Results update on the page.
  3. Use or copy it. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.
When to use the regex builder
Build and test regular expressions with presets, pattern chips, flags, and live match highlights. Free browser regex builder. Use it when you need a fast answer without installing software or creating an account.

Questions fréquentes
En quoi est-ce différent du testeur de regex ?
Le constructeur se concentre sur l'assemblage de modèles à partir de préréglages et de pièces ; le testeur est un minimum de collage et d'exécution. Les deux fonctionnent localement.
Quelle saveur de regex ?
JavaScript RegExp (identique à celui des navigateurs et de Node). Les indicateurs g, i, m et s sont pris en charge ici.
regex builder est-il gratuit ?
Oui. regex builder est gratuit dans le navigateur, sans compte.
Mes données quittent-elles l’appareil ?
La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.
Does the regex builder work on mobile?
Yes. Pages are responsive and tools run in mobile browsers the same way as on desktop.
