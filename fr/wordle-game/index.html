About the wordle game

Free Wordle-style game. Guess the five-letter word in six tries. Green means correct spot, yellow means wrong spot.

Fonctionne dans le navigateur—sans compte ni installation.

How to use the wordle game

  1. Enter your details. Free Wordle-style game. Guess the five-letter word in six tries. Green means correct spot, yellow means wrong spot.
  2. Get the result. Press Guess . Results update on the page.
  3. Use or copy it. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Est-ce le Wordle officiel ?

Non. Il s’agit d’un jeu de devinettes original avec des règles de couleurs similaires, joué uniquement sur cette page.

Combien de suppositions ai-je?

Six. Chaque supposition doit comporter cinq lettres. Utilisez Nouveau mot pour une autre réponse aléatoire.

wordle game est-il gratuit ?

Oui. wordle game est gratuit dans le navigateur, sans compte.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.
