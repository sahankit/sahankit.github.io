How to use the unicode lookup

  1. Enter your details. Fill in Character .
  2. Get the result. Press Lookup . Results update on the page.
  3. Use or copy it. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

When to use the unicode lookup

Get Unicode code point and UTF-8 hex for a character. Use it when you need a fast answer without installing software or creating an account.

Everything runs locally in your browser where the tool supports it—useful for forms, invoices, study, and quick checks on the go.
