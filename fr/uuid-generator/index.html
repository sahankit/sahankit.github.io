What is UUID v4?

Version 4 UUIDs are random 128-bit identifiers, often used as database primary keys or correlation IDs. Collisions are astronomically unlikely for practical apps.

How to use the UUID generator

  1. Enter your details. Fill in How many and UUIDs .
  2. Get the result. Press Generate . Results update on the page.
  3. Use or copy it. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Sont-ils cryptographiquement aléatoires ?

Ils utilisent crypto.getRandomValues dans le navigateur, adapté aux identifiants d'application ; utilisez les API de plate-forme pour les jetons de sécurité si votre infrastructure les fournit.

Générateur d'UUID est-il gratuit ?

Oui. Générateur d'UUID est gratuit dans le navigateur, sans compte.
