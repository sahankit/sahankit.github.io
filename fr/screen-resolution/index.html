Screen resolution vs. viewport

Résolution d'écran is the size of your whole display. Browsers report it in CSS pixels; multiply by the device pixel ratio to get physical pixels. A 4K monitor at 150% scaling, for example, reports 2560 × 1440 CSS pixels with a ratio of 1.5 (3840 × 2160 physical).

The viewport is the visible area of the web page inside the browser window. Web designers use it to test responsive layouts.

Common resolutions

  • 1920 × 1080 (Full HD, 16:9) — the most common desktop size
  • 1366 × 768 — many budget laptops
  • 2560 × 1440 (QHD) and 3840 × 2160 (4K UHD)
  • 390 × 844 and 412 × 915 — common phone viewports in CSS pixels

Frequently asked questions

Pourquoi ma résolution est-elle inférieure aux spécifications de mon moniteur ?

La mise à l'échelle de l'affichage sous Windows ou macOS réduit la taille CSS du rapport du navigateur. Les pixels physiques montrent la résolution réelle du panneau.

Quel est le ratio de pixels de l'appareil ?

Le nombre de pixels physiques par pixel CSS. Les écrans Retina et haute DPI sont généralement au nombre de 2 ou 3.

Des données sont-elles collectées ?

Non. Les valeurs sont lues à partir de votre navigateur et affichées uniquement à vous.

Is this screen resolution free?

Yes. The screen resolution is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
