Prefer the full experience? Use the Récapitulateur IA page (same Chrome Summarizer API).

How to use the AI summarizer

  1. Enter your details. Fill in Type de résumé et Longueur.
  2. Get the result. Press Résumer. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this AI summarizer free?

Yes. The AI summarizer is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
