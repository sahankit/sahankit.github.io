Comment utiliser quelle est mon IP

  1. Entrez vos coordonnées. Consultez votre adresse IPv4 publique depuis le navigateur. Utilise une API IP en lecture seule – pas d'installation.
  2. Obtenez le résultat. Appuyez sur Afficher mon adresse IP publique . Mise à jour des résultats sur la page.
  3. Utilisez-le ou copiez-le. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Quand utiliser quelle est mon adresse IP ?

Consultez votre adresse IPv4 publique depuis le navigateur. Utilise une API IP en lecture seule – pas d'installation. Utilisez-le lorsque vous avez besoin d'une réponse rapide sans installer de logiciel ni créer de compte.

Tout s'exécute localement dans votre navigateur là où l'outil le prend en charge, ce qui est utile pour les formulaires, les factures, les études et les vérifications rapides en déplacement.

Questions fréquentes

Est-ce que mon IP est gratuite ?

Oui. Quelle est mon adresse IP peut être utilisée gratuitement dans votre navigateur sans aucun compte requis.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.

Est-ce que Quelle est mon IP fonctionne sur mobile ?

Oui. Les pages sont réactives et les outils fonctionnent dans les navigateurs mobiles de la même manière que sur ordinateur.
