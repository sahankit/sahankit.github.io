Comment convertir une image en texte

Choisissez une image ou collez une capture d'écran avec Ctrl+V (Cmd+V sur Mac), sélectionnez la langue du texte et appuyez sur Extraire le texte. La première exécution télécharge le moteur OCR et les données de langue (quelques Mo) ; les courses ultérieures sont plus rapides.

Une fois terminé, copiez le texte ou téléchargez-le sous forme de fichier .txt. La reconnaissance utilise Tesseract, le moteur OCR open source, fonctionnant entièrement dans votre navigateur.

Conseils pour une OCR précise

  • Utilisez une image nette et bien éclairée avec un texte sombre sur un fond clair.
  • Recadrez uniquement la zone de texte et redressez d'abord les photos inclinées.
  • Choisissez la bonne langue : utilisez l'anglais et l'hindi pour les documents mixtes.
  • Le texte imprimé fonctionne mieux ; la précision de l’écriture manuscrite est limitée.

Comment utiliser l'image en texte (OCR)

  1. Entrez vos coordonnées. Choisissez un fichier sur votre appareil. Il est traité localement et n'est jamais téléchargé sur ce site.
  2. Obtenez le résultat. Appuyez sur Extraire le texte . Mise à jour des résultats sur la page.
  3. Utilisez-le ou copiez-le. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Mes images sont-elles téléchargées ?

Non. Le moteur OCR est téléchargé sur votre navigateur et l’image est traitée sur votre appareil.

Peut-il lire l'hindi ?

Oui. Choisissez Hindi ou Anglais + Hindi dans la liste des langues.

Peut-il convertir un PDF ?

Prenez une capture d'écran de la page ou exportez-la d'abord sous forme d'image, puis utilisez cet outil. Pour les PDF basés sur du texte, l'outil PDF vers Word est plus rapide.

Cette image en texte (OCR) est-elle gratuite ?

Oui. L'utilisation de l'image en texte (OCR) est gratuite dans votre navigateur sans aucun compte requis.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.
