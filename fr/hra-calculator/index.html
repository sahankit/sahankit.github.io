Comment l'exonération HRA est calculée

Pour de nombreux salariés de l’ancien régime d’impôt sur le revenu, l’HRA exonérée correspond au minimum de trois montants : HRA réel reçu, loyer payé moins 10 % du salaire de base et 50 % du salaire de base (métro) ou 40 % du salaire de base (non-métro).

Utilisez-le avec notre calculateur d'impôt sur le revenu pour comparer le nouveau régime par rapport à l'ancien lorsque le HRA constitue une déduction importante.

Comment utiliser le calculateur HRA

  1. Entrez vos coordonnées. Remplissez Salaire de base ( ₹ annuel ), HRA reçu ( ₹ annuel ) et Loyer payé ( ₹ annuel ) .
  2. Obtenez le résultat. Appuyez sur Calculer l'exonération . Les résultats sont mis à jour sur la page et recalculés à mesure que vous modifiez les valeurs.
  3. Utilisez-le ou copiez-le. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Quand utiliser le calculateur HRA

Calculez l'exonération fiscale HRA pour les employés salariés en Inde. Métro vs non métro, salaire de base et loyer payés. Utilisez-le lorsque vous avez besoin d'une réponse rapide sans installer de logiciel ni créer de compte.

Tout s'exécute localement dans votre navigateur là où l'outil le prend en charge, ce qui est utile pour les formulaires, les factures, les études et les vérifications rapides en déplacement.

Questions fréquentes

La HRA s’applique-t-elle dans le nouveau régime fiscal ?

Généralement non : l’exemption HRA n’est pas disponible dans le cadre du nouveau régime. Cet outil est destiné à la planification de l'ancien régime.

La quittance de loyer est-elle obligatoire ?

Les employeurs et le service des impôts peuvent exiger des contrats de loyer et des reçus pour les HRA réclamés. Cette page ne fait qu'estimer les mathématiques.

Ce calculateur HRA est-il gratuit ?

Oui. Le calculateur HRA peut être utilisé gratuitement dans votre navigateur, sans compte requis.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.

Le calculateur HRA fonctionne-t-il sur mobile ?

Oui. Les pages sont réactives et les outils fonctionnent dans les navigateurs mobiles de la même manière que sur ordinateur.
