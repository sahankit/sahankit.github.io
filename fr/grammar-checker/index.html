Chrome built-in grammar check

Requires desktop Chrome with built-in AI (Gemini Nano) and enough free disk space. Processing happens on your device.

Paste text and run Check grammar to see suggested fixes from the Proofreader API.

How to use the grammar checker

  1. Enter your details. Check grammar, spelling, and punctuation with Chrome’s built-in Proofreader API. Private, on-device when supported.
  2. Get the result. Press Check grammar . Results update on the page.
  3. Use or copy it. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Est-ce que cela télécharge mon texte ?

Non. Le modèle Proofreader s'exécute localement dans Chrome lorsqu'il est disponible.

grammar checker est-il gratuit ?

Oui. grammar checker est gratuit dans le navigateur, sans compte.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.
