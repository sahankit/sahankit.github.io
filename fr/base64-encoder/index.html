Base64 in APIs and configs

Base64 encodes binary data as ASCII text—common in JSON web tokens, data URLs, and email. This tool handles Unicode text via UTF-8 before encoding.

How to use the base64 encode/decode

  1. Enter your details. Fill in Texte.
  2. Get the result. Press Encoder. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Pourquoi le décodage a-t-il échoué ?

L’entrée doit être valide en Base64 (remplissage et jeu de caractères). Supprimez les espaces parasites ou les sauts de ligne s’ils sont collés à partir des journaux.

Is this base64 encode/decode free?

Yes. The base64 encode/decode is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
