Base64 in APIs and configs

Base64 encodes binary data as ASCII text—common in JSON web tokens, data URLs, and email. This tool handles Unicode text via UTF-8 before encoding.

How to use the base64 encode/decode

  1. Enter your details. Fill in Text .
  2. Get the result. Press Encode . Results update on the page.
  3. Use or copy it. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Pourquoi le décodage a-t-il échoué ?

L’entrée doit être valide en Base64 (remplissage et jeu de caractères). Supprimez les espaces parasites ou les sauts de ligne s’ils sont collés à partir des journaux.

base64 encode/decode est-il gratuit ?

Oui. base64 encode/decode est gratuit dans le navigateur, sans compte.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.
