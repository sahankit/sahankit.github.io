How to use the 2048 game

  1. Enter your details. Play 2048 in your browser. Slide tiles with arrow keys or swipe. Merge numbers to reach 2048.

Questions fréquentes

Comment déplacer les tuiles ?

Utilisez les touches fléchées sur le bureau ou faites glisser votre doigt sur un téléphone. Les tuiles glissent jusqu'à ce qu'elles heurtent un mur ou une autre tuile.

Est-ce que cela enregistre mon score ?

Non. Les scores restent dans cet onglet jusqu'à ce que vous actualisiez ou démarriez une nouvelle partie.

Jeu 2048 est-il gratuit ?

Oui. Jeu 2048 est gratuit dans le navigateur, sans compte.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.

Does the 2048 game work on mobile?

Yes. Pages are responsive and tools run in mobile browsers the same way as on desktop.
