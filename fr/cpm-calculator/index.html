How to use the CPM calculator

  1. Enter your details. Fill in Dépenser et Impressions.
  2. Get the result. Press CPM. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this CPM calculator free?

Yes. The CPM calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
