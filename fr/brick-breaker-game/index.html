Comment utiliser le casse-briques

  1. Entrez vos coordonnées. Cassez toutes les briques avec le ballon. Déplacez la palette avec la souris ou en touchant. Jeu d'arcade gratuit de style petits groupes.
  2. Obtenez le résultat. Appuyez sur Nouveau niveau . Mise à jour des résultats sur la page.
  3. Utilisez-le ou copiez-le. Copiez ou téléchargez le résultat. Rien n’est enregistré—actualisez pour recommencer.

Questions fréquentes

Comment lancer le ballon ?

Cliquez ou appuyez sur la toile lorsque la balle est posée sur la raquette.

Et si je rate le ballon ?

Le tour se termine. Appuyez sur Nouveau niveau pour réessayer.

Ce casse-briques est-il gratuit ?

Oui. Le casse-briques est gratuit et peut être utilisé dans votre navigateur sans aucun compte requis.

Mes données quittent-elles l’appareil ?

La plupart des outils traitent vos données sur l’appareil. Si un outil appelle une API publique (âge de domaine, par exemple), c’est indiqué sur la page.

Le casse-briques fonctionne-t-il sur mobile ?

Oui. Les pages sont réactives et les outils fonctionnent dans les navigateurs mobiles de la même manière que sur ordinateur.
