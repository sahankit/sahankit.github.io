Beautify, then read and debug

Paste minified or badly indented code and press تجميل. The formatter (powered by the open-source js-beautify library) re-indents nested tags, CSS rules and JavaScript blocks, and also formats CSS and scripts embedded in HTML. Choose 2 spaces, 4 spaces or tabs to match your project.

Minify for production

  • HTML — removes comments and indentation whitespace while keeping <pre>, <textarea> and <script> content intact.
  • CSS — strips comments, spaces and the last semicolon in each rule.
  • JSON — removes all whitespace.
  • JavaScript — use a build tool such as Terser or esbuild; safe JS minification needs a full parser.

How to use the HTML formatter

  1. Enter your details. Fill in Language , Indent , Paste your code and Result .
  2. Get the result. Press Beautify . Results update on the page.
  3. Use or copy it. انسخ النتيجة أو نزّلها. لا يُحفظ شيء—حدّث الصفحة للبدء من جديد.

الأسئلة الشائعة

هل يغير التنسيق طريقة عمل صفحتي؟

التجميل يغير المسافة البيضاء فقط. يؤدي تصغير HTML إلى طي المسافات الزائدة، وهو ما لا يغير العرض أبدًا.

هل يتم إرسال الرمز الخاص بي إلى الخادم؟

لا. تتم عملية التنسيق في متصفحك؛ يتم تنزيل مكتبة المنسق فقط.

هل يمكن إصلاح HTML المكسور؟

إنه يضع مسافة بادئة على ما تقدمه له ولكنه لا يقوم بإصلاح العلامات المفقودة. قم بالتحقق باستخدام مدقق W3C إذا لزم الأمر.

هل منسق HTML مجاني؟

نعم. منسق HTML مجاني في المتصفح دون حساب.

هل تغادر بياناتي هذا الجهاز؟

معظم الأدوات تعالج الإدخال على جهازك. إذا استدعت الأداة واجهة عامة (مثل عمر النطاق) فسيُذكر ذلك في الصفحة.
