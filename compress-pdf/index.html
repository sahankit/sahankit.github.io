Which compression level should I choose?

  • Recommended — the best balance for most scanned documents, certificates and forms. Text stays sharp on screen and when printed at normal size.
  • Strong — the smallest file, for strict upload limits (for example 100–300 KB on government and exam portals).
  • Light — higher quality for documents with small print or detailed images.
  • Lossless — keeps text selectable, links and form fields; it only optimises the file structure, so savings are smaller.

How it works and why it’s private

Strong, Recommended and Light redraw each page and save it as a compressed JPEG image inside a new PDF. This shrinks scanned PDFs dramatically, but the text becomes part of the image and can’t be selected or searched. Lossless mode rewrites the PDF with compact object streams and keeps everything else unchanged.

Everything runs on your device using open-source PDF libraries, so confidential documents like ID proofs, bank statements and certificates never leave your computer or phone.

Frequently asked questions

How can I compress a PDF to under 200 KB?

Choose Strong. If it is still too big, split the PDF and upload only the required pages, or reduce the number of pages scanned.

Why did my PDF not get smaller?

PDFs that are mostly text are already compact; turning them into images can make them bigger. Use Lossless mode, or keep the original.

Is there a file size or page limit?

There’s no fixed limit, but very large PDFs (hundreds of pages) need more memory and time on phones.

Is this compress PDF free?

Yes. The compress PDF is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
