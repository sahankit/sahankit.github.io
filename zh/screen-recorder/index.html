如何录制屏幕

  • 勾选是否包含选项卡/系统音频和麦克风。
  • 新闻 开始录音 并选择整个屏幕、一个窗口或一个浏览器选项卡。
  • 做您想要捕获的内容 - 教程、演示文稿、错误报告或游戏剪辑。
  • 新闻 停止录音 （或浏览器栏中的“停止共享”），预览视频并下载。

音频、格式和支持

Chrome 和 Edge 可以从浏览器选项卡捕获音频，在 Windows 上可以从整个系统捕获音频； macOS 仅允许选项卡音频。添加麦克风进行旁白。视频保存为 WebM（或浏览器支持的 MP4），可在 Chrome、Edge、Firefox 和 VLC 中播放并直接上传到 YouTube。

屏幕录制需要桌面浏览器 - 移动浏览器不允许网站捕获屏幕。

常见问题

有水印或时间限制吗？

两者都不。录音长度仅受设备内存的限制。

为什么没有声音？

确保您在浏览器的共享对话框中勾选了“共享选项卡音频”或“共享系统音频”。 macOS 仅支持选项卡音频。

我的录音上传了吗？

不会。在您下载之前，视频会创建并存储在您的浏览器中。

这个屏幕录像机是免费的吗？

是的。屏幕录像机可以在浏览器中免费使用，无需帐户。

我的数据会离开这台设备吗？

本站大多数工具在您的设备上处理输入。若工具会调用公开 API（例如域名年龄），页面上会说明。
