常见问题

这在移动设备上有效吗？

不可以。从 Chrome 138 开始，Chrome 的 Translator API 仅适用于桌面。

这个人工智能翻译器是免费的吗？

是的。人工智能翻译器可以在您的浏览器中免费使用，无需帐户。

我的数据会离开这台设备吗？

本站大多数工具在您的设备上处理输入。若工具会调用公开 API（例如域名年龄），页面上会说明。

人工智能翻译器可以在手机上使用吗？

是的。页面具有响应能力，工具在移动浏览器中的运行方式与在桌面上的运行方式相同。
