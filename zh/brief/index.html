How it works

On load, headlines come from a snapshot file updated when the site is built (and hourly via GitHub Actions). Tap Refresh to try a live RSS fetch through rss2json.com. We do not host full article text.

常见问题

Is this the Inshorts app?

No. This is an independent Tools page inspired by short headline UX. Content comes from Google News RSS, not Inshorts.

Why do headlines not load?

If the snapshot file is missing or Refresh is blocked (ad blockers, rss2json limits), try again later or reload the page.
