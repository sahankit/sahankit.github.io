Screen resolution vs. viewport

屏幕分辨率 is the size of your whole display. Browsers report it in CSS pixels; multiply by the device pixel ratio to get physical pixels. A 4K monitor at 150% scaling, for example, reports 2560 × 1440 CSS pixels with a ratio of 1.5 (3840 × 2160 physical).

The viewport is the visible area of the web page inside the browser window. Web designers use it to test responsive layouts.

Common resolutions

  • 1920 × 1080 (Full HD, 16:9) — the most common desktop size
  • 1366 × 768 — many budget laptops
  • 2560 × 1440 (QHD) and 3840 × 2160 (4K UHD)
  • 390 × 844 and 412 × 915 — common phone viewports in CSS pixels

常见问题

为什么我的分辨率低于显示器的规格？

Windows 或 macOS 中的显示缩放使浏览器报告更小的 CSS 大小。物理像素显示真实的面板分辨率。

什么是设备像素比？

每个 CSS 像素的物理像素数。视网膜和高 DPI 屏幕通常为 2 或 3。

是否收集任何数据？

不会。值是从您的浏览器读取的，并且仅向您显示。
