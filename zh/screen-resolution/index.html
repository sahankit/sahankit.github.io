屏幕分辨率与视口

屏幕分辨率 是整个显示器的大小。浏览器以 CSS 像素来报告；乘以 设备像素比 获取物理像素。例如，缩放率为 150% 的 4K 显示器会报告 2560 × 1440 CSS 像素，比率为 1.5（3840 × 2160 物理值）。

The 视口 是浏览器窗口内网页的可见区域。网页设计师用它来测试响应式布局。

共同决议

  • 1920 × 1080（全高清，16:9）——最常见的桌面尺寸
  • 1366 × 768 — 许多廉价笔记本电脑
  • 2560 × 1440（QHD）和 3840 × 2160（4K 超高清）
  • 390 × 844 和 412 × 915 — CSS 像素中的常见手机视口

常见问题

为什么我的分辨率低于显示器的规格？

Windows 或 macOS 中的显示缩放使浏览器报告更小的 CSS 大小。物理像素显示真实的面板分辨率。

什么是设备像素比？

每个 CSS 像素的物理像素数。视网膜和高 DPI 屏幕通常为 2 或 3。

是否收集任何数据？

不会。值是从您的浏览器读取的，并且仅向您显示。

这个屏幕分辨率是免费的吗？

是的。屏幕分辨率可在您的浏览器中免费使用，无需帐户。

我的数据会离开这台设备吗？

本站大多数工具在您的设备上处理输入。若工具会调用公开 API（例如域名年龄），页面上会说明。
