Beautify, then read and debug

Paste minified or badly indented code and press 美化. The formatter (powered by the open-source js-beautify library) re-indents nested tags, CSS rules and JavaScript blocks, and also formats CSS and scripts embedded in HTML. Choose 2 spaces, 4 spaces or tabs to match your project.

Minify for production

  • HTML — removes comments and indentation whitespace while keeping <pre>, <textarea> and <script> content intact.
  • CSS — strips comments, spaces and the last semicolon in each rule.
  • JSON — removes all whitespace.
  • JavaScript — use a build tool such as Terser or esbuild; safe JS minification needs a full parser.

How to use the HTML formatter

  1. Enter your details. Fill in Language , Indent , Paste your code and Result .
  2. Get the result. Press Beautify . Results update on the page.
  3. Use or copy it. 复制或下载结果。不会保存—刷新即可重来。

常见问题

格式设置会改变我的页面的工作方式吗？

美化仅改变空白。缩小 HTML 会折叠多余的空间，这几乎不会改变渲染。

我的代码是否发送到服务器？

不会。格式化发生在您的浏览器中；仅下载格式化程序库。

它可以修复损坏的 HTML 吗？

它会缩进您提供的内容，但不会修复丢失的标签。如果需要，使用 W3C 验证器进行验证。

HTML 格式化程序免费吗？

是。HTML 格式化程序可在浏览器中免费使用，无需账号。
