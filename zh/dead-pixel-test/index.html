坏点测试

免费坏点测试：用纯黑色、白色、红色、绿色、蓝色等填充屏幕，以发现显示器、笔记本电脑、电视或手机上的坏点或卡住像素。

清洁屏幕，然后开始测试。每种颜色都会填满整个屏幕，仔细观察是否有黑色、白色或其他颜色的点。

控制：单击、点击、空格键或 → 为下一种颜色，← 为前一种颜色，Esc 退出。

坏点与卡点

  • 坏点 - 始终为黑色，在白色屏幕上最明显。通常是永久性的。
  • 残留像素 — 保持红色、绿色、蓝色或白色；在黑色或对比色上最明显。有时会自行恢复。
  • 背光渗色 — 黑暗房间中黑屏边缘漏光。
  • 灰尘 — 当您擦拭屏幕时，斑点移动或消失并不是像素故障。

如何测试新显示器或笔记本电脑

用超细纤维布擦拭屏幕，将亮度调高并开始测试。从正常观看距离观察每种颜色，然后近距离观察，逐部分扫描。在退货或保修期内执行此操作 - 制造商的坏点政策通常要求最低数量的故障像素。

常见问题

它适用于手机和电视吗？

是的。在设备上打开页面并点击以更改颜色。智能电视浏览器可能不允许真正的全屏。

卡住的像素可以修复吗？

有时。在屏幕打开时用软布轻轻按摩该部位，或者让显示屏关闭一段时间，会有帮助。坏点通常无法修复。

多少个坏点是可以接受的？

这取决于制造商的政策（通常基于 ISO 9241-307 类别）。检查您的保修条款。
