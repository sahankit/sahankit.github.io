About the tile calculator

Calculate how many floor tiles you need from room size and tile dimensions. Adds waste factor.

Runs in your browser—no signup and no install.

How to use the tile calculator

  1. Enter your details. Fill in 房间长度（英尺）, 房间宽度（英尺）, 瓷砖长度（英寸）, 瓷砖宽度（英寸） 和 废物（%）.
  2. Get the result. Press 计算瓷砖. Results update on the page and recalculate as you edit values.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Is this tile calculator free?

Yes. The tile calculator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
