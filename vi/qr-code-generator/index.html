Frequently asked questions

Do QR codes expire?

Static QR codes do not expire—the data is in the image. If you change the URL later, generate a new code.

Is this QR code generator free?

Yes. The QR code generator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
