What is UUID v4?

Version 4 UUIDs are random 128-bit identifiers, often used as database primary keys or correlation IDs. Collisions are astronomically unlikely for practical apps.

How to use the UUID generator

  1. Enter your details. Fill in How many and UUIDs.
  2. Get the result. Press Generate. Results update on the page.
  3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

Frequently asked questions

Are these cryptographically random?

They use crypto.getRandomValues in the browser—suitable for app IDs; use platform APIs for security tokens if your framework provides them.

Is this UUID generator free?

Yes. The UUID generator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
