Base64 di API dan konfigurasi

Base64 mengkodekan data biner sebagai teks ASCII—umum di token web JSON, URL data, dan email. Alat ini menangani teks Unicode melalui UTF-8 sebelum pengkodean.

Cara menggunakan enkode/dekode base64

  1. Masukkan detail Anda. Isi Teks.
  2. Dapatkan hasilnya. Tekan Enkode. Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Kapan menggunakan enkode/dekode base64

Menyandikan atau mendekode teks Base64 di browser. Mendukung string Unicode. Alat Base64 gratis. Gunakan saat Anda membutuhkan jawaban cepat tanpa menginstal perangkat lunak atau membuat akun.

Semuanya berjalan secara lokal di browser Anda jika alat tersebut mendukungnya—berguna untuk formulir, faktur, studi, dan pemeriksaan cepat saat bepergian.

Pertanyaan umum

Mengapa dekode gagal?

Input harus valid Base64 (padding dan rangkaian karakter). Hapus spasi atau jeda baris jika ditempel dari log.

Apakah enkode/dekode base64 ini gratis?

Ya. Encode/decode base64 gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah enkode/dekode base64 berfungsi di perangkat seluler?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
