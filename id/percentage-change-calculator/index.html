Tentang persentase perubahan

Temukan persen kenaikan atau penurunan dari nilai lama ke nilai baru.

Berjalan di browser—tanpa daftar atau instal.

Cara menggunakan persentase perubahan

  1. Masukkan detail Anda. Isi nilai Lama dan nilai Baru.
  2. Dapatkan hasilnya. Tekan Persen perubahan . Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah perubahan persentase ini gratis?

Ya. Perubahan persentase ini gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah perubahan persentase berfungsi di perangkat seluler?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
