Pertanyaan umum
Apa bedanya dengan penguji regex?
Pembangun berfokus pada perakitan pola dari preset dan bagian; pengujinya minimal tempel dan jalankan. Keduanya dijalankan secara lokal.
Rasa regex yang mana?
JavaScript RegExp (sama seperti di browser dan Node). Bendera g, i, m, dan s didukung di sini.
Apakah regex builder gratis?
Ya. regex builder gratis di browser, tanpa akun.
Apakah data saya keluar dari perangkat?
Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
