Cara menggunakan minggu kehamilan

  1. Masukkan detail Anda. Isikan Hari Pertama Haid Terakhir (LMP).
  2. Dapatkan hasilnya. Tekan Hitung . Hasil diperbarui pada halaman dan dihitung ulang saat Anda mengedit nilai.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah minggu kehamilan ini gratis?

Ya. Minggu-minggu kehamilan gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah minggu kehamilan berfungsi di ponsel?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
