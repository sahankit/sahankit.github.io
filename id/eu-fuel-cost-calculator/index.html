Tentang biaya perjalanan bahan bakar UE

Perkirakan biaya bahan bakar untuk perjalanan dari jarak, konsumsi L/100km, dan harga per liter dalam euro.

Berjalan di browser—tanpa daftar atau instal.

Cara menggunakan biaya perjalanan bahan bakar UE

  1. Masukkan detail Anda. Isi Jarak (km), Konsumsi (L/100km) dan harga Bahan Bakar (€ / liter) .
  2. Dapatkan hasilnya. Tekan biaya perjalanan. Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah perjalanan bahan bakar ke UE ini gratis?

Ya. Biaya perjalanan bahan bakar UE gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah biaya perjalanan bahan bakar UE berlaku di perangkat seluler?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
