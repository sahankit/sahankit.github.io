About the MIME type lookup

Look up common MIME types from a file name or extension. Handy for HTTP headers, uploads, and APIs.

Berjalan di browser—tanpa daftar atau instal.

How to use the MIME type lookup

  1. Enter your details. Fill in File name or extension .
  2. Get the result. Press Lookup . Results update on the page.
  3. Use or copy it. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.
