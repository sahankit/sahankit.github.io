Tentang permainan menebak angka

Tebak angka rahasia antara 1 dan 100. Permainan ini memberi tahu Anda lebih tinggi atau lebih rendah sampai Anda menang.

Berjalan di browser—tanpa daftar atau instal.

Cara menggunakan permainan tebak angka

  1. Masukkan detail Anda. Isi tebakan Anda (1–100) .
  2. Dapatkan hasilnya. Tekan Tebak. Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah angkanya selalu sama?

Tidak. Nomor baru mengambil bilangan bulat acak baru dari 1 hingga 100.

Berapa skor yang bagus?

Pencarian biner biasanya menemukannya dalam tujuh tebakan atau kurang.

Apakah permainan tebak angka ini gratis?

Ya. Permainan menebak angka ini gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah permainan tebak angka bisa digunakan di ponsel?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
