Bagaimana tim diisi
Nama-nama dikocok, lalu dibagikan satu per satu ke seluruh tim, seperti kartu. Jika daftarnya tidak terbagi rata, beberapa tim mempunyai satu orang tambahan. Menjalankannya lagi akan menghasilkan pengacakan baru.
Cara menggunakan generator tim acak
  1. Masukkan detail Anda. Isi Nama, satu per baris dan Jumlah tim.
  2. Dapatkan hasilnya. Tekan Buat tim . Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.
Kapan menggunakan generator tim acak
Tempelkan satu nama per baris dan bagi daftar menjadi tim acak dengan ukuran yang sama, sejauh hitungannya memungkinkan. Diacak di browser. Gunakan saat Anda membutuhkan jawaban cepat tanpa menginstal perangkat lunak atau membuat akun.
Semuanya berjalan secara lokal di browser Anda jika alat tersebut mendukungnya—berguna untuk formulir, faktur, studi, dan pemeriksaan cepat saat bepergian.
Pertanyaan umum
Bisakah dua tim berakhir sama?
Hanya secara kebetulan. Setiap klik diacak lagi.
Apakah generator tim acak ini gratis?
Ya. Generator tim acak gratis untuk digunakan di browser Anda tanpa memerlukan akun.
Apakah data saya keluar dari perangkat?
Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
Apakah generator tim acak berfungsi di perangkat seluler?
Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
