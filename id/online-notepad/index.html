Sebuah notepad sederhana yang mengingat

Mulailah mengetik dan catatan Anda akan disimpan ke penyimpanan lokal browser ini dalam hitungan detik. Tutup tabnya, kembali lagi nanti, dan tab itu masih ada. Jumlah kata dan karakter diperbarui saat Anda menulis.

Gunakan Unduh .txt untuk menyimpan salinan di perangkat Anda, atau Salin semua untuk menempelkannya ke email, obrolan, atau dokumen.

Privasi

Catatan tidak pernah meninggalkan perangkat Anda—tidak ada akun dan tidak ada salinan server. Itu juga berarti catatan tidak disinkronkan antar perangkat, dan menghapus data browser Anda akan menghapusnya, jadi unduh apa pun yang penting.

Cara menggunakan buku catatan online

  1. Masukkan detail Anda. Isi catatan Anda (disimpan otomatis di browser ini) .
  2. Dapatkan hasilnya. Tekan Unduh .txt . Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Di mana catatan saya disimpan?

Hanya di Penyimpanan lokal browser Anda di perangkat ini.

Apakah ini akan berfungsi secara offline?

Setelah halaman dimuat, Anda dapat terus mengetik dan menyimpan tanpa koneksi internet.

Bisakah saya membukanya dalam dua tab?

Ya. Perubahan yang dilakukan di satu tab diambil oleh tab lainnya.

Apakah buku catatan online ini gratis?

Ya. Notepad online gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
