PDF to DOCX in the browser

This tool extracts selectable text from each PDF page and packs it into a .docx file you can open in Microsoft Word, Google Docs, or LibreOffice.

Scanned PDFs (image-only pages) have no text layer—use an OCR tool first, then convert again.

How to use the PDF to Word

  1. Enter your details. Choose a file from your device. It is processed locally and never uploaded to this site.
  2. Get the result. Press Convert to DOCX . Results update on the page and recalculate as you edit values.
  3. Use or copy it. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah PDF saya sudah diunggah?

Tidak. Konversi berjalan sepenuhnya di tab browser Anda.

Apakah pemformatannya akan cocok dengan PDF?

Sebagian besar teks biasa dan hentian halaman. Kolom, font, dan gambar dari PDF tidak dibuat ulang.

Apakah PDF ke Word gratis?

Ya. PDF ke Word gratis di browser, tanpa akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
