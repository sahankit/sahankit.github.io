Tentang kalkulator TDEE

Hitung total pengeluaran energi harian (TDEE) dan BMR menggunakan persamaan Mifflin-St Jeor. Kalkulator kalori gratis.

Berjalan di browser—tanpa daftar atau instal.

Cara menggunakan kalkulator TDEE

  1. Masukkan detail Anda. Isikan Jenis Kelamin, Umur (tahun), Berat Badan (kg), Tinggi Badan (cm) dan Aktivitas.
  2. Dapatkan hasilnya. Tekan Hitung . Hasil diperbarui pada halaman dan dihitung ulang saat Anda mengedit nilai.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah kalkulator TDEE ini gratis?

Ya. Kalkulator TDEE gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah kalkulator TDEE berfungsi di perangkat seluler?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
