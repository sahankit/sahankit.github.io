Chrome built-in AI summariser

This tool calls the browser’s Summarizer API (Gemini Nano). Your text is not sent to Sahankit—we do not run a summarization server.

Requires desktop Chrome with built-in AI (Gemini Nano) and enough free disk space. Processing happens on your device—not on Sahankit servers.

Summary types

Key points — bullet-style takeaways. TL;DR — one or two sentences. Headline — title-style line. Teaser — short promo blurb.

How to use the AI summariser

  1. Paste your text. Tambahkan artikel, catatan, atau bagian bahasa Inggris apa pun di kotak teks.
  2. Choose type and length. Pilih poin-poin penting, TL;DR, judul, atau penggoda, dan keluaran pendek, menengah, atau panjang.
  3. Click Summarise. Chrome mendownload model di perangkat jika diperlukan, lalu menulis ringkasannya. Salin atau edit hasilnya.

Pertanyaan umum

Mengapa dikatakan tidak tersedia?

Gunakan Chrome desktop, kosongkan ruang disk (~GB untuk model), dan tandai seperti ringkasanr-api-for-gemini-nano jika API tidak aktif.

Apakah ini sama dengan ChatGPT?

Tidak. Akun ini menggunakan model pada perangkat Google di Chrome, bukan akun chat cloud.

Bisakah saya meringkas PDF?

Salin teks dari PDF terlebih dahulu, atau gunakan alat PDF ke Word kami untuk mengekstrak teks, lalu tempel di sini.

Apakah Ringkasan AI gratis?

Ya. Ringkasan AI gratis di browser, tanpa akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
