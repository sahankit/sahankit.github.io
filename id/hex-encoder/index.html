Lihat byte UTF-8 dalam heksadesimal.

Cara menggunakan teks ↔ hex

  1. Masukkan detail Anda. Enkode teks ke byte heksadesimal dan dekode heksa ke teks.
  2. Dapatkan hasilnya. Tekan Untuk heksa . Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Kapan menggunakan teks ↔ hex

Enkode teks ke byte heksadesimal dan dekode heksa ke teks. Gunakan saat Anda membutuhkan jawaban cepat tanpa menginstal perangkat lunak atau membuat akun.

Semuanya berjalan secara lokal di browser Anda jika alat tersebut mendukungnya—berguna untuk formulir, faktur, studi, dan pemeriksaan cepat saat bepergian.

Pertanyaan umum

Apakah teks ini ↔ hex gratis?

Ya. Teks ↔ hex gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah teks ↔ hex berfungsi di ponsel?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
