Kontras warna yang dapat diakses

WCAG menyarankan setidaknya kontras 4,5:1 untuk teks normal. Gunakan pembacaan rasio saat memilih teks dan warna latar belakang untuk situs dan slide.

Cara menggunakan pemilih warna

  1. Masukkan detail Anda. Pilih warna, salin HEX dan RGB, dan periksa rasio kontras terhadap warna kedua.
  2. Dapatkan hasilnya. Hasilnya diperbarui pada halaman saat Anda mengetik.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Kapan menggunakan pemilih warna

Pilih warna, salin HEX dan RGB, dan periksa rasio kontras terhadap warna kedua. Gunakan saat Anda membutuhkan jawaban cepat tanpa menginstal perangkat lunak atau membuat akun.

Semuanya berjalan secara lokal di browser Anda jika alat tersebut mendukungnya—berguna untuk formulir, faktur, studi, dan pemeriksaan cepat saat bepergian.

Pertanyaan umum

Apakah pemilih warna ini gratis?

Ya. Pemilih warna gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah pemilih warna berfungsi di perangkat seluler?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
