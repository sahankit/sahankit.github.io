Pertanyaan umum

Apakah ini adil?

Ya. Ia menggunakan nomor acak kriptografis browser, dan jawabannya adalah di sisi mana pun bit tersebut berada.

Apakah ini ya atau tidak gratis?

Ya. Ya atau tidak gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah jawaban ya atau tidak berfungsi di perangkat seluler?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
