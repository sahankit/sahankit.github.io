Tentang kalori berjalan

Perkirakan kalori yang terbakar saat berjalan berdasarkan berat, jarak, atau langkah. Ilustrasi menggunakan perkiraan MET.

Berjalan di browser—tanpa daftar atau instal.

Cara menggunakan kalori berjalan

  1. Masukkan detail Anda. Isikan Berat Badan (kg) dan Jarak (mil).
  2. Dapatkan hasilnya. Tekan Perkiraan. Hasil diperbarui pada halaman dan dihitung ulang saat Anda mengedit nilai.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah jalan kaki ini bebas kalori?

Ya. Kalori berjalan gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah kalori berjalan berfungsi di perangkat seluler?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
