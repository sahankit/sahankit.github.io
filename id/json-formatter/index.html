Format atau perkecil JSON dengan aman

Tempel tanggapan API atau file konfigurasi. Format menambahkan lekukan yang dapat dibaca; Minify menghapus spasi tambahan. JSON yang tidak valid menunjukkan kesalahan penguraian alih-alih gagal secara diam-diam.

Cara menggunakan pemformat JSON

  1. Masukkan detail Anda. Isi JSON .
  2. Dapatkan hasilnya. Tekan Format. Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Kapan menggunakan pemformat JSON

Format dan validasi JSON di browser. Printer cantik JSON gratis dengan pesan kesalahan. Gunakan saat Anda membutuhkan jawaban cepat tanpa menginstal perangkat lunak atau membuat akun.

Semuanya berjalan secara lokal di browser Anda jika alat tersebut mendukungnya—berguna untuk formulir, faktur, studi, dan pemeriksaan cepat saat bepergian.

Pertanyaan umum

Apakah JSON saya dikirim ke mana saja?

Penguraian dan pemformatan hanya terjadi di tab browser Anda.

Apakah pemformat JSON ini gratis?

Ya. Pemformat JSON gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah pemformat JSON berfungsi di perangkat seluler?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
