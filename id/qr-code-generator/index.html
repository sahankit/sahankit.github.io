How to use the QR code generator

  1. Enter your details. Fill in URL or text and Size (px) .
  2. Get the result. Press Generate . Results update on the page.
  3. Use or copy it. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah kode QR kedaluwarsa?

Kode QR statis tidak kedaluwarsa—datanya ada di gambar. Jika nanti Anda mengubah URL, buat kode baru.

Apakah Pembuat kode QR gratis?

Ya. Pembuat kode QR gratis di browser, tanpa akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
