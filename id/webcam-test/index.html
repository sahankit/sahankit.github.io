Cara menguji webcam Anda

Tekan Uji kamera web saya dan izinkan akses kamera saat browser Anda memintanya. Jika pratinjau muncul, kamera Anda berfungsi. Alat tersebut kemudian menunjukkan resolusi streamingnya (misalnya 1280 × 720 atau 1920 × 1080), kecepatan bingkai yang diukur, rasio aspek, dan megapiksel.

Punya lebih dari satu kamera? Pilih dari daftar. Gunakan Ambil cuplikan untuk menyimpan gambar diam untuk memeriksa fokus dan pencahayaan sebelum panggilan video.

Kamera web tidak berfungsi? Coba ini

  • Izinkan izin kamera untuk situs ini dari ikon kamera di bilah alamat.
  • Tutup Zoom, Teams, Meet, atau aplikasi lain yang mungkin menggunakan kamera.
  • Di Windows, periksa Pengaturan → Privasi → Kamera. Di macOS, periksa Pengaturan Sistem → Privasi & Keamanan → Kamera.
  • Periksa penutup privasi fisik atau tombol fungsi kamera di laptop.

Cara menggunakan tes webcam

  1. Masukkan detail Anda. Isi Kamera.
  2. Dapatkan hasilnya. Tekan Uji webcam saya. Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah video saya direkam atau diunggah?

Tidak. Video tetap ada di perangkat Anda. Snapshot dibuat secara lokal dan hanya disimpan jika Anda mendownloadnya.

Mengapa resolusinya lebih rendah dari spesifikasi kamera saya?

Browser mungkin memilih mode kinerja yang lebih rendah, dan beberapa port USB atau aplikasi membatasinya. Nilai yang ditampilkan adalah nilai yang sebenarnya di-streaming oleh kamera Anda.

Apakah ini berfungsi di ponsel?

Ya, di browser seluler modern. Gunakan daftar kamera untuk beralih antara kamera depan dan belakang.

Apakah tes webcam ini gratis?

Ya. Tes webcam gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
