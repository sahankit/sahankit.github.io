Beautify, then read and debug

Paste minified or badly indented code and press Mempercantik. The formatter (powered by the open-source js-beautify library) re-indents nested tags, CSS rules and JavaScript blocks, and also formats CSS and scripts embedded in HTML. Choose 2 spaces, 4 spaces or tabs to match your project.

Minify for production

  • HTML — removes comments and indentation whitespace while keeping <pre>, <textarea> and <script> content intact.
  • CSS — strips comments, spaces and the last semicolon in each rule.
  • JSON — removes all whitespace.
  • JavaScript — use a build tool such as Terser or esbuild; safe JS minification needs a full parser.

How to use the HTML formatter

  1. Enter your details. Fill in Language , Indent , Paste your code and Result .
  2. Get the result. Press Beautify . Results update on the page.
  3. Use or copy it. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah pemformatan mengubah cara kerja halaman saya?

Mempercantik hanya mengubah spasi. Meminimalkan HTML akan menghilangkan ruang ekstra, yang hampir tidak pernah mengubah rendering.

Apakah kode saya dikirim ke server?

Tidak. Pemformatan terjadi di browser Anda; hanya perpustakaan formatter yang diunduh.

Bisakah itu memperbaiki HTML yang rusak?

Ini mengindentasi apa yang Anda berikan tetapi tidak memperbaiki tag yang hilang. Validasi dengan validator W3C jika diperlukan.

Apakah Pemformat HTML gratis?

Ya. Pemformat HTML gratis di browser, tanpa akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
