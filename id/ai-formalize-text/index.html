Cara menggunakan teks formalisasi

  1. Masukkan detail Anda. Jadikan teks informal menjadi lebih formal dengan Rewriter Chrome API. Cocok untuk email dan laporan.
  2. Dapatkan hasilnya. Tekan Formalisasikan . Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Kapan menggunakan teks formalisasi

Jadikan teks informal menjadi lebih formal dengan Rewriter Chrome API. Cocok untuk email dan laporan. Gunakan saat Anda membutuhkan jawaban cepat tanpa menginstal perangkat lunak atau membuat akun.

Semuanya berjalan secara lokal di browser Anda jika alat tersebut mendukungnya—berguna untuk formulir, faktur, studi, dan pemeriksaan cepat saat bepergian.

Pertanyaan umum

Apakah ini memformalkan teks gratis?

Ya. Teks formalisasi gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah teks formalisasi berfungsi di perangkat seluler?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
