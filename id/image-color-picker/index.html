Pick any colour from a photo or screenshot

Upload an image or paste a screenshot, then hover to see a magnified view and click the exact pixel you want. You get the colour in HEX (for CSS and design tools), RGB and HSL—click any value to copy it. Every colour you pick is kept in a history row.

In Chrome and Edge you can also use Pilih dari mana saja di layar to grab a colour from outside the browser, such as another app.

Automatic colour palette

The tool also finds the eight most common distinct colours in your image—handy for building a brand palette from a logo, matching a website to a photo, or choosing paint colours. Click a swatch to copy its HEX code.

How to use the image color picker

  1. Enter your details. Choose a file from your device. It is processed locally and never uploaded to this site.
  2. Get the result. The result updates on the page as you type.
  3. Use or copy it. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah warnanya persis?

Ya—itu membaca piksel sebenarnya. Gambar yang sangat besar diskalakan hingga 2000 piksel, yang dapat sedikit memadukan piksel di sekitarnya.

Bisakah saya menempelkan tangkapan layar?

Ya. Tekan Ctrl+V (Cmd+V di Mac) di mana saja pada halaman.

Apakah gambar saya diunggah?

Tidak. Ini hanya diproses di browser Anda.

Apakah image color picker gratis?

Ya. image color picker gratis di browser, tanpa akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
