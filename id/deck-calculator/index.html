Tentang papan dek

Perkirakan papan geladak dari luas, lebar papan, dan persentase limbah. Kalkulator bahan penghiasan gratis.

Berjalan di browser—tanpa daftar atau instal.

Cara menggunakan papan dek

  1. Masukkan detail Anda. Isi Luas Dek (kaki persegi), Lebar Papan (dalam), Panjang Papan (kaki) dan Limbah (%) .
  2. Dapatkan hasilnya. Tekan jumlah Dewan. Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah papan dek ini gratis?

Ya. Papan dek gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah papan dek berfungsi di perangkat seluler?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
