Kompresor gambar

Seret JPG atau PNG, atur kualitas JPEG dengan penggeser, dan unduh file yang lebih kecil. Untuk batas KB yang tepat (misalnya tanda tangan 20 KB atau foto ujian 50 KB), gunakan alat perkecil ukuran gambar di KB yang ditautkan di bawah.

Kompres gambar di bawah 50 KB atau 100 KB untuk formulir

Portal pemerintah dan ujian sering kali membatasi unggahan foto pada 20–50 KB dengan tetap menjaga dimensi minimum. Kompresor ini mengurangi ukuran file dengan melakukan pengkodean ulang ke JPEG pada kualitas pilihan Anda—mulai sekitar 0,6–0,75 untuk potret.

Butuh target yang tepat? Buka Kurangi ukuran gambar dalam KB untuk mencapai 20 KB, 50 KB, atau 100 KB dengan batas lebar × tinggi opsional.

Kompresi pribadi (tidak ada unggahan cloud)

Gambar digambar ke kanvas dan diekspor sebagai JPEG di browser Anda. Tidak ada yang dikirim ke server ToolHQ—cocok untuk bukti ID, tanda tangan, dan pemindaian tugas kuliah.

Cara menggunakan kompresor gambar

  1. Masukkan detail Anda. Pilih file dari perangkat Anda. Itu diproses secara lokal dan tidak pernah diunggah ke situs ini.
  2. Dapatkan hasilnya. Tekan Kompres & unduh . Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Bagaimana cara mengompres foto di bawah 50 KB?

Turunkan penggeser kualitas dan unduh. Jika masih terlalu besar, gunakan Perkecil ukuran gambar dalam KB dengan target 50 dan pangkas kelebihan latar belakang terlebih dahulu.

dukungan PNG?

Anda dapat mengunggah PNG; outputnya adalah JPEG untuk ukuran lebih kecil. Transparansi menjadi putih di JPEG.

Apakah kompresi akan mengubah lebar dan tinggi?

Alat ini mempertahankan piksel asli dan hanya mengubah kualitas JPEG. Untuk mengubah ukuran dimensi, gunakan pengubah ukuran gambar atau perkecil ukuran gambar di alat KB.

Apakah kompresor gambar ini gratis?

Ya. Kompresor gambar gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
