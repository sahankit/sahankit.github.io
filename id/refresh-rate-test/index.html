Bagaimana tes mengukur Hz

Browser menggambar bingkai animasi selaras dengan tampilan Anda. Pengujian ini menghitung waktu ratusan frame dan mengambil celah median: sekitar 16,7 ms adalah 60 Hz, 8,3 ms adalah 120 Hz, 6,9 ms adalah 144 Hz, dan 4,2 ms adalah 240 Hz. Bingkai yang dijatuhkan muncul saat perangkat Anda tidak dapat mengikuti.

Kotak yang bergerak meninggalkan jejak penanda bingkai—pada kecepatan refresh yang lebih tinggi, penanda akan saling berdekatan dan gerakan terlihat lebih mulus.

Melihat 60 Hz pada monitor 144 Hz?

  • Atur kecepatan refresh di Windows (Pengaturan → Tampilan → Tampilan lanjutan) atau macOS (Pengaturan Sistem → Tampilan).
  • Gunakan kabel DisplayPort atau HDMI 2.0+ yang mendukung kecepatan refresh tinggi.
  • Matikan penghemat baterai; laptop sering kali membatasi baterai pada 60 Hz.
  • Pindahkan jendela browser ke layar refresh tinggi jika Anda menggunakan beberapa monitor.

Cara menggunakan tes kecepatan refresh

  1. Masukkan detail Anda. Periksa kecepatan refresh layar Anda dalam Hz secara online. Lihat frame per detik, waktu frame dan frame yang dijatuhkan, dengan tes gerakan. Verifikasi monitor 120 Hz, 144 Hz, atau 240 Hz Anda.
  2. Dapatkan hasilnya. Tekan Ukur lagi. Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah hasilnya akurat?

Ya untuk sebagian besar pengaturan—ini melaporkan apa yang sebenarnya ditampilkan browser. Penyegaran variabel (G-Sync/FreeSync) dan penghematan daya dapat menyebabkan fluktuasi kecil.

Mengapa dikatakan 30 Hz?

Beberapa browser membatasi tab latar belakang atau mode daya rendah. Simpan tab di depan dan colokkan laptop Anda.

Apakah ini berfungsi di ponsel?

Ya. Ini mendeteksi tampilan ponsel 90 dan 120 Hz saat ponsel tidak dalam mode penghemat baterai.

Apakah tes kecepatan refresh ini gratis?

Ya. Tes kecepatan refresh gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
