Tingkat kompresi mana yang harus saya pilih?

  • Direkomendasikan — keseimbangan terbaik untuk sebagian besar dokumen, sertifikat, dan formulir yang dipindai. Teks tetap tajam di layar dan saat dicetak pada ukuran normal.
  • Kuat — file terkecil, untuk batas unggahan yang ketat (misalnya 100–300 KB di portal pemerintah dan ujian).
  • Lampu — kualitas lebih tinggi untuk dokumen dengan cetakan kecil atau gambar detail.
  • Tanpa kerugian — membuat teks, tautan, dan bidang formulir dapat dipilih; itu hanya mengoptimalkan struktur file, sehingga penghematan lebih kecil.

Cara kerjanya dan mengapa ini bersifat pribadi

Kuat, Direkomendasikan, dan Ringan gambar ulang setiap halaman dan simpan sebagai gambar JPEG terkompresi di dalam PDF baru. Tindakan ini memperkecil ukuran PDF yang dipindai secara signifikan, namun teks menjadi bagian dari gambar dan tidak dapat dipilih atau dicari. Mode lossless menulis ulang PDF dengan aliran objek ringkas dan menjaga semuanya tidak berubah.

Semuanya berjalan di perangkat Anda menggunakan pustaka PDF sumber terbuka, sehingga dokumen rahasia seperti bukti identitas, laporan bank, dan sertifikat tidak akan pernah lepas dari komputer atau ponsel Anda.

Cara menggunakan kompres PDF

  1. Masukkan detail Anda. Pilih file dari perangkat Anda. Itu diproses secara lokal dan tidak pernah diunggah ke situs ini.
  2. Dapatkan hasilnya. Tekan Kompres PDF . Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Bagaimana cara mengompres PDF hingga di bawah 200 KB?

Pilih Kuat. Jika masih terlalu besar, pisahkan PDF dan unggah halaman yang diperlukan saja, atau kurangi jumlah halaman yang dipindai.

Mengapa PDF saya tidak mengecil?

PDF yang sebagian besar berupa teks sudah ringkas; mengubahnya menjadi gambar dapat membuatnya lebih besar. Gunakan mode Lossless, atau simpan yang asli.

Apakah ada ukuran file atau batasan halaman?

Tidak ada batasan tetap, tetapi PDF yang sangat besar (ratusan halaman) memerlukan lebih banyak memori dan waktu di ponsel.

Apakah kompres PDF ini gratis?

Ya. Kompres PDF gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
