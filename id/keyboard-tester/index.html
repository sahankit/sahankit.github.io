Batasan pengujian keyboard browser

Beberapa tombol dicadangkan oleh sistem operasi atau browser dan tidak pernah menjangkau halaman web—misalnya Fn, Print Screen pada beberapa sistem, dan pintasan seperti Ctrl+W atau Cmd+Q. Kunci media berbeda-beda menurut perangkat.

Cara menggunakan penguji keyboard

  1. Masukkan detail Anda. Penguji keyboard online gratis. Tekan tombol untuk memeriksa apakah berfungsi: tombol menyala saat ditahan dan tetap ditandai setelah diuji. Menampilkan kunci acara, kode, dan kode kunci.
  2. Dapatkan hasilnya. Tekan Atur ulang tes . Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Bisakah itu menguji rollover kunci (NKRO)?

Tahan beberapa tombol sekaligus—setiap tombol yang ditahan akan menyala. Jika beberapa lampu berhenti, Anda telah mencapai batas rollover keyboard Anda.

Mengapa tombol Fn tidak muncul?

Fn ditangani di dalam perangkat keras keyboard dan tidak dilaporkan ke browser.

Apakah itu merekam apa yang saya ketik?

Tidak. Penekanan tombol hanya ditampilkan di halaman ini dan tidak pernah dikirim ke mana pun.

Apakah penguji keyboard ini gratis?

Ya. Penguji keyboard gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
