Menggunakan Penerjemah API di desktop Chrome 138+. Unduhan paket bahasa pada penggunaan pertama.

Terjemahan pribadi di Chrome

Memerlukan Chrome desktop dengan AI bawaan dan ruang disk kosong yang cukup. Teks diproses di perangkat Anda—bukan di server Sahankit.

Unduhan paket bahasa saat pertama kali digunakan untuk setiap pasangan yang Anda terjemahkan.

Cara menggunakan penerjemah AI

  1. Masukkan detail Anda. Isi Teks, Dari, Ke dan Terjemahan.
  2. Dapatkan hasilnya. Tekan Terjemahkan. Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Kapan menggunakan penerjemah AI

Terjemahkan teks dengan Penerjemah Chrome API. Terjemahan pribadi di perangkat—tidak ada unggahan ke Sahankit. Gunakan saat Anda membutuhkan jawaban cepat tanpa menginstal perangkat lunak atau membuat akun.

Semuanya berjalan secara lokal di browser Anda jika alat tersebut mendukungnya—berguna untuk formulir, faktur, studi, dan pemeriksaan cepat saat bepergian.

Pertanyaan umum

Apakah ini berfungsi di perangkat seluler?

Tidak. API Penerjemah Chrome hanya untuk desktop pada Chrome 138.

Apakah penerjemah AI ini gratis?

Ya. Penerjemah AI gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah penerjemah AI berfungsi di perangkat seluler?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
