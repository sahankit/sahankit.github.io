Tingkatkan kecepatan mengetik dengan tes berwaktu

Tes satu menit menggunakan kata-kata umum bahasa Inggris memberikan perkiraan WPM dan skor akurasi. Berlatih secara teratur; akurasi lebih penting daripada kecepatan untuk pekerjaan nyata.

Cara menggunakan tes kecepatan mengetik

  1. Masukkan detail Anda. Isikan Ketik di sini.
  2. Dapatkan hasilnya. Tekan Tes baru . Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Kapan menggunakan tes kecepatan mengetik

Tes mengetik 1 menit. Ukur kata per menit dan akurasi di browser. Gunakan saat Anda membutuhkan jawaban cepat tanpa menginstal perangkat lunak atau membuat akun.

Semuanya berjalan secara lokal di browser Anda jika alat tersebut mendukungnya—berguna untuk formulir, faktur, studi, dan pemeriksaan cepat saat bepergian.

Pertanyaan umum

Apa itu WPM yang bagus?

40–60 WPM biasa digunakan untuk penggunaan sehari-hari; 70+ cepat untuk pekerjaan kantor.

Apakah tes kecepatan mengetik ini gratis?

Ya. Tes kecepatan mengetik gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah tes kecepatan mengetik berfungsi di perangkat seluler?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
