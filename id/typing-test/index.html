Improve typing speed with timed tests

A one-minute test using common English words gives a rough WPM and accuracy score. Practice regularly; accuracy matters more than speed for real work.

How to use the typing speed test

  1. Enter your details. Fill in Ketik di sini.

Frequently asked questions

Apa itu WPM yang bagus?

40–60 WPM biasa digunakan untuk penggunaan sehari-hari; 70+ cepat untuk pekerjaan kantor.

Is this typing speed test free?

Yes. The typing speed test is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
