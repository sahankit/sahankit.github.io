Screen resolution vs. viewport

Resolusi layar is the size of your whole display. Browsers report it in CSS pixels; multiply by the device pixel ratio to get physical pixels. A 4K monitor at 150% scaling, for example, reports 2560 × 1440 CSS pixels with a ratio of 1.5 (3840 × 2160 physical).

The viewport is the visible area of the web page inside the browser window. Web designers use it to test responsive layouts.

Common resolutions

  • 1920 × 1080 (Full HD, 16:9) — the most common desktop size
  • 1366 × 768 — many budget laptops
  • 2560 × 1440 (QHD) and 3840 × 2160 (4K UHD)
  • 390 × 844 and 412 × 915 — common phone viewports in CSS pixels

Pertanyaan umum

Mengapa resolusi saya lebih rendah dari spesifikasi monitor saya?

Penskalaan tampilan di Windows atau macOS membuat browser melaporkan ukuran CSS yang lebih kecil. Piksel fisik menunjukkan resolusi panel sebenarnya.

Berapa rasio piksel perangkat?

Jumlah piksel fisik per piksel CSS. Layar retina dan DPI tinggi biasanya 2 atau 3.

Apakah ada data yang dikumpulkan?

Tidak. Nilai dibaca dari browser Anda dan hanya ditampilkan kepada Anda.

Apakah screen resolution gratis?

Ya. screen resolution gratis di browser, tanpa akun.

Apakah data saya keluar dari perangkat?
