What’s in the favicon package

  • favicon.ico — contains 16, 32 and 48 px icons for every browser
  • favicon-16x16.png and favicon-32x32.png — modern PNG favicons
  • apple-touch-icon.png (180 px) — iPhone and iPad home screen
  • android-chrome-192x192.png and 512x512.png — Android and installable web apps
  • site.webmanifest and the HTML tags to paste into your page

Tips for a great favicon

Favicons are tiny—often 16 pixels—so keep them simple: one or two letters, a single emoji, or a bold logo mark with strong contrast. Preview the browser-tab mockup to check it’s readable. Upload the files to your site’s root folder, add the tags to every page’s <head>, and clear your browser cache to see the new icon.

Pertanyaan umum

Apakah saya masih memerlukan favicon.ico?

Ini masih merupakan opsi yang paling kompatibel, dan beberapa alat meminta /favicon.ico secara otomatis. Sertakan file ICO dan PNG.

Bisakah saya mengonversi PNG ke ICO?

Ya. Pilih Gambar, unggah PNG Anda, lalu unduh favicon.ico.

Mengapa favicon baru saya tidak muncul?

Browser menyimpan cache favicon secara agresif. Segarkan ulang, buka URL favicon secara langsung, atau uji di jendela pribadi.

Apakah favicon generator gratis?

Ya. favicon generator gratis di browser, tanpa akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.
