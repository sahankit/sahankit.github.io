Tentang kecepatan maraton

Hitung kecepatan maraton dalam hitungan menit per mil dari waktu selesai sasaran. Kalkulator kecepatan lari gratis.

Berjalan di browser—tanpa daftar atau instal.

Cara menggunakan kecepatan maraton

  1. Masukkan detail Anda. Isi Jam, Menit dan Jarak (mil).
  2. Dapatkan hasilnya. Tekan Kecepatan. Pembaruan hasil di halaman.
  3. Gunakan atau salin. Salin atau unduh hasil. Tidak disimpan—segarkan halaman untuk mulai ulang.

Pertanyaan umum

Apakah kecepatan maraton ini gratis?

Ya. Kecepatan maraton gratis untuk digunakan di browser Anda tanpa memerlukan akun.

Apakah data saya keluar dari perangkat?

Sebagian besar alat memproses input di perangkat Anda. Jika alat memanggil API publik (misalnya umur domain), itu ditulis di halaman.

Apakah kecepatan maraton berfungsi di perangkat seluler?

Ya. Halaman bersifat responsif dan alat berjalan di browser seluler dengan cara yang sama seperti di desktop.
