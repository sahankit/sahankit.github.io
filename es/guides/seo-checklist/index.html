Lista de verificación de SEO simple

  1. Título y descripción únicos en cada página.
  2. Enviar mapa del sitio en Google Search Console
  3. Páginas rápidas y optimizadas para dispositivos móviles
  4. Enlaces internos entre herramientas relacionadas
  5. Contenido útil, no spam duplicado
  6. Verifique el historial del dominio de la competencia con el verificador de edad del dominio al hacer investigación

Proyecto de ejemplo: Chat Y en páginas de GitHub con mapa del sitio y guías.

SEO basics for static sites

Static sites on GitHub Pages can rank when each URL has a unique title, helpful body copy, internal links, and a submitted sitemap. Avoid duplicate thin pages and keyword stuffing.

  • One clear H1 per page matching user intent.
  • Meta description ~150 characters summarizing the page.
  • Link related tools together in prose sections.
  • Submit sitemap.xml in Google Search Console and Bing Webmaster.
