GSTIN format reference (15 characters)

Goods and Services Tax Identification Number encodes state, PAN, entity type, and checksum.

SegmentMeaning
1–2State code
3–12PAN of entity
13Entity number / registration within PAN
14Default Z
15Check digit

Cómo utilizar el formato GSTIN

  1. Introduce tus datos. Complete GSTIN.
  2. Obtenga el resultado. Presione Comprobar. Actualización de resultados en la página.
