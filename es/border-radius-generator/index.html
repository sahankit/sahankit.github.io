The four-value order

When the corners differ, CSS reads the four lengths clockwise from the top left: top left, top right, bottom right, bottom left. A single length applies to every corner. The copied line is ready to paste into a style rule.

How to use the border radius generator

  1. Enter your details. Fill in Todas las esquinas (px), Arriba a la izquierda (px), Arriba a la derecha (px), Abajo a la derecha (px) y Abajo a la izquierda (px).
  2. Get the result. The result updates on the page as you type.

Frequently asked questions

¿Puedo usar porcentaje en lugar de píxeles?

Este generador escribe píxeles. Un radio porcentual es relativo al tamaño del cuadro, que cambia a medida que crece el elemento.

Is this border radius generator free?

Yes. The border radius generator is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
