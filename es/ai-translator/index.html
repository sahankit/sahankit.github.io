Los paquetes de idiomas se descargan la primera vez que se utilizan para cada par que traduzca.

Cómo utilizar el traductor de IA

  1. Introduce tus datos. Complete Texto, De, A y Traducción.
  2. Obtenga el resultado. Pulsa Traducir. Actualización de resultados en la página.
  3. Úselo o cópielo. Copia o descarga el resultado. No se guarda nada—recarga para empezar de nuevo.

Cuándo utilizar el traductor de IA

Traduce texto con el traductor API de Chrome. Traducción privada en el dispositivo: no se puede cargar en Sahankit. Úselo cuando necesite una respuesta rápida sin instalar software ni crear una cuenta.

Todo se ejecuta localmente en su navegador donde la herramienta lo admite: útil para formularios, facturas, estudios y comprobaciones rápidas sobre la marcha.

Preguntas frecuentes

¿Esto funciona en el móvil?

No. La API Translator de Chrome es solo para escritorio a partir de Chrome 138.

¿Este traductor de IA es gratuito?

Sí. El traductor AI se puede utilizar de forma gratuita en su navegador sin necesidad de cuenta.

¿Mis datos salen del dispositivo?

En la mayoría de las herramientas, los datos se quedan en tu dispositivo. Si una herramienta llama a una API pública (por ejemplo la edad del dominio), se indica en la página.

¿El traductor de IA funciona en dispositivos móviles?

Sí. Las páginas responden y las herramientas se ejecutan en navegadores móviles de la misma manera que en computadoras de escritorio.
