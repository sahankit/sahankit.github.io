Acerca del buscador de rutas JSON

Extraiga un valor de JSON utilizando una ruta de punto simple (por ejemplo, nombre.de.usuario o elementos[0].id). Se ejecuta en su navegador.

Funciona en el navegador—sin registro ni instalación.

Cómo utilizar el buscador de rutas JSON

  1. Introduce tus datos. Complete JSON y Ruta.
  2. Obtenga el resultado. Pulsa Obtener valor. Actualización de resultados en la página.
  3. Úselo o cópielo. Copia o descarga el resultado. No se guarda nada—recarga para empezar de nuevo.

Preguntas frecuentes

¿Este buscador de rutas JSON es gratuito?

Sí. El buscador de rutas JSON se puede utilizar de forma gratuita en su navegador sin necesidad de una cuenta.

¿Mis datos salen del dispositivo?

En la mayoría de las herramientas, los datos se quedan en tu dispositivo. Si una herramienta llama a una API pública (por ejemplo la edad del dominio), se indica en la página.

¿El buscador de rutas JSON funciona en dispositivos móviles?

Sí. Las páginas responden y las herramientas se ejecutan en navegadores móviles de la misma manera que en computadoras de escritorio.
