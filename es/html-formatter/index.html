Beautify, then read and debug

Paste minified or badly indented code and press embellecer. The formatter (powered by the open-source js-beautify library) re-indents nested tags, CSS rules and JavaScript blocks, and also formats CSS and scripts embedded in HTML. Choose 2 spaces, 4 spaces or tabs to match your project.

Minify for production

  • HTML — removes comments and indentation whitespace while keeping <pre>, <textarea> and <script> content intact.
  • CSS — strips comments, spaces and the last semicolon in each rule.
  • JSON — removes all whitespace.
  • JavaScript — use a build tool such as Terser or esbuild; safe JS minification needs a full parser.

How to use the HTML formatter

  1. Enter your details. Fill in Language , Indent , Paste your code and Result .
  2. Get the result. Press Beautify . Results update on the page.
  3. Use or copy it. Copia o descarga el resultado. No se guarda nada—recarga para empezar de nuevo.

Preguntas frecuentes

¿El formato cambia el funcionamiento de mi página?

Embellecer solo cambia los espacios en blanco. Minimizar HTML colapsa espacios adicionales, lo que casi nunca cambia la representación.

¿Mi código se envía a un servidor?

No. El formateo se realiza en su navegador; sólo se descarga la biblioteca del formateador.

¿Puede arreglar HTML roto?

Sangra lo que le das pero no repara las etiquetas faltantes. Valide con el validador W3C si es necesario.

¿formateador HTML es gratis?

Sí. formateador HTML es gratis en el navegador, sin cuenta.

¿Mis datos salen del dispositivo?

En la mayoría de las herramientas, los datos se quedan en tu dispositivo. Si una herramienta llama a una API pública (por ejemplo la edad del dominio), se indica en la página.
