Convierta imágenes PDF a JPG, PNG o WebP en su navegador. Elija una calidad de hasta 300 ppp, elija páginas y descárguelas una por una o todas como ZIP. Sin carga.

Cómo convertir PDF a JPG

  • Elija su archivo PDF.
  • Elija JPG para archivos pequeños, PNG para texto y diagramas nítidos o WebP para el formato moderno más pequeño.
  • Elija 150 ppp para pantallas y uso compartido, o 300 ppp para impresión.
  • Optionally enter pages such as 1-3, 5, then press Convertir a imágenes.
  • Descargue las páginas una por una o todas juntas como un archivo ZIP.

Privado y rápido

Las páginas se procesan con el motor PDF.js de Mozilla dentro de su navegador, por lo que su PDF nunca se carga. Eso lo hace seguro para certificados, hojas de calificaciones, facturas y documentos de identificación, y funciona sin conexión una vez cargado.

Cómo utilizar PDF a JPG

  1. Introduce tus datos. Elija un archivo de su dispositivo. Se procesa localmente y nunca se carga en este sitio.
  2. Obtenga el resultado. Pulsa Convertir a imágenes. Los resultados se actualizan en la página y se vuelven a calcular a medida que edita los valores.
  3. Úselo o cópielo. Copia o descarga el resultado. No se guarda nada—recarga para empezar de nuevo.

Preguntas frecuentes

¿Qué resolución debo elegir?

150 ppp es ideal para WhatsApp, correo electrónico y sitios web. Elija 300 ppp si planea imprimir las imágenes.

¿Puedo convertir solo una página?

Sí. Escriba el número de página en el cuadro Páginas, por ejemplo 2.

¿Funciona para archivos PDF escaneados?

Sí. Cada página se guarda exactamente como aparece, ya sea que contenga texto o imágenes escaneadas.

¿Este PDF a JPG es gratuito?

Sí. El PDF a JPG se puede utilizar de forma gratuita en su navegador sin necesidad de una cuenta.

¿Mis datos salen del dispositivo?

En la mayoría de las herramientas, los datos se quedan en tu dispositivo. Si una herramienta llama a una API pública (por ejemplo la edad del dominio), se indica en la página.
