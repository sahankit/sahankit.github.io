Writing tools with Chrome built-in AI

Translate, check grammar, summarize, rewrite, and generate emails, meta descriptions, and social posts using APIs built into desktop Chrome. Models run on your device after a one-time download.

Frequently asked questions

Why does AI say unavailable?

You need desktop Chrome, sufficient disk/RAM, and sometimes chrome://flags for Proofreader, Writer, or Rewriter.

Is Summarizer the same as ChatGPT?

No. These APIs use Google’s on-device model in Chrome, not a cloud chat service.

Which APIs need chrome://flags?

Writer, Rewriter, Proofreader, Summarizer, Translator, and Language Detector may need flags on some Chrome versions—each tool page explains if the API is missing.
