Screen resolution vs. viewport

Screen resolution is the size of your whole display. Browsers report it in CSS pixels; multiply by the device pixel ratio to get physical pixels. A 4K monitor at 150% scaling, for example, reports 2560 × 1440 CSS pixels with a ratio of 1.5 (3840 × 2160 physical).

The viewport is the visible area of the web page inside the browser window. Web designers use it to test responsive layouts.

Common resolutions

  • 1920 × 1080 (Full HD, 16:9) — the most common desktop size
  • 1366 × 768 — many budget laptops
  • 2560 × 1440 (QHD) and 3840 × 2160 (4K UHD)
  • 390 × 844 and 412 × 915 — common phone viewports in CSS pixels

Frequently asked questions

Why is my resolution lower than my monitor’s spec?

Display scaling in Windows or macOS makes the browser report a smaller CSS size. Physical pixels shows the real panel resolution.

What is device pixel ratio?

The number of physical pixels per CSS pixel. Retina and high-DPI screens are usually 2 or 3.

Is any data collected?

No. Values are read from your browser and shown only to you.

Is this screen resolution free?

Yes. The screen resolution is free to use in your browser with no account required.
