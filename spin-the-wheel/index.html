How to use the wheel

Type or paste entries into the box, one per line—names for a classroom, prizes for a giveaway, places to eat, or chores. The wheel redraws as you type. Press Spin (or tap the centre) and the pointer at the top picks the winner.

Tick Remove the winner after each spin to draw several unique winners in a row, like picking teams or raffle prizes. Your list is saved in this browser so it is still there next time.

Is it really random?

Each spin uses your browser’s cryptographic random number generator (crypto.getRandomValues) to choose the spin strength and stopping angle, so every entry has an equal chance. The animation is only for show—the result is decided fairly.

Frequently asked questions

How many entries can I add?

Up to 300. Long names are shortened on the wheel but shown in full when they win.

Can I give one option a bigger chance?

Yes—add it on more than one line. Each line is one equal slice of the wheel.

Can I use it for a giveaway?

Yes. Paste the participant list, enable remove-winner, and spin once per prize. Screen-record the spin for transparency.

Is this spin the wheel free?

Yes. The spin the wheel is free to use in your browser with no account required.

Does my data leave my device?

For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
