Ekran çözünürlüğü ve görünüm alanı

Ekran çözünürlüğü tüm ekranınızın boyutudur. Tarayıcılar bunu CSS piksel cinsinden bildirir; ile çarpın cihaz piksel oranı fiziksel pikseller elde etmek için. Örneğin %150 ölçeklendirmedeki bir 4K monitör, 1,5 (3840 × 2160 fiziksel) oranla 2560 × 1440 CSS piksel rapor eder.

The görünüm alanı Web sayfasının tarayıcı penceresinde görünen alanıdır. Web tasarımcıları bunu duyarlı düzenleri test etmek için kullanır.

Ortak kararlar

  • 1920 × 1080 (Full HD, 16:9) — en yaygın masaüstü boyutu
  • 1366 × 768 — birçok uygun fiyatlı dizüstü bilgisayar
  • 2560 × 1440 (QHD) ve 3840 × 2160 (4K UHD)
  • 390 × 844 ve 412 × 915 — CSS piksel cinsinden yaygın telefon görünüm pencereleri

Ekran çözünürlüğü nasıl kullanılır?

  1. Bilgilerinizi girin. Ekran çözünürlüğünüzü, fiziksel piksellerinizi, tarayıcı görüntü alanı boyutunu, cihaz piksel oranını, renk derinliğini ve yönünü anında görün. Siz yeniden boyutlandırdıkça güncellemeler yayınlanır.
  2. Sonucu alın. Sonuç, siz yazdıkça sayfada güncellenir.
  3. Kullanın veya kopyalayın. Çıktıyı kopyalayın veya indirin. Saklanmaz—yenilemek sıfırlar.

Sık sorulan sorular

Çözünürlüğüm neden monitörümün teknik özelliklerinden daha düşük?

Windows veya macOS'ta ekran ölçeklendirme, tarayıcı raporunun daha küçük bir CSS boyutuna sahip olmasını sağlar. Fiziksel pikseller gerçek panel çözünürlüğünü gösterir.

Cihaz piksel oranı nedir?

CSS piksel başına fiziksel piksel sayısı. Retina ve yüksek DPI ekranlar genellikle 2 veya 3'tür.

Herhangi bir veri toplanıyor mu?

Hayır. Değerler tarayıcınızdan okunur ve yalnızca size gösterilir.

Bu ekran çözünürlüğü ücretsiz mi?

Evet. Ekran çözünürlüğünü tarayıcınızda hesap gerektirmeden kullanmak ücretsizdir.

Verilerim cihazdan çıkar mı?

Çoğu araç girdiyi cihazınızda işler. Araç genel bir API çağırırsa (ör. alan yaşı) sayfada belirtilir.
