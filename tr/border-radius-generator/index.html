The four-value order

When the corners differ, CSS reads the four lengths clockwise from the top left: top left, top right, bottom right, bottom left. A single length applies to every corner. The copied line is ready to paste into a style rule.

How to use the border radius generator

  1. Enter your details. Fill in All corners (px) , Top left (px) , Top right (px) , Bottom right (px) and Bottom left (px) .
  2. Get the result. The result updates on the page as you type.
  3. Use or copy it. Çıktıyı kopyalayın veya indirin. Saklanmaz—yenilemek sıfırlar.

Sık sorulan sorular

Can I use percent instead of pixels?

This generator writes pixels. A percentage radius is relative to the box size, which changes as the element grows.
