    What this calculator can do

    • Trigonometry — sin, cos and tan in degrees or radians (tap DEG/RAD). Type asin, acos or atan for inverse functions.
    • Logs and roots — log (base 10), ln (natural log), √ square root and cbrt for cube roots.
    • Powers — x² and xʸ, scientific notation with EXP (for example 6.02E23).
    • Factorials and percent — 5! = 120, and 50% is read as 0.5.
    • Constants and memory — π, e and Ans (the last result), plus a history of your last 10 calculations.

    Order of operations

    Expressions follow standard precedence: brackets first, then powers, then multiplication and division, then addition and subtraction. Powers are right-associative, so 2^3^2 = 2^9 = 512, and −2^2 = −4. Implied multiplication works too: 2π, 3(4+1) and 2sin(30) are all valid. Missing closing brackets are added automatically.

    On a computer you can type the whole expression and press Enter. Use * or x for multiply and / for divide.

    How to use the scientific calculator

    1. Enter your details. Fill in Expression.
    2. Get the result. The result updates on the page as you type.
    3. Use or copy it. Copy or download the output. Nothing is stored—refresh the page to start over.

    Frequently asked questions

    Why does sin(30) give 0.5 but sin(π/6) gives something else?

    The calculator starts in degree mode, so sin(30) means 30°. Tap DEG to switch to RAD before using radians such as π/6.

    How do I enter scientific notation?

    Use the EXP key or type a capital E, for example 3.2E-5 for 3.2 × 10⁻⁵.

    Is my history saved?

    History is kept only while the page is open. Nothing is sent to a server.

    Is this scientific calculator free?

    Yes. The scientific calculator is free to use in your browser with no account required.

    Does my data leave my device?

    For most tools on this site, input stays on your device. If a tool calls a public API (for example domain age), that is noted on the page.
